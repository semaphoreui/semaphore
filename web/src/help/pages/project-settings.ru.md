# Настройки проекта

Настройки проекта в целом: его имя, сколько его задач может выполняться одновременно и отправляет
ли он оповещения. В разделе «Опасная зона» под формой собраны действия, которые затрагивают весь
проект: его резервная копия, его кэш и его удаление. Изменения в форме вступают в силу после
нажатия **Сохранить**.

## Имя проекта {#newProject-name}

Имя, под которым проект показан в меню проектов в верхней части боковой панели. Поле
обязательное.

## Максимальное количество параллельных задач {#newProject-maxParallelTasks}

Сколько задач этого проекта может выполняться одновременно. Задача, запущенная сверх лимита, ждет
в очереди, пока не завершится одна из выполняемых задач.

Оставьте поле пустым или укажите `0`, чтобы у проекта не было собственного лимита. Лимит всего
сервера, заданный его администратором, действует в любом случае.

## Telegram Chat ID {#newProject-tg}

Необязательное поле. Чат Telegram, в который приходят оповещения этого проекта. Если поле пустое,
оповещения отправляются в чат, заданный для всего сервера.

Поле действует, только если администратор включил оповещения в Telegram для сервера и оповещения
разрешены для этого проекта.

## Разрешить оповещения для этого проекта {#newProject-alert}

Включает оповещения для задач этого проекта. Куда отправляются оповещения, задает для всего
сервера его администратор: электронная почта, Telegram, Slack, Rocket.Chat, Microsoft Teams,
DingTalk или Gotify.

- Письмо отправляется, когда задача завершается с ошибкой, тем участникам проекта, которые могут
  видеть задачу и у которых в учетной записи включены оповещения.
- Сообщение в мессенджеры отправляется, когда задача завершается успешно, завершается с ошибкой
  или ждет подтверждения.

Шаблон задачи может запретить своим успешным или своим неудачным задачам отправлять оповещения.

## Test Alerts {#settings-testAlerts}

Отправляет тестовое оповещение по каждому каналу, включенному на сервере, чтобы вы могли
проверить, что оповещения этого проекта доходят.

Кнопка работает, только если флажок **Разрешить оповещения для этого проекта** установлен и
сохранен. Сначала установите его и нажмите **Сохранить**.

## Резервное копирование проекта {#settings-exportProject}

Скачивает JSON-файл с конфигурацией проекта: шаблоны задач, инвентари, репозитории, группы
переменных, ключи, расписания, интеграции и все остальное, что в нем настроено. Из этого файла
можно снова создать проект с помощью **Восстановить проект** в меню проектов в верхней части
боковой панели.

Файл не включает секреты ключей и секреты на вкладке **Secrets** групп переменных: их нужно ввести
заново после восстановления. Все остальное копируется как есть, в том числе пароль, введенный прямо
в другое поле: адрес репозитория с паролем в нем, текст статического инвентаря, значения обычных
переменных и переменных окружения. Проверьте, нет ли в файле таких значений, прежде чем делиться
им. История задач не входит в резервную копию.

## Очистить кэш {#settings-clearCache}

Удаляет файлы, которые Semaphore хранит на сервере для этого проекта, например его копии
репозиториев. Они скачиваются заново при запуске следующей задачи.

Используйте это действие, когда задача завершается с ошибкой из-за устаревшей или поврежденной
копии репозитория. Действие нельзя отменить, и оно не затрагивает настройки проекта.

## Удалить проект {#settings-deleteProject}

Удаляет проект со всем его содержимым: шаблонами задач, историей задач, инвентарями,
репозиториями, группами переменных, ключами и расписаниями. Сначала Semaphore запрашивает
подтверждение.

Удаленный проект нельзя восстановить. Скачайте резервную копию, прежде чем удалять проект, который
может снова понадобиться.
