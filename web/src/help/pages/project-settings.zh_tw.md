# 專案設定

整個專案的設定：專案名稱、可以同時執行的任務數量，以及是否發送警報。表單下方的危險區域包含作用於整個專案的操作：
備份專案、清除快取和刪除專案。表單中的變更在按下**儲存**後生效。

## 專案名稱 {#newProject-name}

專案在側邊欄頂端的專案選單中顯示的名稱。此欄位為必填。

## 最大平行任務數 {#newProject-maxParallelTasks}

此專案可以同時執行的任務數量。超過上限後啟動的任務會在佇列中等候，直到某個執行中的任務結束。

將此欄位留空或設為 `0`，表示專案本身不設上限。無論哪種情況，由管理員設定的整個伺服器的上限都會適用。

## Telegram 聊天 ID {#newProject-tg}

選填。接收此專案警報的 Telegram 聊天室。若此欄位為空，警報會傳送到為整個伺服器設定的聊天室。

只有在管理員已為伺服器啟用 Telegram 警報，且此專案允許警報時，此欄位才會生效。

## 啟用此專案的警報 {#newProject-alert}

為此專案的任務啟用警報。警報的傳送管道由管理員為整個伺服器設定：電子郵件、Telegram、Slack、Rocket.Chat、
Microsoft Teams、DingTalk 或 Gotify。

- 任務失敗時會寄送電子郵件，收件者是能夠檢視該任務、且在自己的帳號中啟用了警報的專案成員。
- 任務成功、失敗或等待確認時，會向通訊軟體傳送訊息。

任務範本可以讓其成功或失敗的任務不發送警報。

## Test Alerts {#settings-testAlerts}

透過伺服器已啟用的每個管道傳送一則測試警報，讓您確認此專案的警報能否送達。

只有在勾選並儲存**啟用此專案的警報**之後，此按鈕才會生效。請先勾選它，再按下**儲存**。

## 備份專案 {#settings-exportProject}

下載一個包含專案設定的 JSON 檔案：任務範本、清單、儲存庫、變數群組、金鑰、排程、整合，以及專案中設定的其他項目。
可以透過側邊欄頂端專案選單中的**還原專案**，將該檔案重新還原成專案。

該檔案不包含金鑰的機密值，以及變數群組 **Secrets** 分頁中的機密值：還原之後，必須重新輸入它們。其他所有內容都會原樣複製，包括直接輸入到其他欄位中的密碼：含有密碼的儲存庫位址、靜態清單的文字、一般變數和環境變數的值。分享該檔案之前，請先檢查其中是否有這類值。任務歷史不包含在備份中。

## 清除快取 {#settings-clearCache}

刪除 Semaphore 在伺服器上為此專案保存的檔案，例如它保存的儲存庫副本。這些檔案會在下一個任務開始時重新下載。

當任務因儲存庫副本過時或損毀而失敗時，請使用此操作。此操作無法復原，也不會影響專案的設定。

## 刪除專案 {#settings-deleteProject}

刪除專案及其中的所有內容：任務範本、任務歷史、清單、儲存庫、變數群組、金鑰和排程。Semaphore 會先要求確認。

已刪除的專案無法復原。在刪除日後可能還會用到的專案之前，請先下載備份。
