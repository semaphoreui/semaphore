# 团队

项目的成员及其拥有的角色。角色决定成员在项目中可以做什么：运行任务、更改模板和其他资源、管理团队。一个成员可以拥有多个角色，并获得其中任一角色授予的所有权限。

- **新团队成员**以某个角色将用户添加到项目中。只有可以管理团队的成员才能看到此按钮。
- **角色**列会立即更改成员的角色，无需保存。不能管理团队的成员可以看到角色，但无法更改。
- 带锁的角色来自用户在 LDAP 或 OIDC 中的某个组，管理员已将该组映射到此角色。这里无法移除它：当用户离开该组或映射被删除时，它才会消失。
- 项目至少需要一个 Owner。除非由 Semaphore 管理员操作，否则 Semaphore 会拒绝移除最后一个 Owner 或取消其 Owner 角色。
- **离开项目**会将你移出项目。只有管理员允许成员离开项目时才会显示此按钮；最后一个 Owner 同样不能离开。
