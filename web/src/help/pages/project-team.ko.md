# 팀

프로젝트의 멤버와 각 멤버가 가진 역할입니다. 역할은 멤버가 프로젝트에서 할 수 있는 일을 정합니다: 작업 실행, 템플릿과 기타 리소스 변경, 팀
관리. 멤버는 여러 역할을 가질 수 있으며 그중 어느 역할이 주는 권한이든 모두 받습니다.

- **새 팀 멤버**는 역할과 함께 사용자를 프로젝트에 추가합니다. 이 버튼은 팀을 관리할 수 있는 멤버에게 표시됩니다.
- **역할** 열은 저장 없이 멤버의 역할을 바로 바꿉니다. 팀을 관리할 수 없는 멤버는 역할을 볼 수 있지만 바꿀 수는 없습니다.
- 자물쇠가 있는 역할은 관리자가 그 역할에 연결한 LDAP 또는 OIDC의 사용자 그룹에서 옵니다. 여기서는 뺄 수 없으며, 사용자가 그룹을
  떠나거나 연결이 삭제되면 사라집니다.
- 프로젝트에는 Owner가 최소 한 명 있어야 합니다. Semaphore 관리자가 하는 경우가 아니면, 마지막 Owner를 제거하거나 그에게서 Owner 역할을
  빼는 것은 거부됩니다.
- **프로젝트 나가기**는 사용자를 프로젝트에서 내보냅니다. 관리자가 멤버의 프로젝트 탈퇴를 허용한 경우에만 표시되며, 마지막 Owner는
  나갈 수 없습니다.
