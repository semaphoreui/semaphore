# Команда

Участники проекта и их роли. Роль определяет, что участник может делать в проекте: запускать
задачи, изменять шаблоны и другие ресурсы, управлять командой. Участник может иметь несколько
ролей и получает все права, которые дает любая из них.

- **Новый участник команды** добавляет пользователя в проект с ролью. Кнопку видят участники,
  которым разрешено управлять командой.
- Столбец **Роль** меняет роли участника сразу, без сохранения. Участник без права управлять
  командой видит роли, но не может их изменить.
- Роль с замком получена из группы пользователя в LDAP или OIDC, которую администратор сопоставил
  с этой ролью. Ее нельзя убрать здесь: она исчезает, когда пользователь выходит из группы или
  сопоставление удаляют.
- В проекте должен быть хотя бы один Owner. Semaphore не дает удалить последнего Owner или снять
  с него роль Owner, если это делает не администратор Semaphore.
- **Покинуть проект** выводит вас из проекта. Кнопка видна, только если администратор разрешил
  участникам покидать проекты; последний Owner покинуть проект тоже не может.
