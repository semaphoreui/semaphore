# 團隊

專案的成員及其擁有的角色。角色決定成員在專案中可以做什麼：執行任務、變更範本與其他資源、管理團隊。一位成員可以擁有多個角色，並取得其中任一角色授予的所有權限。

- **新增團隊成員**會以某個角色將使用者加入專案。只有可以管理團隊的成員才看得到此按鈕。
- **角色**欄會立即變更成員的角色，不需要儲存。不能管理團隊的成員看得到角色，但無法變更。
- 帶鎖的角色來自使用者在 LDAP 或 OIDC 中的某個群組，管理員已將該群組對應到此角色。這裡無法移除它：當使用者離開該群組或對應被刪除時才會消失。
- 專案至少需要一位 Owner。除非由 Semaphore 管理員操作，否則 Semaphore 會拒絕移除最後一位 Owner 或取消其 Owner 角色。
- **離開專案**會將你移出專案。只有管理員允許成員離開專案時才會顯示此按鈕；最後一位 Owner 同樣不能離開。
