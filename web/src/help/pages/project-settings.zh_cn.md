# 项目设置

整个项目的设置：项目名称、可以同时运行的任务数量，以及是否发送警报。表单下方的危险区域包含作用于整个项目的操作：
备份项目、清除缓存和删除项目。表单中的更改在点击**保存**后生效。

## 项目名称 {#newProject-name}

项目在侧边栏顶部的项目菜单中显示的名称。此字段为必填项。

## 最大并行任务数 {#newProject-maxParallelTasks}

此项目可以同时运行的任务数量。超出限制后启动的任务会在队列中等待，直到某个正在运行的任务结束。

将此字段留空或设为 `0`，表示项目本身不设限制。无论哪种情况，由管理员设置的整个服务器的限制都适用。

## Telegram 聊天 ID {#newProject-tg}

可选。接收此项目警报的 Telegram 聊天。如果此字段为空，警报将发送到为整个服务器设置的聊天。

只有当管理员已为服务器启用 Telegram 警报，并且此项目允许警报时，此字段才会生效。

## 允许此项目的警报 {#newProject-alert}

为此项目的任务启用警报。警报的发送渠道由管理员为整个服务器设置：电子邮件、Telegram、Slack、Rocket.Chat、
Microsoft Teams、DingTalk 或 Gotify。

- 任务失败时会发送电子邮件，收件人是能够查看该任务、并且在自己的账户中启用了警报的项目成员。
- 任务成功、失败或等待确认时，会向即时通讯工具发送消息。

任务模板可以阻止其成功或失败的任务发送警报。

## Test Alerts {#settings-testAlerts}

通过服务器已启用的每个渠道发送一条测试警报，以便检查此项目的警报能否送达。

只有在勾选并保存了**允许此项目的警报**之后，此按钮才会生效。请先勾选它，然后点击**保存**。

## 备份项目 {#settings-exportProject}

下载一个包含项目配置的 JSON 文件：任务模板、库存、仓库、变量组、密钥、计划、集成以及项目中设置的其他内容。
可以通过侧边栏顶部项目菜单中的**恢复项目**，将该文件重新还原为项目。

该文件不包含密钥的秘密值以及变量组 **Secrets** 标签页中的秘密值：恢复之后，需要重新输入它们。其他所有内容都按原样复制，包括直接输入到其他字段中的密码：包含密码的仓库地址、静态库存的文本、普通变量和环境变量的值。分享该文件之前，请检查其中是否有此类值。任务历史不包含在备份中。

## 清除缓存 {#settings-clearCache}

删除 Semaphore 在服务器上为此项目保存的文件，例如它保存的仓库副本。这些文件会在下一个任务开始时重新下载。

当任务因仓库副本过期或损坏而失败时，请使用此操作。此操作无法撤销，并且不会影响项目的设置。

## 删除项目 {#settings-deleteProject}

删除项目及其中的所有内容：任务模板、任务历史、库存、仓库、变量组、密钥和计划。Semaphore 会先请求确认。

已删除的项目无法恢复。在删除以后可能还会用到的项目之前，请先下载备份。
