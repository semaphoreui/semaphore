# Змінити пароль

Встановлює новий пароль для входу в Semaphore з ім’ям користувача і паролем. Новий пароль набуває
чинності, коли ви натискаєте **Зберегти**. Зовнішній користувач, який входить через LDAP або
OpenID Connect, не має тут пароля, який можна змінити.

## Current password {#changePassword-currentPassword}

Відображається, коли ви змінюєте власний пароль.

Ваш поточний пароль. Поле обов’язкове: Semaphore перевіряє його, перш ніж установити новий, щоб
викрадений сеанс або API-токен не можна було перетворити на ваш пароль. Сервер відхиляє зміну,
якщо пароль не збігається.

Адміністратор або менеджер користувачів, який скидає пароль іншого користувача, не бачить цього
поля.

## Пароль {#changePassword-password}

Новий пароль. Поле обов’язкове. Натисніть іконку ока, щоб побачити введене.

Semaphore зберігає лише хеш пароля.
