# パスワードを変更

ユーザー名とパスワードで Semaphore にサインインするための新しいパスワードを設定します。新しいパスワードは **保存** を押すと反映されます。LDAP または OpenID Connect でサインインする外部ユーザーには、ここで変更するパスワードはありません。

## Current password {#changePassword-currentPassword}

自分のパスワードを変更する場合に表示されます。

現在のパスワードです。このフィールドは必須です。Semaphore は新しいパスワードを設定する前にこれを確認するため、盗まれたセッションや API トークンを使ってパスワードを変更されることはありません。パスワードが一致しない場合、サーバーは変更を拒否します。

管理者、または他のユーザーのパスワードをリセットするユーザー管理者には、このフィールドは表示されません。

## パスワード {#changePassword-password}

新しいパスワードです。このフィールドは必須です。目のアイコンをクリックすると、入力した内容が表示されます。

Semaphore はパスワードのハッシュのみを保存します。
