# Choose workspace to attach

Привязывает этот workspace к шаблону, чтобы он появился среди workspace шаблона вместе со своим
состоянием и псевдонимами. Workspace одновременно принадлежит только одному шаблону: после
привязки он исчезает со страницы «Инвентарь» и управляется в шаблоне. Привязка не делает его
workspace по умолчанию для шаблона: для этого откройте шаблон и нажмите **Make default**.

## Template {#inventoryAttach-templateId}

Шаблон, к которому нужно привязать workspace. Поле обязательное. В списке показаны шаблоны
проекта, созданные для того же приложения, что и workspace, — Terraform или OpenTofu.

Workspace сохраняет свое имя, ключ и состояние. Чтобы позже перенести его в другой шаблон, нажмите
**Detach** в шаблоне, к которому он привязан: он вернется на страницу «Инвентарь». Workspace по
умолчанию шаблона нельзя отвязать.
