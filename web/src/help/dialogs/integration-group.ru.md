# Редактировать интеграцию

Интеграция — это набор запусков, которые срабатывают от одного эндпоинта. Когда запрос на URL этого
эндпоинта проходит авторизацию, срабатывает каждый запуск интеграции, условия которого принимают
запрос.

## Имя {#integrationGroupForm-name}

Имя, под которым интеграция показана на странице «Интеграции». Поле обязательное.

## Эндпоинт {#integrationGroupForm-endpointId}

Эндпоинт, URL которого запускают запуски этой интеграции. Один эндпоинт могут использовать несколько
интеграций. Поле обязательное.

## Переопределить авторизацию {#integrationGroupForm-authOverride}

Оставьте выключенным, чтобы запросы проверялись так же, как у эндпоинта. Включите, чтобы проверять
запросы этой интеграции собственным методом и секретом, заданными в полях, которые появятся ниже;
настройки эндпоинта тогда к этой интеграции не применяются.

## Метод авторизации {#integrationAuthForm-authMethod}

Как Semaphore проверяет, что запрос пришел от ожидаемого сервиса. Запрос, не прошедший проверку,
ничего не запускает, и webhook отвечает на него так же, как на любой другой запрос.

- **Нет**: без проверки. Любой, кто знает URL, может запустить задачу.
- **GitHub Webhooks**: заголовок `X-Hub-Signature-256` должен содержать подпись HMAC-SHA256 тела,
  созданную с секретом, в том виде, в каком ее отправляет GitHub.
- **Bitbucket Webhooks**: та же проверка заголовка `X-Hub-Signature`, в том виде, в каком его
  отправляет Bitbucket.
- **Token**: заголовок, указанный в **Заголовок авторизации**, должен содержать сам секрет.
- **HMAC** и **HMAC (SHA-512)**: заголовок, указанный в **Заголовок авторизации**, должен содержать
  HMAC-SHA256 или HMAC-SHA512 тела, созданный с секретом, в шестнадцатеричном виде строчными
  буквами, без префикса вроде `sha256=`.
- **BasicAuth**: запрос должен передавать логин и пароль ключа из поля **Секрет аутентификации** в
  своем заголовке `Authorization`.

## Заголовок авторизации {#integrationAuthForm-authHeader}

Показывается, когда в поле **Метод авторизации** выбрано **Token**, **HMAC** или **HMAC (SHA-512)**.

Имя заголовка запроса, в котором передается токен или подпись, например `X-Webhook-Token`.
Регистр имени не важен. Запрос без этого заголовка отклоняется.

## Секрет аутентификации {#integrationAuthForm-authSecretId}

Показывается, когда в поле **Метод авторизации** выбрано не **Нет**.

Ключ из раздела «Хранилище ключей», по которому проверяется запрос. Для **BasicAuth** подходит
только ключ типа **Логин с паролем**. Для остальных методов подходит и ключ типа **Строка**:
проверка использует его значение или пароль ключа **Логин с паролем**.

Поле нужно для всех методов, кроме **Нет**: без ключа или с пустым секретом отклоняется каждый
запрос.
