# Template permissions

이 템플릿 하나에 대해 역할에 추가 권한을 부여합니다. 이 역할을 가진 멤버는 역할이 프로젝트 전체에서 가진 권한에
더해 이 권한을 받습니다. 여기에서 부여한 권한은 추가만 할 뿐, 권한을 빼앗지 않습니다. 여러 역할을 가진 멤버는
그 역할 중 어느 하나에 부여된 모든 권한을 받습니다.

## 역할 {#templatePerm-roleSlug}

권한을 받는 역할입니다. 목록에는 이 프로젝트의 역할, 공유 역할, 기본 제공 역할이 표시됩니다. 이 필드는 필수이며,
한 역할은 한 템플릿에 대해 하나의 권한 부여만 가질 수 있습니다. 서버는 두 번째 부여를 거부합니다.

저장된 권한 부여의 역할은 변경할 수 없습니다. 여기에서 무엇을 선택하든 서버는 역할을 유지하고 권한만 저장합니다.
다른 역할에 권한을 주려면 목록에서 이 권한 부여를 제거하고 새로 추가하세요.

## Permissions {#templatePerm-permissionsTitle}

이 역할을 가진 멤버가 이 템플릿으로 할 수 있는 일입니다.

- **Can see this template**: 템플릿이 그 작업과 로그와 함께 템플릿 목록에 표시됩니다.
- **Can run this template**: 템플릿에서 작업을 시작하고, 그 작업을 중지하거나 확인하거나 거부합니다.
- **Can edit this template**: 템플릿을 변경하고 삭제하며, 모든 작업을 중지하고, 이 권한을 관리합니다.

실행이나 편집에는 템플릿 보기가 포함됩니다. 둘 중 하나를 체크하면 **Can see this template**도 체크되며 해제할 수
없습니다. 아무 권한도 주지 않는 권한 부여를 저장하려면 모든 상자를 체크 해제한 채로 두세요.
