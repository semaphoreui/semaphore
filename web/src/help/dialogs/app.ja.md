# Edit App

アプリは、Semaphore がタスクの実行に使うツールです。Ansible、Terraform、OpenTofu、Terragrunt、Bash、Python、PowerShell、または独自のコマンドがあります。すべてのタスクテンプレートは 1 つのアプリ用に作られます。このダイアログでは、サーバーがアプリをどのように起動するか、インターフェースでアプリをどのように表示するかを設定します。

設定はデータベースに保存され、保存したサーバーではすぐに反映されます。クラスターの他のノードは、再起動時に設定を読み込みます。空にしたフィールドは、サーバーが再起動するまで以前の値を保持します。

## ID {#appForm-id}

必須です。アプリを保存するときのキーで、タスクテンプレートはこのキーでアプリを参照します。組み込みのアプリは `ansible`、`terraform`、`tofu`、`terragrunt`、`pulumi`、`bash`、`python`、`powershell` です。それ以外の ID を指定すると、独自のアプリが追加されます。Semaphore はそれをスクリプトとして実行し、**Path** に指定されたコマンド、または **Path** が空の場合は ID と同じ名前のコマンドを使います。

ID にはドットを含めないでください。既存のアプリの ID を変更しても、アプリの名前は変わりません。設定は新しい ID の新しいアプリとして保存され、古いアプリは残ります。

## Icon {#appForm-icon}

任意です。Material Design Icons のアイコン名で、`mdi-` 接頭辞を付けずに指定します。例: `language-python`。アプリの組み込みアイコンを使う場合は空のままにします。その場合、独自のアプリには疑問符が表示されます。

## 名前 {#appForm-title}

任意です。アプリケーションの一覧と **新しいテンプレート** メニューに表示されるアプリの名前です。`Ansible Playbook` のような組み込みの名前を使う場合は空のままにします。その場合、独自のアプリには名前がなくなるので、名前を付けてください。

## Path {#appForm-path}

任意です。Semaphore がデフォルトのコマンドの代わりに実行するコマンドです。サーバーの `PATH` から検索される名前か、フルパスを指定します。例: `/usr/local/bin/terraform-1.9`。デフォルトは `terraform`、`tofu`、`terragrunt`、`bash`、`python3`、`powershell` です。独自のアプリは、ID と同じ名前のコマンドを実行します。

Ansible はこのフィールドを無視します。Semaphore は常に `ansible-playbook` と `ansible-galaxy` を実行します。

## Priority {#appForm-priority}

アプリケーションの一覧と **新しいテンプレート** メニューでのアプリの位置です。数値が大きいアプリほど先に表示されます。組み込みのアプリは、Ansible の 1000 から Python の 500 までです。優先度が `0` 以下の組み込みアプリは、サーバーの起動時に組み込みの優先度に戻ります。

## Args {#appForm-args}

任意です。コマンドラインでコマンドの直後に置かれる引数で、チップ 1 つにつき 1 つです。**+** をクリックすると追加し、チップをクリックすると変更し、チップをドラッグすると順序を変更します。

- Terraform、OpenTofu、Terragrunt: これらの引数は、`init` や `apply` など、Semaphore がすべてのコマンドに追加する引数の前に置かれます。
- スクリプトのアプリ: これらの引数はテンプレートのスクリプトの前に置かれ、デフォルトの引数を置き換えます。PowerShell はデフォルトで `-File` 付きで実行されるため、`-File` を一覧の最後に置いてください。
- Ansible はこのフィールドを無視します。

## Active {#appForm-active}

有効なアプリは **新しいテンプレート** メニューに表示されます。チェックを外すと、そのメニューにアプリが表示されなくなります。そのアプリで作成済みのテンプレートは、アプリを保持したまま引き続き実行されます。

新しいアプリではチェックが外れています。アプリを利用可能にするにはチェックを入れます。
