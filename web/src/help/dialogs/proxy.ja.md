# 編集 Proxy

プロキシは、プロジェクトのタスクが直接接続できないサーバーに到達するために経由するホストです。
リポジトリの **Proxy** フィールドで選ぶとリポジトリをそれ経由で取得し、インベントリで選ぶと
Ansible がそれ経由でホストに接続します。

## 名前 {#proxyForm-name}

必須で、プロジェクト内で一意です。リポジトリとインベントリはこの名前でプロキシを表示します。

## タイプ {#proxyForm-type}

- **SSH (jump host)**: Semaphore がホストに SSH で接続し、そこからサーバーへの接続を開きます。
  別のプロキシを必要とできるのはこのタイプだけです。
- **SOCKS5**、**HTTP**、**HTTPS**: 接続を中継するプロキシサーバーです。`https` のリポジトリでは
  Git が自身で使い、SSH 接続は Semaphore がこれを経由させるため、他のツールのインストールは
  不要です。

## Host {#proxyForm-host}

必須。ホスト名または IP アドレスで、ユーザー、ポート、スキームは含めません。ホスト名に使えるのは
英字、数字、ドット、ハイフン、アンダースコアだけです。

## Port {#proxyForm-port}

任意、1 から 65535。空の場合、SSH ジャンプホストでは `22` です。他のタイプではポートを指定して
ください。指定しないと Git と SSH 接続が異なるポートを想定します。

## User {#proxyForm-user}

SSH のみ: ジャンプホストのログイン名です。空の場合は Semaphore を実行しているユーザーです。
英字、数字、ドット、ハイフン、アンダースコアで、先頭にハイフンは使えません。SOCKS5 や HTTP の
プロキシは代わりに **アクセスキー** からログイン名を取ります。

## アクセスキー {#proxyForm-sshKeyId}

任意。プロキシ自体へのログインに使うキーストアのキーで、通常はその先のサーバーのキーとは
別のものです:

- SSH ジャンプホストには **SSHキー**;
- SOCKS5、HTTP、HTTPS には **パスワードでログイン**。パスワードは環境変数で渡され、コマンドラインには
  出ません。

## Requires Proxy {#proxyForm-requiresProxyId}

SSH のみ、任意。先に経由する、プロジェクトの別の SSH プロキシです。別のジャンプホストからしか
到達できないジャンプホストに使います。チェーンは最大 5 個のプロキシで、すでに含まれるプロキシに
戻ることはできません。
