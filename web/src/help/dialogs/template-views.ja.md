# ビューを編集

ビューは、タスクテンプレートの一覧の上にあるタブです。ビューには、そのビューに入れたテンプレート、またはプロジェクトのすべてのテンプレートが表示されます。このダイアログはすべての変更をすぐに保存します。ダイアログ全体の保存ボタンはありません。タブの順序を変更するには、ビューをハンドルでドラッグします。

## タイトル {#viewsForm-title}

タブの名前です。入力し、フィールドの横のチェックマークで確定します。バツ印は保存されているタイトルに戻します。新しいビューは、タイトルがあり、それを確定するか設定のいずれかを変更すると保存されます。ダイアログを閉じても、確定していないタイトルは保存されません。

歯車は、タイトルの下にビューの設定を開きます。

## 削除 {#viewsForm-viewDelete}

ごみ箱のアイコンは、確認なしですぐにビューを削除します。ビューのテンプレートは削除されません。プロジェクトに残り、どのビューにも属さなくなります。

## Type {#viewsForm-type}

タブに表示されるテンプレートです。

- **Custom**: テンプレートのダイアログの **ビュー** フィールドでこのビューが指定されているテンプレートです。これがデフォルトです。
- **All**: ビューに関係なく、プロジェクトのすべてのテンプレートです。

メンバーには、どのビューでも、そのメンバーが表示できるテンプレートだけが表示されます。

## Sort by {#viewsForm-sortColumn}

タブのテンプレートを並べ替える列です。使えるのは **Name** だけです。これがないタブも名前で並べ替えられるため、このフィールドは **Reverse** と組み合わせて意味を持ちます。

## Reverse {#viewsForm-sortReverse}

タブを降順に並べ替えます。**Sort by** が設定されている場合にのみ機能します。

## Hidden {#viewsForm-hidden}

プロジェクトのリソースを管理できないメンバーからタブを隠します。管理できるメンバーには、取り消し線付きで引き続き表示されます。タブを隠しても、そのテンプレートは隠れません。**All** タイプのビューには引き続き一覧表示されます。

## ビューを追加 {#viewsForm-add}

一覧の末尾に、タイトルが空のビューを追加します。タイトルを入力してください。
