# Змінна опитування

Змінна опитування — це запитання, яке діалог завдання ставить щоразу, коли ви запускаєте шаблон.
Відповідь потрапляє в завдання як змінна: додаткова змінна для Ansible, `-var` для Terraform і
OpenTofu, аргумент для скрипта або змінна середовища. Змінна зберігається разом із шаблоном, коли
ви зберігаєте діалог шаблону. Той самий діалог редагує опитування workflow, де тип **Secret** не
пропонується.

## Ім’я {#surveyVarDialog-name}

Ім’я, під яким завдання отримує відповідь: ім’я додаткової змінної, змінної Terraform, аргументу
`name=value` скрипта або змінної середовища. Пробіли на кінцях відкидаються. Поле обов’язкове.

Використовуйте ім’я, якого немає в жодної іншої змінної опитування і яке приймає інструмент,
наприклад `app_version`. Відповідь замінює змінну з таким самим ім’ям із групи змінних шаблону.

## Заголовок {#surveyVarDialog-title}

Підпис поля в діалозі завдання, наприклад `Version to deploy`. Це також текст чипа змінної в
діалозі шаблону. Поле обов’язкове.

## Опис {#surveyVarDialog-description}

Необов’язкове поле. Підказка, яка показується під полем діалогу завдання, поки воно у фокусі: що
вводити або приклад.

## Тип {#surveyVarDialog-type}

Який вид відповіді запитує діалог завдання:

- **String**: один рядок тексту. Це значення за замовчуванням.
- **Integer**: лише цифри; діалог завдання відхиляє все інше, зокрема знак мінус. Відповідь
  однаково потрапляє в завдання як текст: перетворіть її в playbook, наприклад за допомогою
  `| int`.
- **Secret**: текст, який діалог завдання маскує. Відповідь не зберігається із завданням, тож
  повторний запуск запитує її знову, а Ansible отримує її у файлі, зашифрованому vault. Секрет не
  має значення за замовчуванням.
- **Enum**: одне значення, вибране зі списку, який ви визначаєте нижче.
- **Text**: кілька рядків тексту.
- **Select**: кілька значень, вибраних зі списку, який ви визначаєте нижче. Завдання отримує їх
  як список; в аргументі, `-var` або змінній середовища список записується як JSON, наприклад
  `["a","b"]`.

Зміна типу очищає значення за замовчуванням, а тип без списку очищає значення.

## Pass variable as {#surveyVarDialog-target}

Як відповідь потрапляє в завдання:

- **Extra variable**: звичайний спосіб для інструмента. Ansible отримує її як додаткову змінну,
  Terraform і OpenTofu — як `-var name=value`, скрипт Bash, PowerShell або Python — як аргумент
  `name=value` після скрипта.
- **Environment variable**: змінна середовища процесу, `name=value`, для будь-якого виду шаблону.
  Тоді змінна не передається іншим способом.

## Ключ {#surveyVarDialog-valueName}

Відображається, коли вибрано тип **Enum** або **Select**.

Текст, який діалог завдання показує для цього значення у списку. Кожному значенню потрібен ключ,
і ключі мають відрізнятися: інакше діалог відмовляється зберігати змінну.

## Значення {#surveyVarDialog-valueValue}

Відображається, коли вибрано тип **Enum** або **Select**.

Що отримує завдання, коли вибрано це значення. Воно може відрізнятися від свого ключа: ключ
`Production` може передавати `prod`.

## Add Value {#surveyVarDialog-addValue}

Відображається, коли вибрано тип **Enum** або **Select**.

Додає порожній рядок до списку значень. **Enum** або **Select** потребує принаймні одного
значення. Іконка кошика в рядку видаляє його.

## Значення за замовчуванням {#surveyVarDialog-defaultValue}

Відображається для всіх типів, крім **Secret**.

Відповідь, яку діалог завдання заповнює під час відкриття; там її можна змінити. Для **Enum**
виберіть одне зі значень, для **Select** — будь-яку їх кількість. Залиште поле порожнім, щоб
почати з порожньої відповіді.

Значення за замовчуванням заповнює лише діалог завдання. Завдання, запущене іншим способом,
наприклад через API, значення за замовчуванням не отримує.

## Обов’язково {#surveyVarDialog-required}

Діалог завдання не запускає завдання, доки змінна не має відповіді. Як і значення за
замовчуванням, цю перевірку виконує лише діалог завдання, а не сервер.
