# New Token

API-токен позволяет скрипту или другому сервису обращаться к API Semaphore от вашего имени, с
теми же правами, что и у вашей учетной записи. Передавайте его в заголовке `Authorization`
запроса: `Bearer` и токен. Токен показывается один раз, сразу после создания: скопируйте его
тогда же.

## Token Name {#token-name}

Необязательное поле. Имя, по которому токен можно отличить в списке токенов, например имя
скрипта, который его использует. Оно не является частью токена и не меняет того, что токен может
делать.

## Expires {#token-expires}

Когда токен перестает работать. Выберите период, отсчитываемый от текущего момента, **Never** для
токена, который работает до удаления, или **Custom**, чтобы самостоятельно выбрать момент.

Токен без срока действия работает, пока вы не удалите его из списка. Для токена, который
передается скрипту или другому сервису, лучше выбрать период.

## Expiration date {#token-expiresAt}

Показывается, когда в поле **Expires** выбрано **Custom**.

Дата и время, когда токен перестает работать, в часовом поясе вашего браузера. Момент должен быть
в будущем: сервер отклоняет токен, срок действия которого уже истек бы.
