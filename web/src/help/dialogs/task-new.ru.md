# Новая задача

Запускает задачу шаблона: одно выполнение его плейбука, кода Terraform или скрипта. Шаблон
определяет, какие поля показывает этот диалог, и в каждом разделе ниже сказано, когда его поле
есть в диалоге. Кнопка внизу называется **Запуск**, **Сборка** или **Развертывание** в
зависимости от типа шаблона.

Если у шаблона есть опрос, его вопросы — это поля после поля **Сообщение**. Поле, отмеченное `*`,
обязательное, поле Integer принимает только цифры, а ответы по умолчанию уже заполнены. Semaphore
передает ответы задаче как переменные: extra vars для Ansible, `-var` для Terraform, аргументы
`name=value` для скрипта или переменные окружения для вопроса, настроенного таким образом. Ответ
заменяет переменную с тем же именем в группах переменных шаблона. Секретный ответ скрывается при
вводе и не сохраняется вместе с задачей.

## Коммит {#newTask-commit}

Показывается, когда вы повторно запускаете более раннюю задачу и эта задача выполнялась на
известном коммите.

Задача извлекает этот коммит репозитория вместо самого нового коммита ветки. Закройте этот блок,
чтобы запустить самый новый коммит.

Коммит используется, только если шаблон разрешает переопределять ветку, и никогда — для
репозитория, отмеченного как монорепозиторий. В остальных случаях задача выполняет самый новый
коммит.

## Версия сборки {#newTask-buildTaskId}

Показывается, когда тип шаблона — **Развертывание**.

Сборка для развертывания: одна из 20 последних успешных задач шаблона сборки, перечисленных по
версии и сообщению. Выбрана самая новая. Поле обязательное.

Версия сборки доходит до задачи: как `semaphore_vars.task_details.incoming_version` в Ansible, как
переменная окружения `SEMAPHORE_TASK_DETAILS_INCOMING_VERSION` в скрипте. Список пуст, если вам
не разрешено видеть шаблон сборки.

## Сообщение {#newTask-message}

Необязательное поле. Заметка о том, зачем выполняется задача, например
`Hotfix for the login page`. Она показывается вместе с задачей в истории задач и ничего не меняет в выполнении.

Плейбук может прочитать ее как `semaphore_vars.task_details.message`, а скрипт — как переменную
окружения `SEMAPHORE_TASK_DETAILS_MESSAGE`.

## Ветка {#newTask-gitBranch}

Показывается, когда шаблон разрешает переопределять ветку, если только репозиторий не является
монорепозиторием.

Ветка или тег репозитория, которые извлекает задача. Изначально в поле указана ветка шаблона.
Если поле пустое, задача использует ветку шаблона, а если у шаблона ее нет — ветку репозитория.
Имя, которое не является допустимым именем ветки Git, отклоняется.

## Инвентарь {#newTask-inventoryId}

Показывается, когда шаблон разрешает выбирать инвентарь в задаче и вам разрешено видеть проект.
Для шаблона Terraform, OpenTofu или Terragrunt поле называется **Workspace**, но сервер использует
выбор только для шаблонов Ansible: задача Terraform, OpenTofu или Terragrunt выполняется в
workspace шаблона, что бы вы здесь ни выбрали.

Инвентарь, с которым выполняется задача. Изначально в поле указан инвентарь шаблона, а в списке —
инвентари проекта, созданные для приложения шаблона. Если к моменту запуска задачи выбранного
инвентаря уже нет, задача выполняется с инвентарем шаблона.

## Лимит {#taskParams-limit}

Показывается для шаблона Ansible, который разрешает переопределять лимит.

Хосты или группы инвентаря, на которых выполняется плейбук, по одному шаблону на элемент, например
`web` или `10.0.0.11`. Semaphore передает их как `--limit` через запятую. Изначально в списке
указан лимит шаблона. Удалите все элементы, чтобы выполнить плейбук на всех хостах инвентаря.

## Теги {#taskParams-tags}

Показывается для шаблона Ansible, который разрешает переопределять теги.

Выполняются только задачи и роли плейбука с одним из этих тегов: Semaphore передает их как
`--tags`, по одному тегу на элемент. Изначально в списке указаны теги шаблона. Удалите все
элементы, чтобы выполнить весь плейбук.

## Пропустить теги {#taskParams-skipTags}

Показывается для шаблона Ansible, который разрешает переопределять пропускаемые теги.

Задачи и роли плейбука с одним из этих тегов не выполняются: Semaphore передает их как
`--skip-tags`, по одному тегу на элемент. Изначально в списке указаны пропускаемые теги шаблона.

## Отладка {#taskParams-debug}

Показывается для шаблона Ansible, который разрешает отладку.

Запускает `ansible-playbook` с флагом подробности, чтобы лог задачи показывал больше деталей.
Подпись показывает флаг: `-v` столько раз, сколько указывает **Уровень отладки**.

## Уровень отладки {#taskParams-debugLevel}

Показывается вместе с **Отладка** и становится доступен, когда установлен флажок **Отладка**.

Насколько подробен лог, от 1 (`-v`) до 6 (`-vvvvvv`). По умолчанию 4 (`-vvvv`): при этом
показываются и подробности подключений к хостам.

## Пробный запуск {#taskParams-dryRun}

Показывается для шаблона Ansible, если шаблон его не скрывает.

Запускает плейбук с `--check`: Ansible сообщает, что он изменил бы на хостах, и ничего не меняет.

## Различия {#taskParams-diff}

Показывается для шаблона Ansible, если шаблон его не скрывает.

Запускает плейбук с `--diff`: лог показывает изменения, внесенные в файлы и шаблоны на хостах.
Установите также флажок **Пробный запуск**, чтобы увидеть изменения, не внося их.

## Пропустить установку Galaxy {#taskParams-skipGalaxyInstall}

Показывается для шаблона Ansible, который разрешает переопределять установку Galaxy.

Перед запуском плейбука Semaphore устанавливает роли и коллекции, перечисленные в файлах
`requirements.yml` репозитория, если файл изменился с последней установки. Установите флажок,
чтобы пропустить этот шаг для этой задачи.

Изначально флажок снят, что бы ни было задано в шаблоне, а снятый флажок устанавливает
зависимости.

## Plan {#taskParams-plan}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Выполняет `plan` и на этом завершает задачу: ничего не применяется. Используйте это, чтобы сначала
просмотреть изменения. Без этого флажка задача переходит к применению плана, если в нем есть
изменения.

## Destroy {#taskParams-destroy}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Добавляет `-destroy` к `plan` и `apply`: задача планирует, а затем применяет удаление всех
ресурсов в состоянии workspace. Установите также флажок **Plan**, чтобы увидеть, что было бы
уничтожено, ничего не уничтожая.

## Auto Approve {#taskParams-autoApprove}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Применяет план сразу после его создания. Без этого флажка задача останавливается после плана и
ждет, пока кто-нибудь не подтвердит или не отклонит ее на странице задачи.

Флажок действует, только если шаблон разрешает автоматическое одобрение. Шаблон, настроенный
всегда одобрять, применяет план без вопросов, что бы ни показывал флажок.

## Upgrade {#taskParams-upgrade}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Выполняет `init` с `-upgrade`: провайдеры и модули обновляются до самых новых версий, которые
допускают их ограничения версий.

## Reconfigure {#taskParams-reconfigure}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Выполняет `init` с `-reconfigure`: backend настраивается заново, а сохраненная конфигурация
backend игнорируется. Без этого флажка Semaphore выполняет `init -migrate-state`, который
переносит существующее состояние в измененный backend.

## CLI args {#newTask-args}

Показывается, когда шаблон разрешает переопределять аргументы командной строки.

Дополнительные аргументы для командной строки задачи, по одному на элемент: `--forks=10` — это
один элемент, `--forks` и `10` — два. Нажмите на элемент, чтобы изменить его, перетащите его,
чтобы изменить порядок, а последний элемент используйте, чтобы добавить новый.

Изначально в списке указаны аргументы шаблона. Semaphore всегда передает аргументы шаблона и
добавляет этот список после них, поэтому, как только вы измените список, оставшиеся в нем
аргументы шаблона передаются дважды. Удалите их и оставьте только те аргументы, которые вы
добавляете.
