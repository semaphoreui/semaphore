# Edit Global Role

全局角色向被分配该角色的用户授予针对整个 Semaphore 实例的权限；您可以在用户的对话框中分配它。它不提供项目内部的访问权限：
项目内部的访问权限只来自用户作为项目成员所持有的角色。无论分配了哪些角色，管理员都拥有所有全局权限。全局角色是 Pro 功能。

## 名称 {#globalRole-name}

角色在用户页面的全局角色标签页以及用户对话框中显示的名称。此字段为必填项。您可以随时重命名角色。

## Slug {#globalRole-slug}

角色的标识符。在您输入名称时，Semaphore 会根据名称自动填写它，直到您亲自编辑 slug 为止。它由 1 到 100
个字母、数字、下划线和连字符组成，例如 `user-admins`。

slug 在全局角色中必须唯一；项目角色可以使用相同的 slug。角色保存之后就无法更改 slug：编辑角色时此字段处于锁定状态。

## Global permissions {#globalRole-permissionsTitle}

持有该角色的用户可以在整个实例范围内执行的操作。新角色不勾选任何权限。用户所有全局角色的权限会累加。

- **Can manage users**：创建用户、更改和删除用户，并在用户列表中查看其详细信息。这样的用户不能将某个用户设为管理员或
  Pro 用户，也不能更改或删除管理员，或者持有其自身不具备的全局权限的用户。
- **Can manage global roles**：创建、更改和删除全局角色以及共享的项目角色，并决定哪些用户持有哪个全局角色。
  只将此权限授予您可以托付整个实例的人员。
- **Can manage system settings**：更改实例的设置、应用、全局运行器和组映射；查看集群以及服务器的信息；
  查看和删除所有项目的任务；清除服务器的缓存。
- **Can read the audit log**：读取实例的审计日志并将其导出。
