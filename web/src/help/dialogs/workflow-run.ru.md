# Run Workflow

Запускает выполнение workflow после того, как вы ответили на его опрос. Диалог открывается только
для workflow с опросом: workflow без опроса запускается сразу. После нажатия **Запуск** открывается
страница нового выполнения; если сервер отклоняет значения, диалог остается открытым с вашими
ответами.

## Переменные {#workflowRunDialog-survey}

По одному полю на каждую переменную опроса workflow, в порядке опроса, с заполненным значением по
умолчанию. Поле, отмеченное `*`, обязательное, поле Integer принимает только цифры, а поле списка
принимает одно значение или, если переменная допускает несколько, любое их количество. **Запуск**
ничего не запускает, пока все поля не будут заполнены правильно.

Значения сохраняются вместе с выполнением и показываются на его странице в разделе **Variables**.
Задача workflow не получает их сама по себе: переменная ее шаблона получает значение, только если
ее узел привязывает ее к переменной workflow. Одно лишь совпадение имени ничего не передает.

Опрос workflow не содержит секретов, потому что выполнение хранит свои значения в открытом виде.
Вместо этого храните пароли и токены в ключе или группе переменных.
