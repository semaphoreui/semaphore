# Редактировать группу

Группа хостов управляемого инвентаря. Плейбук выполняется на части хостов по имени группы, а
переменная группы задается один раз для всех ее хостов. Хосты добавляются в группу на вкладке Hosts,
в диалоге хоста или действиями над отмеченными хостами.

## Имя {#inventoryGroupForm-name}

Имя, под которым Ansible знает группу, например в `hosts: web` плейбука. Поле обязательное. Имя
уникально в пределах инвентаря, регистр букв различается: `web` и `Web` — это две группы. Имя не
может содержать пробелы, запятые, квадратные скобки и двоеточия, его длина не больше 250 символов, и
оно не может быть `all` или `ungrouped`. Ansible предупреждает об именах с символами кроме букв,
цифр и подчеркивания, например `web-eu`, но такое имя все равно работает.

## Описание {#inventoryGroupForm-description}

Необязательное поле. Заметка для людей, она видна в списке групп. Ansible ее не получает.

## Child groups {#inventoryGroupForm-children}

Необязательное поле. Группы внутри этой группы. Хосты дочерней группы тоже принадлежат этой группе.
Группа не может быть собственным предком.

## Переменные {#inventoryGroupForm-variables}

Необязательное поле. Переменные этой группы, записанные как словарь YAML или JSON:

```yaml
http_port: 8080
ntp_server: ntp.example.com
```

Их получает каждый хост группы. Переменная хоста имеет приоритет над переменной группы с тем же
именем, а переменная группы — над переменной инвентаря. Якоря, ссылки и ключи слияния YAML не
принимаются.
