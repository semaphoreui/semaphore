# 보기 수정

보기는 작업 템플릿 목록 위에 있는 탭입니다. 보기는 그 안에 넣은 템플릿이나 프로젝트의 모든 템플릿을 보여 줍니다.
이 대화 상자는 모든 변경을 즉시 저장하므로, 대화 상자 전체에 대한 저장 버튼은 없습니다. 탭의 순서를 바꾸려면
핸들을 잡고 보기를 끌어다 놓으세요.

## 제목 {#viewsForm-title}

탭의 이름입니다. 입력한 다음 필드 옆의 체크 표시로 확정하세요. X 표시는 저장된 제목으로 되돌립니다. 새 보기는
제목이 있고 그것을 확정하거나 설정 중 하나를 변경하면 저장됩니다. 대화 상자를 닫아도 확정하지 않은 제목은
저장되지 않습니다.

톱니바퀴를 누르면 제목 아래에 보기의 설정이 열립니다.

## 삭제 {#viewsForm-viewDelete}

휴지통 아이콘은 묻지 않고 즉시 보기를 삭제합니다. 보기의 템플릿은 삭제되지 않습니다. 템플릿은 프로젝트에 남으며
더 이상 어떤 보기에도 속하지 않습니다.

## Type {#viewsForm-type}

탭이 보여 주는 템플릿입니다.

- **Custom**: 템플릿 대화 상자의 **보기** 필드에 이 보기가 지정된 템플릿입니다. 기본값입니다.
- **All**: 보기와 관계없이 프로젝트의 모든 템플릿입니다.

멤버는 어떤 보기에서든 자신이 볼 수 있는 템플릿만 봅니다.

## Sort by {#viewsForm-sortColumn}

탭의 템플릿을 정렬하는 열로, **Name**이 유일한 열입니다. 이 설정이 없는 탭도 이름순으로 정렬되므로, 이 필드는
**Reverse**와 함께 쓸 때 의미가 있습니다.

## Reverse {#viewsForm-sortReverse}

탭을 내림차순으로 정렬합니다. **Sort by**가 설정되어 있을 때만 작동합니다.

## Hidden {#viewsForm-hidden}

프로젝트 리소스를 관리할 수 없는 멤버에게서 탭을 숨깁니다. 관리할 수 있는 멤버에게는 취소선이 그어진 채로
보입니다. 탭을 숨겨도 그 템플릿은 숨겨지지 않습니다. **All** 유형의 보기에는 여전히 표시됩니다.

## 보기 추가 {#viewsForm-add}

목록 끝에 제목을 입력할 수 있는 빈 보기를 추가합니다.
