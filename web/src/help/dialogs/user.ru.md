# Редактировать пользователя

Пользователь — это учетная запись, с которой входят в Semaphore. Вкладка **Settings** содержит
профиль учетной записи и ее флажки; **Сохранить** записывает их. Вкладка **Security** содержит
пароль, двухфакторную аутентификацию и связанные учетные записи для входа, а вкладка **Roles** —
глобальные роли пользователя: обе действуют сразу, без **Сохранить**. Что пользователь может
делать внутри проекта, задается на странице **Команда** этого проекта, а не здесь.

## Имя {#user-name}

Полное имя пользователя, которое показывается на боковой панели и в списках пользователей и
участников проекта. Поле обязательное.

Для пользователя с флажком **Внешний** Semaphore берет имя у провайдера удостоверений при входе,
если провайдер его передает, поэтому изменение, сделанное здесь, может не сохраниться после
следующего входа.

## Имя пользователя {#user-username}

Логин пользователя. Поле обязательное. Пользователь входит с именем пользователя или адресом
электронной почты и паролем.

Имя пользователя с флажком **Внешний** нельзя изменить: сервер отказывается его сохранять.

## Электронная почта {#user-email}

Адрес электронной почты пользователя. Поле обязательное. Semaphore отправляет на него оповещения
о задачах пользователя, а приложение-аутентификатор показывает его как имя учетной записи. Адрес
закрытый: его видят только сам пользователь и те, кто может управлять пользователями.

Для пользователя с флажком **Внешний** адрес приходит от провайдера удостоверений: поле доступно
только для чтения, и Semaphore обновляет адрес при каждом входе.

## Пароль {#user-password}

Показывается при создании нового пользователя.

Пароль, с которым входит пользователь. Поле обязательное, кроме пользователя с флажком
**Внешний**, у которого нет пароля в Semaphore. Чтобы изменить пароль существующего пользователя,
используйте **Change password** на вкладке **Security**.

## Отправить оповещения {#user-alert}

Отправляет пользователю письмо, когда задача завершается с ошибкой в проекте, где пользователь
может видеть задачу. Проект должен разрешать оповещения, а администратор сервера должен включить
оповещения по электронной почте. Шаблон задачи может запретить своим неудачным задачам отправлять
оповещения.

Флажок не влияет на оповещения проекта, отправляемые в Telegram, Slack и другие мессенджеры.

## Администратор {#user-admin}

Показывается, если вы администратор.

Администратор может делать на сервере все: управлять пользователями, глобальными ролями и
настройками сервера и открывать любой проект с полными правами.

Снять флажок со своей собственной учетной записи нельзя, а на сервере всегда остается хотя бы
один администратор: сервер отказывается снимать флажок с последнего.

## Pro user {#user-pro}

Показывается в версии Pro. Изменить флажок может только администратор.

Выдает пользователю место в подписке Pro. В подписке фиксированное количество пользователей Pro:
когда оно исчерпано, сервер отказывается сохранять флажок. Без активной подписки флажок ни на что
не влияет.

## Внешний {#user-external}

Показывается, если вы администратор. Флажок можно установить только при создании пользователя.

Внешний пользователь входит через LDAP или OpenID Connect, а не с паролем Semaphore: поле пароля
недоступно, а вход с паролем отклоняется. Имя и адрес электронной почты берутся у провайдера
удостоверений при каждом входе. Оставьте флажок снятым для пользователя, который входит с
паролем.

## Change password {#user-changePassword}

Показывается на вкладке **Security** существующего пользователя, у которого не установлен флажок
**Внешний**, если сервер разрешает вход с паролем.

Открывает диалог, который задает новый пароль. Чтобы изменить свой собственный пароль, нужно
указать текущий; чтобы сбросить пароль другого пользователя, этого не нужно.

## Time-based one-time password {#user-totp}

Показывается на вкладке **Security**, если администратор включил двухфакторную аутентификацию для
сервера.

Включает двухфакторную аутентификацию для этого пользователя. Когда вы включаете переключатель,
Semaphore сразу создает секрет и показывает его в виде QR-кода: отсканируйте его
приложением-аутентификатором. С этого момента при входе после пароля запрашивается код из
приложения.

Если сервер разрешает восстановление, под QR-кодом показывается код восстановления. Он
показывается только один раз: скопируйте его и храните в надежном месте. Выключение
переключателя сразу удаляет секрет.

## LDAP provider {#user-ldapProvider}

Показывается на вкладке **Security** вашей собственной учетной записи, если на сервере есть
провайдер LDAP, с которым ваша учетная запись еще не связана.

Сервер LDAP, с которым нужно связать вашу учетную запись, если их несколько.

## LDAP username {#user-ldapUsername}

Показывается вместе с **LDAP provider**.

Ваше имя пользователя на сервере LDAP. Связывание позволяет входить в эту учетную запись также
через LDAP.

## LDAP password {#user-ldapPassword}

Показывается вместе с **LDAP provider**.

Ваш пароль на сервере LDAP. Semaphore использует его один раз, чтобы проверить, что учетная
запись LDAP принадлежит вам, и не сохраняет его.

## Link {#user-ldapLink}

Показывается вместе с **LDAP provider**.

Связывает вашу учетную запись с учетной записью LDAP, указанной выше. Связывание отклоняется,
если учетные данные неверны, если учетная запись LDAP связана с другим пользователем или если ваша
учетная запись уже связана с этим провайдером. Связанная учетная запись появляется в разделе
**Linked accounts**; закройте ее метку, чтобы отменить связь.

## Global role {#global-role-select}

Показывается на вкладке **Roles** существующего пользователя в версии Pro, если вы можете
управлять глобальными ролями.

Глобальная роль, которую нужно выдать пользователю, из тех ролей, которых у него еще нет.
Глобальная роль дает права на весь сервер: управлять пользователями, глобальными ролями или
настройками сервера или читать журнал аудита. Сами глобальные роли создаются на вкладке
**Глобальные роли** страницы «Пользователи».

## Assign {#globalRoleAssign-assign}

Показывается вместе с **Global role**.

Сразу выдает пользователю выбранную роль. Роли, которые есть у пользователя, перечислены ниже,
у каждой есть кнопка, чтобы ее отобрать. **Effective global permissions** показывает, что в итоге
может делать пользователь и откуда берется каждое право.
