# Edit mapping

Зіставлення вказує Semaphore, які облікові дані зі «Сховища ключів» використовувати для SSH-хоста
або Git-URL. Репозиторій має один ключ, але завдання може звертатися й до інших серверів:
субмодулів, ролей і колекцій із `requirements.yml`, модулів Terraform, репозиторіїв інвентарю.
Зіставлення проєкту застосовуються до кожного Git- і SSH-з’єднання його завдань, а також до
команд Git, які Semaphore виконує для проєкту, наприклад до перевірки репозиторію на нові коміти.
Жоден файл вашого репозиторію не змінюється.

## Тип {#hostConfigForm-type}

З чим зіставляється зіставлення:

- **Host**: ім’я SSH-хоста. Кожне SSH-з’єднання завдання з цим хостом використовує ключ
  зіставлення: Git через SSH, а також Ansible, що під’єднується до хоста інвентарю з цим ім’ям.
  Зіставлення має пріоритет над конфігурацією SSH сервера для того самого хоста.
- **URL**: Git-URL або його початок. Git під’єднується до кожного репозиторію під цим URL з
  обліковими даними зіставлення.

Перемикання на **Host** очищає поле **Credential**, якщо в ньому вибрано ключ, який зіставлення
хоста не може використовувати.

## Host або URL {#hostConfigForm-host}

Поле обов’язкове. Для кожного хоста або URL може існувати одне зіставлення кожного типу.

Для **Host**: ім’я хоста точно так, як Git або Ansible до нього під’єднуються, наприклад
`github.com` або `10.0.0.21`. Лише літери, цифри, крапки, дефіси і знаки підкреслення: без
користувача, без порту, без шаблонів.

Для **URL**: адреса, що починається з `https://` або `http://`, без логіна в ній і без пробілів,
лапок або `=`. Вкажіть цілий репозиторій або префікс, що закінчується на `/`, щоб охопити групу
репозиторіїв:

```
https://github.com/acme/
https://github.com/acme/infra.git
```

Коли збігається кілька зіставлень, перемагає найдовше: зіставлення репозиторію вище перевизначає
зіставлення `acme` для цього одного репозиторію.

З SSH-ключем зіставлення URL змушує Git під’єднуватися через SSH до хоста з URL на порт `22`,
незалежно від того, який порт указано в URL.

## Credential {#hostConfigForm-sshKeyId}

Ключ зі «Сховища ключів», який використовується для з’єднань, що відповідають зіставленню. Поле
обов’язкове.

- **Host** приймає лише **SSH-ключ**. Якщо ключ має логін, SSH під’єднується від імені цього
  користувача.
- **URL** приймає **SSH-ключ** або **Логін з паролем**. SSH-ключ під’єднується зі своїм логіном
  або як `git`, якщо логіна немає. Логін з паролем працює лише з URL `https://`; для токена
  вкажіть токен як пароль, а логін залиште порожнім.

Логін з паролем передається Git через його оточення, а не через командний рядок, і лог завдання
показує лише початковий URL.
