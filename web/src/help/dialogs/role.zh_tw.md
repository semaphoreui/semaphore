# 編輯角色

角色是專案內一組具名的權限。您將角色授予專案的成員，成員可以執行其任一角色所允許的操作。從專案的「角色」頁面開啟時，
此對話方塊只編輯該專案的角色；從專案之外的「角色」頁面開啟時，它編輯的是每個專案都可以使用的共用角色。內建角色 Owner、
Manager、Task Runner 和 Guest 無法變更。

## 名稱 {#role-name}

角色在「角色」頁面以及任何選擇角色的地方（例如將成員加入專案時）顯示的名稱。此欄位為必填。您可以隨時重新命名角色。

## Slug {#role-slug}

角色的識別碼。在您輸入名稱時，Semaphore 會根據名稱自動填入，直到您自行編輯 Slug 為止。它由 1 到 100 個字母、數字、
底線和連字號組成，例如 `release-managers`。

角色儲存後，Slug 就無法再變更：編輯角色時此欄位會被鎖定。

- Slug 必須是唯一的，檢查時不區分字母大小寫。共用角色的 Slug 必須與其他所有角色不同；專案角色的 Slug 必須與共用角色以及其專案的其他角色不同。
- `owner`、`manager`、`task_runner`、`guest` 和 `all` 為保留字，不論大小寫。

## 權限 {#role-permissionsTitle}

擁有此角色的成員在專案中可以執行的操作。新角色預設不勾選任何權限。成員所擁有之所有角色的權限會累加；無論角色為何，Semaphore
的管理員都可以在每個專案中執行任何操作。

- **Can read project**：檢視專案：其任務範本、任務及其日誌、清單、金鑰、儲存庫、變數群組、排程和成員。專案中的每一項讀取都需要此權限，
  而且沒有其他權限包含它，因此幾乎每個角色都應勾選它。沒有此權限時，成員只能看到本身授予該角色存取權的任務範本和工作流程，以及它們的任務。
- **可執行專案任務**：從任務範本啟動任務、停止任務，以及確認或拒絕等待確認的任務。
- **可更新專案**：變更專案的設定以及刪除專案。
- **可管理專案資源**：建立、修改及刪除任務範本、清單、金鑰、儲存庫、變數群組、排程、檢視、整合、密鑰儲存區、專案執行器和專案的角色；
  刪除任務；設定哪些角色可以使用某個任務範本。
- **可管理專案使用者**：將成員加入專案、變更其角色以及移除成員。
- **Can run workflows**：啟動工作流程並停止其執行。
- **Can edit workflows**：建立、修改及刪除工作流程，並設定哪些角色可以使用某個工作流程。
- **Can approve workflows**：核准或拒絕工作流程執行中等待核准的步驟。
