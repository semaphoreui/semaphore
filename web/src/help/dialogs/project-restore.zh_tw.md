# 還原專案...

從備份檔案建立一個新專案，該備份檔案是透過某個專案「設定」頁面上的**備份專案**所產生的。新專案會取得備份中設定的任務範本、清單、儲存庫、
變數群組、金鑰、排程、整合及其他項目，而您會成為它的擁有者。只有管理員可以還原專案，除非伺服器的管理員允許所有使用者建立專案。

## 專案名稱 {#restoreProject-name}

新專案的名稱。此欄位為必填，它會取代備份檔案中所寫的名稱。

此名稱必須與伺服器上所有專案的名稱都不同：伺服器會拒絕以已被使用的名稱還原專案。

## 備份檔案 {#restoreProject-file}

備份的 JSON 檔案。請在按下 **Restore** 之前選取檔案。

備份不包含金鑰的機密值，以及變數群組 **Secrets** 分頁中的機密值：還原之後，Semaphore 會告訴您有多少把金鑰是空的，需要重新輸入其機密值，變數群組的機密值也必須重新輸入。直接輸入到其他欄位中的密碼，例如儲存庫位址中的密碼，會依檔案中的原樣還原。
專案的成員及其任務歷史不包含在備份中。由較新版本的 Semaphore 所產生的備份會被拒絕。
