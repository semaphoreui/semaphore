# 編輯使用者

使用者是登入 Semaphore 的帳號。**Settings** 分頁包含帳號的個人資料及其旗標；**儲存**會寫入它們。**Security**
分頁包含密碼、雙重驗證和已連結的登入帳號，**Roles** 分頁則包含使用者的全域角色：這兩個分頁的操作都會立即生效，不需要**儲存**。
使用者在專案內可以執行的操作，是在該專案的**團隊**頁面上設定，而不是在這裡。

## 名稱 {#user-name}

使用者的全名，顯示在側邊欄，以及使用者清單和專案成員清單中。此欄位為必填。

對於**外部**使用者，若身分提供者在登入時傳送了名稱，Semaphore 會從身分提供者取得名稱，因此在此所做的變更，可能在下次登入後就不再保留。

## 使用者名稱 {#user-username}

使用者的登入名稱。此欄位為必填。使用者以使用者名稱或電子郵件，加上密碼登入。

**外部**使用者的使用者名稱無法變更：伺服器會拒絕儲存。

## 電子郵件 {#user-email}

使用者的電子郵件地址。此欄位為必填。Semaphore 會將使用者的任務警報寄到此地址，驗證器應用程式也會將它顯示為帳號名稱。
它是私人資訊：只有使用者本人以及可以管理使用者的人才能看到它。

對於**外部**使用者，電子郵件來自身分提供者：此欄位為唯讀，Semaphore 會在每次登入時更新此地址。

## 密碼 {#user-password}

在建立新使用者時顯示。

使用者登入時所用的密碼。此欄位為必填，但**外部**使用者除外，他們在 Semaphore 中沒有密碼。若要更改現有使用者的密碼，請使用
**Security** 分頁上的 **Change password**。

## 發送警報 {#user-alert}

當使用者可以檢視的專案中有任務失敗時，寄送電子郵件給該使用者。該專案必須允許警報，且伺服器的管理員必須已開啟電子郵件警報。
任務範本可以讓其失敗的任務不發送警報。

此旗標不會影響專案傳送到 Telegram、Slack 及其他通訊軟體的警報。

## 管理員使用者 {#user-admin}

在您是管理員時顯示。

管理員可以在伺服器上執行任何操作：管理使用者、全域角色和伺服器的設定，並以完整權限開啟每個專案。

您無法移除自己帳號的此旗標，而且伺服器至少會保留一位管理員：它會拒絕移除最後一位管理員的此旗標。

## Pro user {#user-pro}

在 Pro 版本中顯示。只有管理員可以變更此旗標。

為使用者提供 Pro 訂閱的一個席位。訂閱的 Pro 使用者數量是固定的：達到上限時，伺服器會拒絕儲存此旗標。沒有有效的訂閱時，此旗標不會有任何作用。

## 外部 {#user-external}

在您是管理員時顯示。只能在建立使用者時設定。

外部使用者透過 LDAP 或 OpenID Connect 登入，而不是使用 Semaphore 的密碼：密碼欄位會被停用，以密碼登入會被拒絕。
每次登入時，名稱和電子郵件都會從身分提供者取得。若使用者以密碼登入，請保持此方塊不勾選。

## Change password {#user-changePassword}

在非**外部**的現有使用者的 **Security** 分頁上，當伺服器允許以密碼登入時顯示。

開啟一個設定新密碼的對話方塊。若要更改您自己的密碼，您必須提供目前的密碼；若要重設其他使用者的密碼，則不需要。

## Time-based one-time password {#user-totp}

在管理員已為伺服器開啟雙重驗證時，顯示於 **Security** 分頁上。

為此使用者開啟雙重驗證。當您開啟此開關時，Semaphore 會立即建立一個密鑰，並以 QR 碼顯示：請用驗證器應用程式掃描它。
從此之後，登入時會在輸入密碼後要求輸入應用程式中的驗證碼。

若伺服器允許復原，QR 碼下方會顯示一組復原碼。它只會顯示一次：請複製並妥善保存。關閉此開關會立即移除該密鑰。

## LDAP 提供者 {#user-ldapProvider}

當伺服器有一個您的帳號尚未連結的 LDAP 提供者時，顯示於您自己帳號的 **Security** 分頁上。

有多個 LDAP 伺服器時，要將您的帳號連結到的那一個。

## LDAP username {#user-ldapUsername}

與 **LDAP 提供者**一起顯示。

您在 LDAP 伺服器上的使用者名稱。連結之後，您也可以透過 LDAP 登入此帳號。

## LDAP password {#user-ldapPassword}

與 **LDAP 提供者**一起顯示。

您在 LDAP 伺服器上的密碼。Semaphore 只會使用它一次，以確認該 LDAP 帳號屬於您，並且不會儲存它。

## Link {#user-ldapLink}

與 **LDAP 提供者**一起顯示。

將您的帳號連結到上方的 LDAP 帳號。當憑證錯誤、該 LDAP 帳號已連結到其他使用者，或您的帳號已連結到該提供者時，連結會被拒絕。
已連結的帳號會出現在 **Linked accounts** 之下；關閉其標籤即可解除連結。

## Global role {#global-role-select}

在 Pro 版本中，當您可以管理全域角色時，顯示於現有使用者的 **Roles** 分頁上。

要授予使用者的全域角色，從使用者尚未擁有的角色中選擇。全域角色授予涵蓋整個伺服器的權限：管理使用者、全域角色或伺服器的設定，或讀取稽核日誌。
全域角色本身是在「使用者」頁面的**全域角色**分頁中建立的。

## Assign {#globalRoleAssign-assign}

與 **Global role** 一起顯示。

立即將所選的角色授予使用者。使用者擁有的角色會列在下方，每個角色都有一個移除它的按鈕。**Effective global permissions**
會顯示使用者最終可以執行的操作，以及每項權限的來源。
