# 調査変数

調査変数は、テンプレートを実行するたびにタスクのダイアログが尋ねる質問です。回答は変数としてタスクに渡されます。Ansible では追加の変数、Terraform と OpenTofu では `-var`、スクリプトでは引数、または環境変数です。変数は、テンプレートのダイアログを保存したときにテンプレートとともに保存されます。同じダイアログでワークフローの調査も編集できますが、そこではタイプ **Secret** は表示されません。

## 名前 {#surveyVarDialog-name}

タスクが回答を受け取るときの名前です。追加の変数、Terraform の変数、スクリプトの `name=value` 引数、または環境変数の名前です。両端の空白は削除されます。このフィールドは必須です。

調査の他の変数にない名前で、ツールが受け付ける名前を使ってください。例: `app_version`。回答は、テンプレートの変数グループにある同じ名前の変数を置き換えます。

## タイトル {#surveyVarDialog-title}

タスクのダイアログでのフィールドのラベルです。例: `Version to deploy`。テンプレートのダイアログでの変数のチップのテキストでもあります。このフィールドは必須です。

## 説明 {#surveyVarDialog-description}

任意です。タスクのダイアログのフィールドにフォーカスがある間、その下に表示されるヒントです。何を入力するか、または例を示します。

## タイプ {#surveyVarDialog-type}

タスクのダイアログが求める回答の種類です。

- **String**: 1 行のテキストです。これがデフォルトです。
- **Integer**: 数字のみです。タスクのダイアログはそれ以外のもの (マイナス記号も) を拒否します。それでも回答はテキストとしてタスクに渡されます。プレイブックで変換してください。例: `| int`。
- **Secret**: タスクのダイアログでマスクされるテキストです。回答はタスクとともに保存されないため、再実行では再度尋ねられます。Ansible は Vault で暗号化されたファイルでそれを受け取ります。シークレットにはデフォルト値がありません。
- **Enum**: 下で定義する一覧から選ぶ 1 つの値です。
- **Text**: 複数行のテキストです。
- **Select**: 下で定義する一覧から選ぶ複数の値です。タスクはそれらを一覧として受け取ります。引数、`-var`、環境変数では、一覧は JSON として書かれます。例: `["a","b"]`。

タイプを変更するとデフォルト値はクリアされ、一覧のないタイプでは値もクリアされます。

## Pass variable as {#surveyVarDialog-target}

回答がタスクに渡される方法です。

- **Extra variable**: ツールの通常の方法です。Ansible は追加の変数として、Terraform と OpenTofu は `-var name=value` として、Bash、PowerShell、Python のスクリプトはスクリプトの後の `name=value` 引数として受け取ります。
- **Environment variable**: プロセスの環境変数 `name=value` で、すべての種類のテンプレートで使えます。その場合、変数は通常の方法では渡されません。

## キー {#surveyVarDialog-valueName}

タイプが **Enum** または **Select** の場合に表示されます。

タスクのダイアログが一覧でこの値に表示するテキストです。すべての値にキーが必要で、キーは互いに異なる必要があります。そうでない場合、ダイアログは変数の保存を拒否します。

## 値 {#surveyVarDialog-valueValue}

タイプが **Enum** または **Select** の場合に表示されます。

この値を選んだときにタスクが受け取るものです。キーと異なっていてもかまいません。キー `Production` で `prod` を渡すことができます。

## Add Value {#surveyVarDialog-addValue}

タイプが **Enum** または **Select** の場合に表示されます。

値の一覧に空の行を追加します。**Enum** と **Select** には少なくとも 1 つの値が必要です。行のごみ箱のアイコンでその行を削除します。

## Default value {#surveyVarDialog-defaultValue}

**Secret** 以外のすべてのタイプで表示されます。

タスクのダイアログを開いたときに入力される回答で、そこで変更できます。**Enum** では値の 1 つを、**Select** では任意の数の値を選びます。空の回答で始める場合は、このフィールドを空のままにします。

デフォルト値を入力するのはタスクのダイアログだけです。別の方法 (たとえば API) で開始したタスクは、デフォルト値を受け取りません。

## 必須 {#surveyVarDialog-required}

変数に回答があるまで、タスクのダイアログはタスクを開始しません。デフォルト値と同じく、この確認はタスクのダイアログだけが行い、サーバーは行いません。
