# 소스 편집

소스는 Git 리포지토리의 파일에서 관리형 인벤토리의 호스트와 그룹을 가져옵니다. 파일은 Sync를 누를 때마다 읽히고, 파일에 적힌 호스트와 그룹이 파일과 같은 상태로 유지됩니다. 서버에는 Ansible과 리포지토리에 대한 접근 권한이 필요합니다.

## 이름 {#inventorySourceForm-name}

소스의 이름입니다. 카드와 소스가 가져온 호스트 옆에 표시됩니다. 필수 항목입니다.

## 리포지토리 {#inventorySourceForm-repository}

파일을 읽어 올 프로젝트의 리포지토리입니다. 필수 항목입니다. 그 브랜치가 사용됩니다.

## 경로 {#inventorySourceForm-path}

리포지토리 안 인벤토리 파일의 경로(예: `inventory/prod.yml`) 또는 인벤토리 파일이 있는 디렉터리의 경로입니다. 필수 항목입니다.

파일은 정적 YAML 또는 INI로 읽으며, 스크립트와 플러그인 설정 파일은 거부됩니다. 디렉터리에서는 Ansible이 건너뛰지 않는 모든 파일이 올바른 인벤토리여야 하며, 그렇지 않으면 동기화가 실패하고 아무것도 바뀌지 않습니다. Ansible은 디렉터리 안에서 `.cfg`, `.md`, `.txt` 등 일부 확장자를 건너뜁니다. 리포지토리 밖을 가리키는 링크가 있는 리포지토리는 거부됩니다.
