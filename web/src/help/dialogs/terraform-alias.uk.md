# Редагувати Key

Псевдонім — це адреса HTTP-бекенду, який Semaphore надає для цього workspace: Terraform або
OpenTofu, спрямований на неї, читає, записує, блокує і розблоковує стан workspace у Semaphore.
Semaphore створює адресу, коли ви створюєте псевдонім; у цьому діалозі ви лише вибираєте ключ,
який її захищає. Псевдоніми — функція Semaphore PRO.

## Auth key {#tfAlias-authKeyId}

Ключ, який охороняє псевдонім. Список пропонує лише ключі типу **Логін з паролем** зі «Сховища
ключів» проєкту; якщо список порожній, спершу створіть такий ключ там.

Клієнт псевдоніма надсилає логін і пароль цього ключа. Після збереження скопіюйте адресу зі
списку псевдонімів і вкажіть її в бекенді `http` своєї конфігурації разом із логіном і паролем
ключа:

```hcl
terraform {
  backend "http" {
    address        = "ALIAS_URL"
    lock_address   = "ALIAS_URL"
    unlock_address = "ALIAS_URL"
    username       = "LOGIN"
    password       = "PASSWORD"
  }
}
```

Адреса відповідає на стандартні методи бекенду `http`, тож одна адреса обслуговує стан,
блокування і розблокування. Вибір іншого ключа для наявного псевдоніма зберігає його адресу:
тоді клієнтам потрібні логін і пароль нового ключа.
