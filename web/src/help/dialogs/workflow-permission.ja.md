# Workflow permissions

この 1 つのワークフローに対する追加の権限をロールに付与します。ロールを持つメンバーは、ロールがプロジェクト全体で持つ権限に加えて、これらの権限を得ます。ここでの付与は追加するだけで、権限を取り上げることはありません。複数のロールを持つメンバーは、そのいずれかに付与されたすべての権限を得ます。

## 役割 {#templatePerm-roleSlug}

権限を得るロールです。一覧には、このプロジェクトのロール、共有のロール、組み込みのロールが表示されます。このフィールドは必須で、1 つのロールはワークフローに対して 1 つの付与しか持てません。2 つ目はサーバーが拒否します。

保存済みの付与のロールは変更できません。ここで何を選んでも、サーバーはロールを保持し、権限だけを保存します。権限を別のロールに付与するには、この付与を一覧から削除し、新しい付与を追加してください。

## Permissions {#templatePerm-permissionsTitle}

ロールを持つメンバーがこのワークフローで行えることです。

- **Can see this workflow**: ワークフローが、その実行とともに、ワークフローの一覧に表示されます。
- **Can run this workflow**: ワークフローの実行を開始します。
- **Can edit this workflow**: ワークフローを変更、削除し、これらの権限を管理します。
- **Can approve this workflow**: その実行の承認ステップを承認または拒否します。

実行、編集、承認には、ワークフローの表示が含まれます。いずれかにチェックを入れると、**Can see this workflow** にもチェックが入り、外せなくなります。何も付与しない付与を保存するには、すべてのボックスのチェックを外したままにします。
