# Редактировать хост

Хост управляемого инвентаря. Задача, которая использует инвентарь, выполняется на тех его хостах,
которые включены в списке хостов.

Хост, импортированный из источника инвентаря, управляется этим источником. Имя и переменные доступны
только для чтения и обновляются при каждой синхронизации. Описание, неимпортированные группы и
переключатель Enabled можно менять.

## Имя {#inventoryHostForm-name}

Имя, под которым Ansible знает хост, и адрес, к которому он подключается, если в переменных не задан
`ansible_host`. Поле обязательное. Имя уникально в пределах инвентаря, регистр букв различается:
`web1` и `Web1` — это два хоста. Имя не может содержать пробелы, запятые, квадратные скобки и
двоеточия, его длина не больше 250 символов.

## Описание {#inventoryHostForm-description}

Необязательное поле. Заметка для людей, она видна в списке хостов. Ansible ее не получает.

## Groups {#inventoryHostForm-groups}

Необязательное поле. Группы, в которых состоит хост. Хост может состоять в нескольких группах.
Группы создаются на вкладке Groups.

## Переменные {#inventoryHostForm-variables}

Необязательное поле. Переменные этого хоста, записанные как словарь YAML или JSON:

```yaml
ansible_host: 10.0.0.11
ansible_port: 2222
```

Переменная хоста имеет приоритет над переменной инвентаря с тем же именем. Якоря, ссылки и ключи
слияния YAML не принимаются.
