# Восстановить проект...

Создает новый проект из файла резервной копии, сделанного с помощью **Резервное копирование
проекта** на странице «Настройки» проекта. Новый проект получает шаблоны задач, инвентари,
репозитории, группы переменных, ключи, расписания, интеграции и все остальное, что настроено в
резервной копии, а вы становитесь его владельцем. Восстановить проект может только администратор,
если только администратор сервера не разрешил всем пользователям создавать проекты.

## Имя проекта {#restoreProject-name}

Имя нового проекта. Поле обязательное, и оно заменяет имя, записанное в файле резервной копии.

Имя должно отличаться от имен всех проектов на сервере: сервер отказывается восстанавливать
проект под уже занятым именем.

## Backup file {#restoreProject-file}

JSON-файл резервной копии. Выберите файл, прежде чем нажать **Restore**.

Резервная копия не включает секреты ключей и секреты на вкладке **Secrets** групп переменных:
после восстановления Semaphore сообщает, сколько ключей пусты и требуют повторного ввода секретов,
и секреты групп переменных также нужно ввести заново. Пароль, введенный прямо в другое поле,
например в адрес репозитория, возвращается в том виде, в каком он есть в файле. Участники проекта
и история его задач не входят в резервную копию. Резервная копия, созданная более новой версией
Semaphore, отклоняется.
