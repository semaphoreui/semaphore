# Edit App

Приложение — это инструмент, с помощью которого Semaphore выполняет задачи: Ansible, Terraform,
OpenTofu, Terragrunt, Bash, Python, PowerShell или ваша собственная команда. Каждый шаблон задачи
создается для одного приложения, а этот диалог задает, как сервер его запускает и как приложение
показано в интерфейсе.

Настройки хранятся в базе данных и сразу вступают в силу на сервере, который их сохраняет;
остальные узлы кластера считывают их при перезапуске. Поле, которое вы очистили, сохраняет прежнее
значение до перезапуска сервера.

## ID {#appForm-id}

Обязательное поле. Ключ, под которым хранится приложение; шаблон задачи ссылается на свое
приложение по этому ключу. Встроенные приложения: `ansible`, `terraform`, `tofu`, `terragrunt`,
`pulumi`, `bash`, `python` и `powershell`. Любой другой ID добавляет ваше собственное приложение:
Semaphore запускает его как скрипт с командой, указанной в поле **Path**, а если **Path** пустое —
с командой, названной так же, как ID.

Используйте ID без точек. Изменение ID существующего приложения не переименовывает его: настройки
сохраняются как новое приложение под новым ID, а старое приложение остается.

## Icon {#appForm-icon}

Необязательное поле. Имя значка из набора Material Design Icons без префикса `mdi-`, например
`language-python`. Оставьте поле пустым, чтобы сохранить встроенный значок приложения; ваше
собственное приложение тогда показывается со знаком вопроса.

## Имя {#appForm-title}

Необязательное поле. Имя приложения в списке приложений и в меню **Новый шаблон**. Оставьте поле
пустым, чтобы сохранить встроенное имя, например `Ansible Playbook`; у вашего собственного
приложения тогда нет имени, поэтому задайте его.

## Path {#appForm-path}

Необязательное поле. Команда, которую Semaphore запускает вместо команды по умолчанию: либо имя,
которое ищется в `PATH` сервера, либо полный путь, например `/usr/local/bin/terraform-1.9`.
Команды по умолчанию: `terraform`, `tofu`, `terragrunt`, `bash`, `python3` и `powershell`; ваше
собственное приложение запускает команду, названную так же, как его ID.

Ansible игнорирует это поле: Semaphore всегда запускает `ansible-playbook` и `ansible-galaxy`.

## Priority {#appForm-priority}

Место приложения в списке приложений и в меню **Новый шаблон**: приложение с большим числом
идет первым. Приоритеты встроенных приложений начинаются с 1000 у Ansible и опускаются до 500 у
Python. Встроенное приложение с приоритетом `0` или меньше получает обратно свой встроенный
приоритет при запуске сервера.

## Args {#appForm-args}

Необязательное поле. Аргументы, которые ставятся в командной строке сразу после команды, по одному
на элемент. Нажмите **+**, чтобы добавить аргумент, нажмите на элемент, чтобы изменить его,
перетаскивайте элементы, чтобы изменить их порядок.

- Terraform, OpenTofu и Terragrunt: аргументы идут перед аргументами, которые Semaphore добавляет к
  каждой команде, например `init` и `apply`.
- Приложения-скрипты: аргументы идут перед скриптом шаблона и заменяют аргументы по умолчанию:
  PowerShell по умолчанию запускается с `-File`, поэтому поставьте `-File` последним в списке.
- Ansible игнорирует это поле.

## Active {#appForm-active}

Активное приложение предлагается в меню **Новый шаблон**. Снимите флажок, чтобы скрыть приложение
из этого меню: шаблоны, уже созданные с ним, сохраняют свое приложение и по-прежнему выполняются.

Для нового приложения флажок снят: установите его, чтобы приложение стало доступно.
