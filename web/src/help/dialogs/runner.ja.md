# ランナーを編集

ランナーは、Semaphore サーバーではなく自身のマシンでタスクを実行する、独立した `semaphore runner` プロセスです。サーバーがランナーでタスクを実行するように設定されている場合、またはタスクテンプレートやそのインベントリにランナータグがある場合に、タスクはランナーに送られます。その場合、サーバーは有効で、登録済みで、オンラインで、並列タスク数の上限に達していないランナーを選びます。最初にプロジェクトのランナー、次にグローバルランナーの順で、各グループ内ではランダムな順序です。一致するすべてのランナーがオフラインまたはビジーの場合、タスクはキューで待機します。一致するランナーがまったくない場合、タスクは失敗します。

## 名前 {#runner-name}

必須です。ランナー ページに表示されるランナーの名前です。例: ランナーが動作しているホスト。ランナーが受け取るタスクには影響しません。

## Tags {#runner-tags}

Semaphore Pro で利用できます。その他のエディションでは、このフィールドはロックされています。

このランナーのタスクを選ぶタグです。ランナータグを持つタスクは、そのタグを持つランナーにのみ送られます。タスクテンプレートのタグは、インベントリのタグより優先されます。タグを入力して Enter キーを押すか、他のランナーで使われているタグを選択します。空のタグと重複したタグは、保存時に削除されます。

**Is default** にチェックが入っていない限り、プロジェクトのランナーには少なくとも 1 つのタグが必要です。

## Is default {#runner-isDefault}

ランナータグのないタスクは、デフォルトとしてマークされたランナーにのみ送られます。自身のタグのいずれかを持つタスクだけを受け取るランナーでは、チェックを外します。

新しいグローバルランナーではチェックが入っており、新しいプロジェクトのランナーではチェックが外れています。

## Register {#runner-registered}

ランナーを作成する場合に表示されます。

- チェックあり (デフォルト): サーバーはトークン付きでランナーを作成します。**作成** の後、ダイアログにトークンと、それを使ってランナーを起動するコマンドが表示されます。
- チェックなし: ランナーはトークンなしで作成されます。後で、ランナーの行にある **Regenerate registration token** (2 つの矢印のアイコン) をクリックして、1 時間有効な一度限りの登録トークンを取得し、`semaphore runner register` でランナーを登録します。

登録されていないランナーはタスクを受け取りません。

## Webhook {#runner-webhook}

任意です。サーバーがこのランナーにタスクを渡すときに呼び出す URL です。例: ランナーを必要に応じて起動するため。サーバーは JSON のボディを付けて `POST` リクエストを送信します。

```json
{"action": "start", "project_id": 1, "task_id": 42, "template_id": 7, "runner_id": 3}
```

URL は 30 秒以内にステータス 200 または 204 で応答する必要があります。そうでない場合、タスクは失敗します。Webhook を持つランナーは、最近サーバーをポーリングしていなくても、常にオンラインとして扱われます。常時動作しているランナーでは、このフィールドを空のままにします。

## 最大並列タスク数 {#runner-maxParallelTasks}

ランナーが同時に実行できるタスクの数です。上限に達すると、次のタスクは一致する別のランナーに送られるか、キューで待機します。上限を設けない場合は、このフィールドを空のままにするか `0` を設定します。

## 有効 {#runner-active}

新しいタスクを受け取るのは有効なランナーだけです。ランナーを削除せずに運用から外すには、チェックを外します。ランナーの一覧のスイッチでも同じことができます。

新しいランナーではチェックが外れています。チェックを入れるか、後で一覧でランナーを有効にしてください。
