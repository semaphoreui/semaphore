# New Token

API-токен дає змогу скрипту або іншому сервісу викликати API Semaphore від вашого імені, з тими
самими правами, що й у вашого облікового запису. Надсилайте його в заголовку `Authorization`
запиту: `Bearer` і токен. Токен показується один раз, одразу після створення: скопіюйте його тоді.

## Token Name {#token-name}

Необов’язкове поле. Назва, за якою токен можна відрізнити у списку токенів, наприклад назва
скрипта, який його використовує. Вона не є частиною токена і не змінює того, що токен може
робити.

## Expires {#token-expires}

Коли токен перестає працювати. Виберіть період, що відраховується від цього моменту, **Never**
для токена, який працює, доки його не видалять, або **Custom**, щоб самому вибрати момент.

Токен без терміну дії працює, доки ви не видалите його зі списку. Для токена, наданого скрипту
або іншому сервісу, краще вибрати період.

## Expiration date {#token-expiresAt}

Відображається, коли в полі **Expires** вибрано **Custom**.

Дата і час, коли токен перестає працювати, у часовому поясі вашого браузера. Момент має бути в
майбутньому: сервер відхиляє токен, термін дії якого вже минув би.
