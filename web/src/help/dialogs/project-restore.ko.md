# 프로젝트 복원...

프로젝트 설정 페이지의 **프로젝트 백업**으로 만든 백업 파일에서 새 프로젝트를 만듭니다. 새 프로젝트에는
백업에 설정된 작업 템플릿, 인벤토리, 리포지토리, 변수 그룹, 키, 일정, 통합 및 기타 항목이 들어가며, 복원한
사람이 소유자가 됩니다. 서버 관리자가 모든 사용자에게 프로젝트 생성을 허용하지 않는 한, 관리자만 프로젝트를
복원할 수 있습니다.

## 프로젝트 이름 {#restoreProject-name}

새 프로젝트의 이름입니다. 이 필드는 필수이며, 백업 파일에 기록된 이름을 대체합니다.

이름은 서버에 있는 모든 프로젝트의 이름과 달라야 합니다. 서버는 이미 사용 중인 이름으로 프로젝트를
복원하는 것을 거부합니다.

## Backup file {#restoreProject-file}

백업의 JSON 파일입니다. **Restore**를 누르기 전에 파일을 선택하세요.

백업에는 키의 비밀 값과 변수 그룹의 **Secrets** 탭에 있는 비밀 값이 들어 있지 않습니다. 복원 후
Semaphore는 비어 있어 비밀 값을 다시 입력해야 하는 키의 개수를 알려 주며, 변수 그룹의 비밀 값도 다시
입력해야 합니다. 리포지토리 주소처럼 다른 필드에 직접 입력한 비밀번호는 파일에 있는 그대로
돌아옵니다. 프로젝트의 멤버와 작업 기록은 백업에 포함되지 않습니다. 더 새로운 버전의 Semaphore가
만든 백업은 거부됩니다.
