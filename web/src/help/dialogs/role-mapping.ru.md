# New mapping

Сопоставление дает роль в проекте каждому пользователю, который входит через провайдер LDAP или
OpenID Connect и состоит там в группе. Semaphore считывает группы пользователя при каждом входе
через провайдер и выдает или отбирает сопоставленные роли в соответствии с ними, так что
пользователь, покинувший группу, теряет роль при следующем входе. Сопоставленная роль делает
пользователя участником проекта. Сопоставление нельзя изменить: удалите его и добавьте новое.

## Provider {#roleMapping-provider}

Каталог LDAP или провайдер OpenID Connect, из которого берется группа. В списке перечислены
провайдеры, настроенные в конфигурации сервера. Поле обязательное.

Группы считываются, только если провайдер для этого настроен: провайдеру LDAP нужна база поиска
групп (`group_search_dn`), провайдер OpenID Connect указывает claim с группами (`groups_claim`).
Сопоставление провайдера, который позже удален из конфигурации, остается в списке с отметкой
**Provider not configured**.

## Group {#roleMapping-group}

Имя группы в том виде, в каком его передает провайдер. Поле обязательное.

- LDAP: значение атрибута имени группы в записи группы, по умолчанию `cn`, например `devops`.
  Полный DN, такой как `cn=devops,ou=groups,dc=example,dc=com`, сокращается до его `cn`.
- OpenID Connect: одно из значений claim с группами в том виде, в каком его отправляет провайдер.

## Project {#roleMapping-projectId}

Проект, в котором выдается роль. Поле обязательное. Администратор видит все проекты; любой другой
пользователь видит только проекты, участником которых он является.

## Роль {#roleMapping-role}

Роль, которую участники группы получают в проекте. Поле обязательное и становится доступно, когда
выбран проект. В списке перечислены роли этого проекта, общие роли и встроенные роли. Если вы
выберете другой проект, роль, которой там нет, очищается.

Роль **Owner**, выданная сопоставлением, не учитывается, когда Semaphore не дает отобрать роль у
последнего владельца проекта, потому что она может пропасть при следующем входе. Оставьте хотя
бы одного владельца, добавленного вручную.
