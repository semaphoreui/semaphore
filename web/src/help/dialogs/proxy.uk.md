# Редагувати Proxy

Проксі — це хост, через який завдання проєкту дістаються серверів, до яких не можуть підключитися
напряму. Виберіть його в полі **Proxy** репозиторію, щоб отримувати репозиторій через нього, або
інвентарю, щоб Ansible підключався через нього до хостів.

## Назва {#proxyForm-name}

Обов'язково й унікально в проєкті. Репозиторії та інвентарі показують проксі під цією назвою.

## Тип {#proxyForm-type}

- **SSH (jump host)**: Semaphore підключається до хоста через SSH і звідти відкриває з'єднання із
  сервером. Лише цей тип може потребувати іншого проксі.
- **SOCKS5**, **HTTP**, **HTTPS**: проксі-сервер, що передає з'єднання. Git сам використовує його
  для репозиторію `https`; SSH-з'єднання Semaphore проводить через нього, тож інші інструменти
  встановлювати не потрібно.

## Host {#proxyForm-host}

Обов'язково. Ім'я хоста або IP-адреса, без користувача, порту та схеми. Ім'я хоста може містити
лише літери, цифри, крапки, дефіси та підкреслення.

## Port {#proxyForm-port}

Необов'язково, від 1 до 65535. Порожнє значення означає `22` для SSH jump host. Для інших типів
вкажіть порт: без нього Git і SSH-з'єднання припускають різні порти.

## User {#proxyForm-user}

Лише SSH: логін на jump host. Порожнє значення означає користувача, від імені якого працює
Semaphore. Літери, цифри, крапки, дефіси та підкреслення, без дефіса на початку. Проксі SOCKS5 або
HTTP бере логін із поля **Ключ доступу**.

## Ключ доступу {#proxyForm-sshKeyId}

Необов'язково. Ключ зі сховища ключів, з яким виконується вхід на саме проксі, зазвичай не ключ
серверів за ним:

- **SSH-ключ** для SSH jump host;
- **Логін з паролем** для SOCKS5, HTTP і HTTPS. Пароль передається через оточення, ніколи через
  командний рядок.

## Requires Proxy {#proxyForm-requiresProxyId}

Лише SSH, необов'язково. Інше SSH-проксі проєкту, через яке треба пройти спочатку, для jump host,
доступного лише з іншого. Ланцюжок містить не більше 5 проксі й не може повертатися до проксі, яке
вже в ньому є.
