# Edit mapping

マッピングは、SSH ホストまたは Git の URL に対して、キーのストアのどの資格情報を使うかを Semaphore に指示します。リポジトリは 1 つのキーを持ちますが、タスクは他のサーバーにも接続することがあります。サブモジュール、`requirements.yml` のロールとコレクション、Terraform モジュール、インベントリのリポジトリです。プロジェクトのマッピングは、そのタスクのすべての Git と SSH の接続、および Semaphore がプロジェクトのために実行する Git コマンド (リポジトリの新しいコミットのチェックなど) に適用されます。リポジトリのファイルは何も変更されません。

## タイプ {#hostConfigForm-type}

マッピングが一致する対象です。

- **Host**: SSH のホスト名です。そのホストへのタスクのすべての SSH 接続が、マッピングのキーを使います。SSH 経由の Git と、その名前のインベントリホストに接続する Ansible です。同じホストについては、マッピングがサーバーの SSH 設定より優先されます。
- **URL**: Git の URL、またはその先頭部分です。Git は、その URL の下にあるすべてのリポジトリにマッピングの資格情報で接続します。

**Host** に切り替えると、ホストのマッピングで使えない **Credential** はクリアされます。

## Host または URL {#hostConfigForm-host}

このフィールドは必須です。ホストまたは URL ごとに、タイプごとに 1 つのマッピングを作成できます。

**Host** の場合: Git または Ansible が接続するとおりのホスト名です。例: `github.com` または `10.0.0.21`。英字、数字、ドット、ハイフン、アンダースコアのみを使えます。ユーザー、ポート、ワイルドカードは使えません。

**URL** の場合: `https://` または `http://` で始まるアドレスで、ログインを含まず、空白、引用符、`=` を含まないものです。リポジトリ全体を指定するか、`/` で終わる接頭辞を指定してリポジトリのグループをまとめて対象にします。

```
https://github.com/acme/
https://github.com/acme/infra.git
```

複数のマッピングが一致する場合は、最も長いものが優先されます。上のリポジトリのマッピングは、そのリポジトリについてのみ `acme` のマッピングより優先されます。

SSH キーを使う場合、URL のマッピングにより、Git は URL に指定されたポートに関係なく、URL のホストのポート `22` に SSH で接続します。

## Credential {#hostConfigForm-sshKeyId}

マッピングが一致する接続に使われる、キーのストアのキーです。このフィールドは必須です。

- **Host** は **SSHキー** のみを受け付けます。キーにログインがある場合、SSH はそのユーザーとして接続します。
- **URL** は **SSHキー** または **パスワードでログイン** を受け付けます。SSH キーはそのログインとして接続し、ログインがない場合は `git` として接続します。パスワードでログインは `https://` の URL でのみ機能します。トークンの場合は、トークンをパスワードに入れ、ログインを空のままにします。

パスワードでログインは、Git のコマンドラインではなく環境を通じて Git に渡され、タスクのログには元の URL のみが表示されます。
