# Run Workflow

Запускає виконання workflow, щойно ви відповіли на його опитування. Діалог відкривається лише для
workflow з опитуванням: workflow без опитування запускається одразу. Після **Запуск** відкривається
сторінка нового виконання; якщо сервер відхиляє значення, діалог залишається відкритим з вашими
відповідями.

## Variables {#workflowRunDialog-survey}

По одному полю на кожну змінну опитування workflow, у порядку опитування, із заповненим значенням
за замовчуванням. Поле, позначене `*`, обов’язкове, поле Integer приймає лише цифри, а поле-список
приймає одне значення або, якщо змінна дозволяє кілька, будь-яку їх кількість. **Запуск** нічого
не запускає, доки всі поля не будуть правильними.

Значення зберігаються разом із виконанням і показуються на його сторінці в розділі **Variables**.
Завдання workflow не отримує їх саме собою: змінна його шаблону отримує значення, лише коли його
вузол прив’язує її до змінної workflow. Сама лише назва нічого не передає.

Опитування workflow не містить секретів, бо виконання зберігає його значення у відкритому вигляді.
Паролі й токени натомість зберігайте в ключі або в групі змінних.
