# Template permissions

Дает роли дополнительные права на этот шаблон. Участник с этой ролью получает их в дополнение к
правам, которые роль имеет во всем проекте: выдача прав здесь только добавляет права и никогда не
отбирает их. Участник с несколькими ролями получает все права, выданные любой из них.

## Роль {#templatePerm-roleSlug}

Роль, которая получает права. В списке показаны роли этого проекта, общие роли и встроенные роли.
Поле обязательное, и у роли может быть только одна выдача прав на шаблон: вторую сервер
отклоняет.

Роль сохраненной выдачи прав нельзя изменить. Сервер сохраняет роль и записывает только права,
что бы вы здесь ни выбрали. Чтобы дать права другой роли, удалите эту выдачу из списка и добавьте
новую.

## Permissions {#templatePerm-permissionsTitle}

Что участник с этой ролью может делать с этим шаблоном:

- **Can see this template**: шаблон есть в списке шаблонов вместе с его задачами и их логами.
- **Can run this template**: запускать задачи из шаблона, а также останавливать, подтверждать или
  отклонять его задачи.
- **Can edit this template**: изменять и удалять шаблон, останавливать все его задачи и управлять
  этими правами.

Запуск или изменение включают просмотр шаблона: когда вы отмечаете любое из них, **Can see this
template** тоже отмечается, и снять его нельзя. Оставьте все флажки снятыми, чтобы сохранить
выдачу, которая ничего не дает.
