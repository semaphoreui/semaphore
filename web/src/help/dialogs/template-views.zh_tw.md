# 編輯檢視

檢視是任務範本清單上方的分頁。檢視會顯示您放入其中的範本，或專案的所有範本。此對話方塊會立即儲存每一項變更：整個對話方塊沒有「儲存」按鈕。
拖曳檢視的握把即可變更分頁的順序。

## 標題 {#viewsForm-title}

分頁的名稱。輸入名稱後，請以欄位旁的勾號確認；叉號則會恢復已儲存的標題。新檢視在有了標題，且您確認標題或變更其某項設定後才會儲存。
關閉對話方塊不會儲存您尚未確認的標題。

齒輪圖示會在標題下方開啟檢視的設定。

## 刪除 {#viewsForm-viewDelete}

垃圾桶圖示會立即刪除檢視，不會詢問。檢視中的範本不會被刪除：它們會留在專案中，但不再屬於任何檢視。

## Type {#viewsForm-type}

分頁顯示哪些範本：

- **Custom**：在範本對話方塊中，其**檢視**欄位指定為此檢視的範本。這是預設值。
- **All**：專案的所有範本，無論其檢視為何。

在任何檢視中，成員都只會看到自己有權檢視的範本。

## Sort by {#viewsForm-sortColumn}

分頁中範本的排序欄位；只有 **Name** 一個選項。未設定此欄位的分頁同樣會依名稱排序，因此此欄位要與 **Reverse** 一起使用才有意義。

## Reverse {#viewsForm-sortReverse}

以遞減順序排序分頁。只有在設定了 **Sort by** 時才有效。

## Hidden {#viewsForm-hidden}

對無法管理專案資源的成員隱藏此分頁。能夠管理的成員仍會看到它，並以刪除線顯示。隱藏分頁並不會隱藏其範本：類型為 **All** 的檢視仍會列出它們。

## 新增檢視 {#viewsForm-add}

在清單末端新增一個檢視，並附帶一個空白標題供您輸入。
