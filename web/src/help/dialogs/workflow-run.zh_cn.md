# 运行工作流

在您回答工作流的调查之后启动一次工作流运行。此对话框只会为带有调查的工作流打开：没有调查的工作流会立即启动。
点击 **Run** 后会打开新运行的页面；如果服务器拒绝这些值，对话框会保持打开并保留您的回答。

## 变量 {#workflowRunDialog-survey}

工作流调查中的每个变量对应一个字段，按调查中的顺序排列，并已填入其默认值。标有 `*` 的字段为必填项，Integer
字段只接受数字，列表字段接受一个值，或者在变量允许多个值时接受任意数量的值。在每个字段都有效之前，**Run**
不会启动任何内容。

这些值随运行一起保存，并显示在运行页面的 **Variables** 下。工作流中的任务不会自动获得这些值：只有当节点将模板的变量绑定到工作流的变量时，
该变量才会获得值。仅凭名称相同不会传递任何内容。

工作流调查不包含秘密值，因为运行会以明文保存其值。请将密码和令牌放在密钥或变量组中。
