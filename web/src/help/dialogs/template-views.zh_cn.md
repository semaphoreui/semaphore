# 编辑视图

视图是任务模板列表上方的标签页。一个视图显示您放入其中的模板，或者项目的所有模板。此对话框会立即保存每一项更改：
整个对话框没有保存按钮。拖动视图的手柄可以更改标签页的顺序。

## 标题 {#viewsForm-title}

标签页的名称。输入名称后，点击字段旁边的对勾进行确认；点击叉号会恢复已保存的标题。新视图在有了标题并且您确认了标题，
或者更改了它的某项设置之后即被保存。关闭对话框不会保存您尚未确认的标题。

齿轮图标会在标题下方打开视图的设置。

## 删除 {#viewsForm-viewDelete}

垃圾桶图标会立即删除视图，不会询问。视图中的模板不会被删除：它们仍保留在项目中，只是不再属于任何视图。

## Type {#viewsForm-type}

标签页显示哪些模板：

- **Custom**：在模板对话框中，其**视图**字段指定了此视图的模板。这是默认值。
- **All**：项目的所有模板，无论其视图是什么。

在任何视图中，成员都只能看到自己有权查看的模板。

## Sort by {#viewsForm-sortColumn}

标签页中模板的排序列；**Name** 是唯一的选项。未设置排序列的标签页同样按名称排序，因此此字段需要与 **Reverse**
一起使用才有意义。

## Reverse {#viewsForm-sortReverse}

按降序对标签页进行排序。只有在设置了 **Sort by** 时才生效。

## Hidden {#viewsForm-hidden}

对无法管理项目资源的成员隐藏此标签页。能够管理的成员仍然可以看到它，但会显示为删除线。隐藏标签页不会隐藏其中的模板：
类型为 **All** 的视图仍会列出它们。

## 添加视图 {#viewsForm-add}

在列表末尾添加一个视图，并带有一个空标题供您输入。
