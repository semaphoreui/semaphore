# Run Workflow

調査に回答すると、ワークフローの実行を開始します。このダイアログは調査のあるワークフローでのみ開きます。調査のないワークフローはすぐに開始します。**実行** の後、新しい実行のページが開きます。サーバーが値を拒否した場合、ダイアログは回答を保持したまま開いたままになります。

## 変数 {#workflowRunDialog-survey}

ワークフローの調査の変数ごとに 1 つのフィールドがあり、調査の順序で並び、デフォルト値が入力されています。`*` の付いたフィールドは必須で、Integer のフィールドは数字のみを受け付けます。一覧のフィールドは 1 つの値、または変数が複数を許可している場合は任意の数の値を受け付けます。すべてのフィールドが有効になるまで、**実行** は何も開始しません。

値は実行とともに保存され、そのページの **Variables** の下に表示されます。ワークフローのタスクが自動的にそれらを受け取ることはありません。テンプレートの変数が値を受け取るのは、そのノードがそれをワークフローの変数に結び付けている場合だけです。名前が同じだけでは何も渡されません。

実行は値を平文で保持するため、ワークフローの調査にはシークレットを含めません。パスワードとトークンは、代わりにキーまたは変数グループに入れてください。
