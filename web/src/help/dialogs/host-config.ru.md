# Edit mapping

Сопоставление сообщает Semaphore, какие учетные данные из раздела «Хранилище ключей» использовать
для SSH-хоста или Git URL. У репозитория один ключ, но задача может обращаться и к другим
серверам: подмодулям, ролям и коллекциям из `requirements.yml`, модулям Terraform, репозиториям
инвентаря. Сопоставления проекта действуют для всех соединений Git и SSH его задач и для команд
Git, которые Semaphore выполняет для проекта, например для проверки репозитория на новые коммиты.
Ни один файл вашего репозитория не меняется.

## Тип {#hostConfigForm-type}

С чем сравнивается сопоставление:

- **Host**: имя SSH-хоста. Каждое SSH-соединение задачи с этим хостом использует ключ
  сопоставления: Git по SSH и Ansible, подключающийся к хосту инвентаря с этим именем.
  Сопоставление имеет приоритет над SSH-конфигурацией сервера для того же хоста.
- **URL**: Git URL или его начало. Git подключается к каждому репозиторию под этим URL с учетными
  данными сопоставления.

При переключении на **Host** очищается поле **Credential**, если сопоставление хоста не может
использовать выбранный ключ.

## Host or URL {#hostConfigForm-host}

Поле обязательное. Для каждого хоста или URL может существовать одно сопоставление каждого типа.

Для **Host**: имя хоста точно в том виде, в каком к нему подключаются Git или Ansible, например
`github.com` или `10.0.0.21`. Только буквы, цифры, точки, дефисы и знаки подчеркивания: без
пользователя, без порта, без подстановочных знаков.

Для **URL**: адрес, который начинается с `https://` или `http://`, без логина в нем и без
пробелов, кавычек и `=`. Укажите весь репозиторий или префикс, который заканчивается на `/`,
чтобы охватить группу репозиториев:

```
https://github.com/acme/
https://github.com/acme/infra.git
```

Если подходят несколько сопоставлений, побеждает самое длинное: сопоставление репозитория выше
переопределяет сопоставление `acme` для этого одного репозитория.

С SSH-ключом сопоставление URL заставляет Git подключаться по SSH к хосту из URL на порт `22`,
какой бы порт ни был указан в URL.

## Credential {#hostConfigForm-sshKeyId}

Ключ из раздела «Хранилище ключей», который используется для соединений, подходящих под
сопоставление. Поле обязательное.

- **Host** принимает только **SSH ключ**. Если у ключа есть логин, SSH подключается от имени этого
  пользователя.
- **URL** принимает **SSH ключ** или **Логин с паролем**. SSH-ключ подключается со своим логином
  или как `git`, если логина нет. Логин с паролем работает только с URL `https://`; для токена
  укажите токен в пароле и оставьте логин пустым.

Логин с паролем передается Git через окружение, а не через командную строку, и лог задачи
показывает только исходный URL.
