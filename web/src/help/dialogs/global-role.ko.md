# Edit Global Role

전역 역할은 할당된 사용자에게 Semaphore 인스턴스 전체에 대한 권한을 부여합니다. 전역 역할은 사용자
대화 상자에서 할당합니다. 이 역할은 프로젝트 내부에 대한 액세스 권한을 주지 않습니다. 그 권한은 오직
사용자가 프로젝트 멤버로서 가진 역할에서만 나옵니다. 관리자는 할당된 역할과 관계없이 모든 전역 권한을
가집니다. 전역 역할은 Pro 기능입니다.

## 이름 {#globalRole-name}

사용자 페이지의 전역 역할 탭과 사용자 대화 상자에 표시되는 역할 이름입니다. 이 필드는 필수입니다. 역할
이름은 언제든지 바꿀 수 있습니다.

## Slug {#globalRole-slug}

역할의 식별자입니다. 이름을 입력하는 동안 Semaphore가 이름에서 자동으로 채우며, 직접 슬러그를 수정하면
자동 채우기가 멈춥니다. 문자, 숫자, 밑줄, 하이픈으로 1~100자를 사용할 수 있습니다. 예: `user-admins`.

슬러그는 전역 역할 사이에서 고유해야 하며, 프로젝트 역할은 같은 슬러그를 가질 수 있습니다. 역할을 저장한
후에는 바꿀 수 없으며, 역할을 수정할 때 이 필드는 잠겨 있습니다.

## Global permissions {#globalRole-permissionsTitle}

이 역할을 가진 사용자가 인스턴스 전체에서 할 수 있는 일입니다. 새 역할에는 체크된 권한이 없습니다.
사용자가 가진 모든 전역 역할의 권한은 합산됩니다.

- **Can manage users**: 사용자를 만들고, 변경하고, 삭제하며, 사용자 목록에서 사용자의 세부 정보를 봅니다.
  이 권한을 가진 사용자는 다른 사용자를 관리자나 Pro 사용자로 만들 수 없으며, 관리자나 자신이 갖지 않은
  전역 권한을 가진 사용자를 변경하거나 삭제할 수 없습니다.
- **Can manage global roles**: 전역 역할과 공유 프로젝트 역할을 만들고, 변경하고, 삭제하며, 어떤 사용자가
  어떤 전역 역할을 가질지 정합니다. 인스턴스 전체를 맡길 수 있는 사람에게만 부여하세요.
- **Can manage system settings**: 인스턴스 설정, 애플리케이션, 전역 러너, 그룹 매핑을 변경하고, 클러스터와
  서버 정보를 보고, 모든 프로젝트의 작업을 보고 제거하며, 서버의 캐시를 지웁니다.
- **Can read the audit log**: 인스턴스의 감사 로그를 읽고 내보냅니다.
