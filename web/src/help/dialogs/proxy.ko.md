# 수정 Proxy

프록시는 프로젝트의 작업이 직접 연결할 수 없는 서버에 도달하기 위해 거치는 호스트입니다. 저장소의
**Proxy** 필드에서 선택하면 저장소를 그것을 통해 가져오고, 인벤토리에서 선택하면 Ansible이 그것을
통해 호스트에 연결합니다.

## 이름 {#proxyForm-name}

필수이며 프로젝트 안에서 고유해야 합니다. 저장소와 인벤토리는 이 이름으로 프록시를 표시합니다.

## 유형 {#proxyForm-type}

- **SSH (jump host)**: Semaphore가 호스트에 SSH로 연결하고 그곳에서 서버로의 연결을 엽니다.
  다른 프록시를 필요로 할 수 있는 유형은 이것뿐입니다.
- **SOCKS5**, **HTTP**, **HTTPS**: 연결을 전달하는 프록시 서버입니다. `https` 저장소에는 Git이
  직접 사용하고, SSH 연결은 Semaphore가 이를 거쳐 보내므로 다른 도구를 설치할 필요가 없습니다.

## Host {#proxyForm-host}

필수. 호스트 이름 또는 IP 주소이며 사용자, 포트, 스킴은 넣지 않습니다. 호스트 이름에는 문자,
숫자, 점, 하이픈, 밑줄만 쓸 수 있습니다.

## Port {#proxyForm-port}

선택 사항, 1에서 65535. 비워 두면 SSH 점프 호스트는 `22`입니다. 다른 유형에서는 포트를
지정하세요. 지정하지 않으면 Git과 SSH 연결이 서로 다른 포트를 가정합니다.

## User {#proxyForm-user}

SSH 전용: 점프 호스트의 로그인입니다. 비워 두면 Semaphore를 실행하는 사용자입니다. 문자, 숫자,
점, 하이픈, 밑줄을 쓸 수 있으며 하이픈으로 시작할 수 없습니다. SOCKS5나 HTTP 프록시는 대신
**액세스 키**에서 로그인을 가져옵니다.

## 액세스 키 {#proxyForm-sshKeyId}

선택 사항. 프록시 자체에 로그인할 때 쓰는 키 저장소의 키로, 보통 그 뒤에 있는 서버의 키와는
다릅니다:

- SSH 점프 호스트에는 **SSH 키**;
- SOCKS5, HTTP, HTTPS에는 **비밀번호로 로그인**. 비밀번호는 환경으로 전달되며 명령줄에는 절대
  나타나지 않습니다.

## Requires Proxy {#proxyForm-requiresProxyId}

SSH 전용, 선택 사항. 먼저 거쳐야 하는 프로젝트의 다른 SSH 프록시로, 다른 점프 호스트에서만 도달할
수 있는 점프 호스트에 씁니다. 체인에는 최대 5개의 프록시가 들어가며 이미 체인에 있는 프록시로 되돌아갈
수 없습니다.
