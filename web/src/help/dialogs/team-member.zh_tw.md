# 新增 團隊成員

將使用者以某個角色加入專案。角色決定成員在專案中可以看到和執行的內容；其帳號的其他部分都不會改變。若管理員已開啟邀請功能，
使用者會改為收到邀請，並在接受後成為成員。

## 電子郵件或使用者名稱 {#teamMember-inviteType}

在可以同時透過電子郵件和使用者名稱邀請使用者時顯示。

選擇人員的方式：**Email** 用於邀請某個電子郵件地址，**Username** 用於選擇在此 Semaphore 伺服器上已有帳號的使用者。

## 電子郵件 {#teamMember-email}

在透過電子郵件邀請人員時顯示。

要邀請之人員的電子郵件地址。對方接受邀請後即成為專案的成員。

## 使用者 {#teamMember-userId}

在透過使用者名稱選擇人員時顯示。

要加入的使用者，以使用者名稱和全名列出。此欄位為必填。清單中列出 Semaphore 伺服器上所有尚未成為專案成員的使用者：沒有帳號的人員必須先向管理員取得帳號。

## 角色 {#teamMember-role}

成員在專案中可以執行的操作。此欄位為必填。內建角色：

- **Owner**：所有操作，包括專案的設定、其團隊以及刪除專案。
- **Manager**：執行任務和工作流程、核准工作流程，以及建立、修改和刪除任務範本、清單、金鑰、儲存庫、變數群組、排程、整合和工作流程。
  Manager 無法變更專案的設定或其團隊。
- **Task Runner**：檢視專案、執行任務和工作流程，以及核准工作流程。Task Runner 無法變更專案中的任何內容。
- **Guest**：檢視專案、其任務及其日誌，不能變更任何內容。

清單中也包含為此專案建立的角色（**專案角色**），以及所有專案共用的角色（**Shared roles**）。這類角色會授予在「角色」頁面上為其設定的權限。
邀請只能附帶內建角色。

能夠管理團隊的成員可以授予任何角色，包括 **Owner**。此對話方塊只授予一個角色；之後可以在團隊清單的**角色**欄中新增更多角色。
