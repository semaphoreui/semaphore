# Choose workspace to attach

이 워크스페이스를 템플릿에 연결하여, 템플릿의 워크스페이스 사이에 상태 및 별칭과 함께 표시되게 합니다.
워크스페이스는 한 번에 하나의 템플릿에만 속합니다. 연결되면 인벤토리 페이지에서 빠지고 템플릿에서 관리됩니다.
연결해도 템플릿의 기본 워크스페이스가 되지는 않습니다. 기본으로 만들려면 템플릿을 열고 **Make default**를
누르세요.

## Template {#inventoryAttach-templateId}

워크스페이스를 연결할 템플릿입니다. 이 필드는 필수입니다. 목록에는 워크스페이스와 같은 앱(Terraform 또는
OpenTofu)용으로 만든 프로젝트의 템플릿이 표시됩니다.

워크스페이스는 이름, 키, 상태를 유지합니다. 나중에 다른 템플릿으로 옮기려면 연결된 템플릿에서 **Detach**를
누르세요. 워크스페이스는 인벤토리 페이지로 돌아옵니다. 템플릿의 기본 워크스페이스는 분리할 수 없습니다.
