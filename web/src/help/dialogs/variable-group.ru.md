# Редактировать группу переменных

Группа переменных содержит дополнительные переменные, переменные окружения и секреты, которые
Semaphore передает каждой задаче шаблона задачи, использующего эту группу. Ansible получает
дополнительные переменные как `--extra-vars`, Terraform и OpenTofu — как `-var`; переменные
окружения задаются для процесса задачи. Шаблон может использовать несколько групп: если две из
них задают одно и то же имя, побеждает группа, которая идет в шаблоне позже.

## Имя группы {#varGroup-name}

Имя, под которым группа показана на странице «Группы переменных» и в списке выбора группы
переменных в шаблоне задачи. Поле обязательное.

## Secret storage {#varGroup-secretStorageId}

Показывается, когда группа новая и сервер поддерживает хранилища секретов. Необязательное поле.

Хранилище секретов, в котором хранятся секреты этой группы, например HashiCorp Vault. Оставьте
поле пустым, чтобы хранить секреты в базе данных Semaphore в зашифрованном виде.

Хранилище выбирается один раз, при создании группы: существующая группа сохраняет свое
хранилище, и поле больше не показывается. Хранилище с отметкой **Read only** не принимает новые
секреты: сохранение секрета в него завершается ошибкой.

## Secret key prefix {#varGroup-secretStorageKeyPrefix}

Показывается, когда группа новая и сервер поддерживает хранилища секретов. Доступно, когда
выбрано **Secret storage**.

Начало пути, который получает в хранилище каждый секрет этой группы. Semaphore добавляет к нему
10 случайных символов: с префиксом `semaphore/prod/` секрет хранится как `semaphore/prod/`, за
которым следуют эти символы. Префикс берется как есть, поэтому заканчивайте его на `/`, если
секреты должны лежать под ним как в папке.

Префикс задается один раз, при создании группы. Вкладка **Secrets** показывает его как шаблон
исходного пути.

## Table, JSON или YAML {#varGroup-extraVarsMode}

Как вы редактируете дополнительные переменные:

- **Table**: одна строка на переменную, у каждой есть тип. Строка добавляется кнопкой **+** рядом
  с переключателем.
- **JSON**: все переменные в виде одного объекта JSON.
- **YAML**: все переменные в виде одного отображения YAML.

Диалог открывается в режиме **Table**. Переключатель преобразует введенный текст; если его не
удается прочитать, диалог остается в прежнем режиме и показывает ошибку. В любом режиме
переменные сохраняются как один объект из имен и значений.

## Дополнительные переменные в JSON {#varGroup-extraVarsJson}

Показывается, когда дополнительные переменные редактируются в режиме **JSON**.

Дополнительные переменные в виде одного объекта JSON. Имя не может быть пустым; значение может
быть строкой, числом, списком или объектом:

```json
{
  "app_version": "1.4.2",
  "replicas": 3,
  "regions": ["eu-west-1", "us-east-1"]
}
```

## Дополнительные переменные в YAML {#varGroup-extraVarsYaml}

Показывается, когда дополнительные переменные редактируются в режиме **YAML**.

Дополнительные переменные в виде одного отображения YAML. Текст читается с типами, которые знает
JSON: дата без кавычек, например `2024-01-01`, остается строкой, а `.inf` или `.nan` отклоняются.
Список или скаляр на верхнем уровне тоже отклоняются.

```yaml
app_version: 1.4.2
replicas: 3
regions:
  - eu-west-1
  - us-east-1
```

## Имя переменной {#varGroup-varName}

Показывается в каждой строке, когда дополнительные переменные редактируются в режиме **Table**.

Имя переменной в том виде, в каком ее видит плейбук или код Terraform, например `app_version`.

## Тип переменной {#varGroup-varType}

Показывается в каждой строке, когда дополнительные переменные редактируются в режиме **Table**.

Как читается значение строки:

- **String**: текст как есть.
- **Number**: число, например `42`.
- **List**: массив JSON, например `["a", "b"]`.
- **Dict**: объект JSON, например `{"key": "value"}`.

Значение, которое не соответствует своему типу, останавливает сохранение с указанием имени
переменной.

## Значение переменной {#varGroup-varValue}

Показывается в каждой строке, когда дополнительные переменные редактируются в режиме **Table**.

Значение переменной в формате ее типа. Для **List** или **Dict** кнопка в конце поля открывает
редактор побольше.

Semaphore передает значения в Ansible как данные: выражение `{{ … }}` внутри значения не
вычисляется, плейбук получает текст как есть.

## Имя переменной окружения {#varGroup-envName}

На вкладке **Variables**, в разделе **Переменные среды**, в каждой строке. Строка добавляется
кнопкой **+** этого раздела.

Имя переменной, которая задается в окружении процесса, выполняющего задачу, например
`AWS_REGION`.

## Значение переменной окружения {#varGroup-envValue}

На вкладке **Variables**, в разделе **Переменные среды**, в каждой строке.

Значение переменной в виде текста. Оно хранится открытым текстом и показывается всем, кто
открывает группу: пароли и токены вместо этого храните на вкладке **Secrets**.

## Sync keys enabled {#varGroup-syncEnabled}

Показывается на вкладке **Secrets** группы, у которой есть хранилище секретов.

Включите параметр, чтобы импортировать секреты из хранилища в эту группу по путям, заданным в
**Sync paths**. Импорт выполняется, когда вы нажимаете кнопку синхронизации группы на странице
«Группы переменных», а также автоматически с интервалом, заданным в **Sync paths**. Когда параметр
выключен, ничего не импортируется.

## Sync paths {#varGroup-syncPaths}

Показывается, когда включено **Sync keys enabled**.

Открывает диалог с путями хранилища, из которых выполняется импорт, и интервалом автоматического
импорта. Число на кнопке — это количество путей. Кнопка синхронизации группы на странице «Группы
переменных» остается недоступной, пока у группы нет хотя бы одного пути.

В диалоге есть только кнопка **Закрыть**: то, что вы в нем изменяете, сохраняется вместе с
группой кнопкой **Сохранить** этого диалога.

## Имя секретной переменной {#varGroup-secretVarName}

На вкладке **Secrets**, в разделе **Дополнительные переменные**, в каждой строке. Строка
добавляется кнопкой **+** этого раздела.

Имя дополнительной переменной, значение которой является секретом. Задача получает ее так же, как
дополнительные переменные вкладки **Variables**; секрет имеет приоритет над дополнительной
переменной с тем же именем. Ansible получает секреты в файле, зашифрованном Ansible Vault,
Terraform и OpenTofu — как `-var`. Как предупреждает диалог, секрет, переданный таким образом, все
же может появиться открытым текстом в логе Ansible.

## Значение секретной переменной {#varGroup-secretVarValue}

На вкладке **Secrets**, в разделе **Дополнительные переменные**, в каждой строке.

Значение секрета. Semaphore шифрует его или записывает в хранилище секретов группы и больше
никогда его не показывает: когда вы позже открываете группу, поле пустое. Оставьте его пустым,
чтобы сохранить хранимое значение, или введите новое, чтобы заменить его. Удаление строки удаляет
секрет при сохранении группы.

## Имя секретной переменной окружения {#varGroup-secretEnvName}

На вкладке **Secrets**, в разделе **Переменные среды**, в каждой строке. Строка добавляется
кнопкой **+** этого раздела.

Имя переменной окружения, значение которой является секретом, например `DB_PASSWORD`. Она
задается в окружении процесса, выполняющего задачу, так же как переменные окружения вкладки
**Variables**.

## Значение секретной переменной окружения {#varGroup-secretEnvValue}

На вкладке **Secrets**, в разделе **Переменные среды**, в каждой строке.

Значение секрета. Как и для секретной дополнительной переменной, оно больше никогда не
показывается: оставьте поле пустым, чтобы сохранить хранимое значение, или введите новое, чтобы
заменить его.
