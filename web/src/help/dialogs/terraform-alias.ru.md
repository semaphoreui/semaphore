# Редактировать Key

Псевдоним — это адрес HTTP backend, который Semaphore предоставляет для этого workspace:
Terraform или OpenTofu, направленный на него, читает, записывает, блокирует и разблокирует
состояние workspace в Semaphore. Semaphore создает адрес при создании псевдонима; в этом диалоге
вы только выбираете ключ, который его защищает. Псевдонимы — функция Semaphore PRO.

## Auth key {#tfAlias-authKeyId}

Ключ, который защищает псевдоним. Список предлагает только ключи типа **Логин с паролем** из
раздела «Хранилище ключей» проекта; если список пуст, сначала создайте такой ключ там.

Клиент псевдонима отправляет логин и пароль этого ключа. После сохранения скопируйте адрес из
списка псевдонимов и укажите его в backend `http` вашей конфигурации вместе с логином и паролем
ключа:

```hcl
terraform {
  backend "http" {
    address        = "ALIAS_URL"
    lock_address   = "ALIAS_URL"
    unlock_address = "ALIAS_URL"
    username       = "LOGIN"
    password       = "PASSWORD"
  }
}
```

Адрес отвечает на методы backend `http` по умолчанию, поэтому один адрес обслуживает состояние,
блокировку и разблокировку. Если выбрать другой ключ для существующего псевдонима, его адрес
сохраняется: тогда клиентам нужны логин и пароль нового ключа.
