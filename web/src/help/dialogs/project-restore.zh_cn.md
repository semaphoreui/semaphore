# 恢复项目...

根据在项目的设置页面中用**备份项目**生成的备份文件创建一个新项目。新项目会获得备份中设置的任务模板、库存、仓库、
变量组、密钥、计划、集成和其他内容，并且您将成为它的所有者。只有管理员可以恢复项目，除非服务器管理员允许每个用户创建项目。

## 项目名称 {#restoreProject-name}

新项目的名称。此字段为必填项，它会替换备份文件中写入的名称。

该名称必须与服务器上所有项目的名称都不同：服务器会拒绝以已被占用的名称恢复项目。

## 备份文件 {#restoreProject-file}

备份的 JSON 文件。请在点击 **Restore** 之前选择该文件。

备份不包含密钥的秘密值以及变量组 **Secrets** 标签页中的秘密值：恢复之后，Semaphore 会告诉您有多少个密钥是空的，需要重新输入其秘密值，变量组的秘密值也需要重新输入。直接输入到其他字段中的密码，例如仓库地址中的密码，会按文件中的原样恢复。
项目的成员及其任务历史不包含在备份中。由较新版本的 Semaphore 生成的备份会被拒绝。
