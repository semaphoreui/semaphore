# New Token

API トークンを使うと、スクリプトや別のサービスが、自分のアカウントと同じ権限で、自分として Semaphore API を呼び出せます。リクエストの `Authorization` ヘッダーで、`Bearer` とトークンを送信します。トークンは作成直後に一度だけ表示されます。そのときにコピーしてください。

## Token Name {#token-name}

任意です。トークンの一覧でトークンを区別するための名前です。例: トークンを使うスクリプトの名前。トークンの一部ではなく、トークンで行えることにも影響しません。

## Expires {#token-expires}

トークンが機能しなくなる時期です。現在から数えた期間、削除されるまで機能するトークンには **Never**、時点を自分で選ぶには **Custom** を選びます。

期限のないトークンは、一覧から削除するまで機能します。スクリプトや別のサービスに渡すトークンには、期間を指定することをお勧めします。

## Expiration date {#token-expiresAt}

**Expires** が **Custom** の場合に表示されます。

トークンが機能しなくなる日時で、ブラウザーのタイムゾーンで指定します。この時点は未来である必要があります。すでに期限切れになるトークンはサーバーが拒否します。
