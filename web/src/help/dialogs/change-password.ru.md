# Сменить пароль

Задает новый пароль для входа в Semaphore по логину и паролю. Новый пароль вступает в силу после
нажатия **Сохранить**. У внешнего пользователя, который входит через LDAP или OpenID Connect, здесь
нет пароля, который можно сменить.

## Current password {#changePassword-currentPassword}

Показывается, когда вы меняете свой собственный пароль.

Ваш текущий пароль. Поле обязательное: Semaphore проверяет его, прежде чем задать новый, чтобы
украденную сессию или API-токен нельзя было превратить в ваш пароль. Сервер отклоняет изменение,
если пароль не совпадает.

Администратор или менеджер пользователей, который сбрасывает пароль другого пользователя, не видит
этого поля.

## Пароль {#changePassword-password}

Новый пароль. Поле обязательное. Нажмите на значок глаза, чтобы показать введенный текст.

Semaphore хранит только хеш пароля.
