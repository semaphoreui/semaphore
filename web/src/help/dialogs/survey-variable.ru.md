# Переменная опроса

Переменная опроса — это вопрос, который диалог задачи задает при каждом запуске шаблона. Ответ
доходит до задачи как переменная: дополнительная переменная для Ansible, `-var` для Terraform и
OpenTofu, аргумент для скрипта или переменная окружения. Переменная сохраняется вместе с
шаблоном, когда вы сохраняете диалог шаблона. Этот же диалог изменяет опрос workflow, где тип
**Secret** не предлагается.

## Имя {#surveyVarDialog-name}

Имя, под которым задача получает ответ: имя дополнительной переменной, переменной Terraform,
аргумента `name=value` скрипта или переменной окружения. Пробелы по краям отбрасываются. Поле
обязательное.

Используйте имя, которого нет у других переменных опроса и которое принимает инструмент,
например `app_version`. Ответ заменяет переменную с тем же именем из группы переменных шаблона.

## Название {#surveyVarDialog-title}

Подпись поля в диалоге задачи, например `Version to deploy`. Это также текст метки переменной в
диалоге шаблона. Поле обязательное.

## Описание {#surveyVarDialog-description}

Необязательное поле. Подсказка, которая показывается под полем диалога задачи, пока оно в фокусе:
что вводить или пример.

## Тип {#surveyVarDialog-type}

Какой ответ запрашивает диалог задачи:

- **String**: одна строка текста. Это значение по умолчанию.
- **Integer**: только цифры; диалог задачи отклоняет все остальное, в том числе знак минуса. Ответ
  все равно доходит до задачи как текст: преобразуйте его в плейбуке, например с помощью `| int`.
- **Secret**: текст, который диалог задачи маскирует. Ответ не сохраняется вместе с задачей,
  поэтому при повторном запуске он запрашивается снова, а Ansible получает его в файле,
  зашифрованном vault. У секрета нет значения по умолчанию.
- **Enum**: одно значение, выбранное из списка, который вы задаете ниже.
- **Text**: несколько строк текста.
- **Select**: несколько значений, выбранных из списка, который вы задаете ниже. Задача получает
  их как список; в аргументе, `-var` или переменной окружения список записывается как JSON,
  например `["a","b"]`.

При смене типа значение по умолчанию очищается, а тип без списка очищает значения.

## Pass variable as {#surveyVarDialog-target}

Как ответ доходит до задачи:

- **Extra variable**: обычный для инструмента способ. Ansible получает его как дополнительную
  переменную, Terraform и OpenTofu — как `-var name=value`, скрипт Bash, PowerShell или Python —
  как аргумент `name=value` после скрипта.
- **Environment variable**: переменная окружения процесса, `name=value`, для любого вида шаблона.
  Тогда переменная не передается другим способом.

## Ключ {#surveyVarDialog-valueName}

Показывается, когда выбран тип **Enum** или **Select**.

Текст, который диалог задачи показывает для этого значения в списке. Каждому значению нужен ключ,
и ключи должны различаться: иначе диалог отказывается сохранять переменную.

## Значение {#surveyVarDialog-valueValue}

Показывается, когда выбран тип **Enum** или **Select**.

Что получает задача, когда выбрано это значение. Оно может отличаться от своего ключа: ключ
`Production` может передавать `prod`.

## Add Value {#surveyVarDialog-addValue}

Показывается, когда выбран тип **Enum** или **Select**.

Добавляет пустую строку в список значений. Для **Enum** или **Select** нужно хотя бы одно
значение. Значок корзины в строке удаляет ее.

## Default value {#surveyVarDialog-defaultValue}

Показывается для любого типа, кроме **Secret**.

Ответ, который диалог задачи заполняет при открытии; там его можно изменить. Для **Enum**
выберите одно из значений, для **Select** — любое их количество. Оставьте поле пустым, чтобы
начинать с пустого ответа.

Значение по умолчанию заполняет только диалог задачи. Задача, запущенная другим способом,
например через API, не получает значения по умолчанию.

## Обязательно {#surveyVarDialog-required}

Диалог задачи не запускает задачу, пока у переменной нет ответа. Как и значение по умолчанию, эту
проверку выполняет только диалог задачи, а не сервер.
