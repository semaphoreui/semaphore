# Редактировать Secret Storage

Хранилище секретов — это внешний менеджер секретов, в котором Semaphore хранит секреты и из
которого их читает: HashiCorp Vault, OpenBao, Devolutions Server, AWS Secrets Manager или Azure
Key Vault. Группа переменных, созданная с хранилищем, хранит в нем свои секреты, а хранилище с
включенной синхронизацией импортирует свои секреты в раздел «Хранилище ключей» проекта. Вид
хранилища выбирается в меню **New Storage** и не может быть изменен в этом диалоге; поля ниже
зависят от него.

## Имя {#secretStorage-name}

Имя, под которым хранилище показано на вкладке **Storages** раздела «Хранилище ключей» и в списке
выбора **Secret storage** новой группы переменных. Поле обязательное.

## Server URL {#secretStorage-vaultURL}

Показывается, когда хранилище — это HashiCorp Vault, OpenBao или Devolutions Server.

Адрес сервера со схемой, например `https://vault.example.com:8200`. Поле обязательное.

## Mount {#secretStorage-vaultMount}

Показывается, когда хранилище — это HashiCorp Vault или OpenBao. Необязательное поле.

Путь монтирования механизма секретов, в котором хранятся секреты. Оставьте поле пустым, чтобы
использовать `secret` — значение по умолчанию.

## Namespace {#secretStorage-vaultNamespace}

Показывается, когда хранилище — это HashiCorp Vault или OpenBao. Необязательное поле.

Пространство имен, в котором находятся секреты. Пространства имен есть в Vault Enterprise и HCP
Vault Dedicated, а также в OpenBao начиная с версии 2.3. Оставьте поле пустым для сервера без
пространств имен.

## Источник секрета {#secretSource-options}

Показывается для любого вида хранилища над секретом, с которым входит Semaphore: **Token** для
Vault или OpenBao, секрет приложения для Devolutions Server, секретный ключ для AWS, секрет
клиента для Azure.

Откуда Semaphore берет этот секрет:

- **Store in DB**: вы вводите секрет в этом диалоге; Semaphore шифрует его и хранит в своей базе
  данных.
- **From ENV**: вы вводите имя переменной окружения сервера Semaphore; секрет читается из нее при
  каждом использовании хранилища.
- **From File**: вы вводите абсолютный путь к файлу на сервере Semaphore; секрет читается из него
  каждый раз, без завершающего перевода строки. Файл должен находиться внутри каталога секретов
  сервера (`dirs.secrets` в конфигурации, по умолчанию `/tmp/semaphore`), а путь с `..`
  отклоняется.

При переключении источника поле под ним очищается.

## Token {#secretStorage-vaultToken}

Показывается, когда хранилище — это HashiCorp Vault или OpenBao, а источник секрета —
**Store in DB**.

Токен, с которым Semaphore проходит аутентификацию на сервере. Он должен давать право читать
секреты, а если хранилище не **Read only**, то и записывать и удалять их.

Для нового хранилища поле обязательное. Когда вы открываете существующее хранилище, поле пустое:
оставьте его пустым, чтобы сохранить хранимый токен, или введите новый, чтобы заменить его.

## Env var name / Path to the file {#secretStorage-vaultTokenSource}

Показывается, когда хранилище — это HashiCorp Vault или OpenBao, а источник секрета —
**From ENV** или **From File**.

Имя переменной окружения или путь к файлу, где хранится токен. Для нового хранилища поле
обязательное.

## Skip TLS certificate verification {#secretStorage-dvlsInsecureTls}

Показывается, когда хранилище — это Devolutions Server.

Semaphore подключается к серверу, не проверяя его TLS-сертификат. Тогда любой, кто находится между
Semaphore и сервером, может прочитать секреты. Оставьте параметр выключенным и вместо этого выдайте
серверу сертификат, которому доверяет Semaphore.

## Vault ID {#secretStorage-dvlsKey}

Показывается, когда хранилище — это Devolutions Server.

ID хранилища (vault) Devolutions Server, в котором находятся секреты. Для нового хранилища поле
обязательное.

## App Key {#secretStorage-dvlsAppKey}

Показывается, когда хранилище — это Devolutions Server.

Ключ приложения той учетной записи приложения, с которой входит Semaphore, — той, чей секрет
указывается в поле **Secret**. Для нового хранилища поле обязательное.

## Secret {#secretStorage-dvlsSecret}

Показывается, когда хранилище — это Devolutions Server, а источник секрета — **Store in DB**.

Секрет приложения для учетной записи приложения из поля **App Key**. Для нового хранилища поле
обязательное. Когда вы открываете существующее хранилище, поле пустое: оставьте его пустым, чтобы
сохранить хранимый секрет, или введите новый, чтобы заменить его.

## Env var name / Path to the file {#secretStorage-dvlsEnv}

Показывается, когда хранилище — это Devolutions Server, а источник секрета — **From ENV** или
**From File**.

Имя переменной окружения или путь к файлу, где хранится секрет приложения. Для нового хранилища
поле обязательное.

## Region {#secretStorage-awsRegion}

Показывается, когда хранилище — это AWS Secrets Manager.

Регион AWS, в котором находятся секреты, например `us-east-1`. Поле обязательное.

## Endpoint URL {#secretStorage-awsEndpointURL}

Показывается, когда хранилище — это AWS Secrets Manager. Необязательное поле.

Адрес API Secrets Manager, к которому нужно обращаться вместо endpoint региона по умолчанию,
например VPC endpoint. Оставьте поле пустым, чтобы использовать endpoint AWS по умолчанию.

## Use IAM Role / Instance Profile {#secretStorage-awsUseIamRole}

Показывается, когда хранилище — это AWS Secrets Manager.

Когда параметр включен, Semaphore не хранит ключ доступа и берет учетные данные AWS из окружения,
в котором работает сервер, например из IAM-роли его инстанса. Поля ключа доступа ниже тогда
недоступны.

При включении параметра хранимый ключ доступа удаляется при сохранении. Чтобы снова выключить
его, нужен новый **Secret Access Key**.

## Access Key ID {#secretStorage-awsAccessKeyId}

Показывается, когда хранилище — это AWS Secrets Manager. Недоступно, когда включено
**Use IAM Role / Instance Profile**.

ID ключа доступа, с которым входит Semaphore, например `AKIAIOSFODNN7EXAMPLE`. Поле обязательное,
когда IAM-роль выключена. ID не является секретом: он хранится и показывается как есть.

## Secret Access Key {#secretStorage-awsSecretKey}

Показывается, когда хранилище — это AWS Secrets Manager, а источник секрета — **Store in DB**.
Недоступно, когда включено **Use IAM Role / Instance Profile**.

Секрет ключа доступа. Поле обязательное для нового хранилища и после выключения IAM-роли. В
остальных случаях оно пустое, когда вы открываете хранилище: оставьте его пустым, чтобы сохранить
хранимый ключ, или введите новый, чтобы заменить его.

## Env var name / Path to the file {#secretStorage-awsSecretKeySource}

Показывается, когда хранилище — это AWS Secrets Manager, а источник секрета — **From ENV** или
**From File**. Недоступно, когда включено **Use IAM Role / Instance Profile**.

Имя переменной окружения или путь к файлу, где хранится секретный ключ доступа. Поле обязательное
в тех же случаях, что и **Secret Access Key**.

## Vault URL {#secretStorage-azureVaultURL}

Показывается, когда хранилище — это Azure Key Vault.

Адрес хранилища ключей, например `https://my-vault.vault.azure.net`. Поле обязательное.

## Tenant ID {#secretStorage-azureTenantId}

Показывается, когда хранилище — это Azure Key Vault.

ID клиента (tenant) Microsoft Entra для приложения, от имени которого входит Semaphore. Поле
обязательное.

## Client ID {#secretStorage-azureClientId}

Показывается, когда хранилище — это Azure Key Vault.

ID приложения (клиента) этого приложения. Ему нужен доступ к секретам хранилища ключей. Поле
обязательное.

## Client Secret {#secretStorage-azureClientSecret}

Показывается, когда хранилище — это Azure Key Vault, а источник секрета — **Store in DB**.

Секрет клиента приложения. Для нового хранилища поле обязательное. Когда вы открываете
существующее хранилище, поле пустое: оставьте его пустым, чтобы сохранить хранимый секрет, или
введите новый, чтобы заменить его.

## Env var name / Path to the file {#secretStorage-azureClientSecretSource}

Показывается, когда хранилище — это Azure Key Vault, а источник секрета — **From ENV** или
**From File**.

Имя переменной окружения или путь к файлу, где хранится секрет клиента. Для нового хранилища поле
обязательное.

## Read only {#secretStorage-readonly}

Когда параметр включен, Semaphore только читает из хранилища. Секрет группы переменных нельзя
создать или изменить в нем: сохранение завершается ошибкой. При удалении секрета, ключа или группы
переменных в Semaphore их секрет остается в хранилище.

Когда параметр выключен, Semaphore записывает в хранилище секреты групп переменных, которые его
используют, и удаляет их оттуда вместе с группами.

## Sync keys enabled {#secretStorage-syncEnabled}

Включите параметр, чтобы импортировать секреты из хранилища в раздел «Хранилище ключей» проекта
по путям, заданным в **Sync paths**. Импорт выполняется, когда вы нажимаете кнопку синхронизации
хранилища на вкладке **Storages**, а также автоматически с интервалом, заданным в **Sync paths**.

Импортированный ключ отмечается как синхронизированный: его имя и тип нельзя изменить, а при его
удалении в Semaphore секрет остается в хранилище. Удаление хранилища при включенной синхронизации
удаляет и импортированные им ключи.

## Sync paths {#secretStorage-syncPaths}

Показывается, когда включено **Sync keys enabled**.

Открывает диалог с путями хранилища, из которых выполняется импорт, и интервалом автоматического
импорта. Число на кнопке — это количество путей. Кнопка синхронизации хранилища остается
недоступной, пока не задан хотя бы один путь.

В диалоге есть только кнопка **Закрыть**: то, что вы в нем изменяете, сохраняется вместе с
хранилищем кнопкой **Сохранить** этого диалога (**Создать** для нового хранилища).
