# Редактировать Proxy

Прокси — это хост, через который задачи проекта достигают серверов, к которым не могут подключиться
напрямую. Выберите его в поле **Proxy** репозитория, чтобы получать репозиторий через него, или
инвентаря, чтобы Ansible подключался через него к хостам.

## Имя {#proxyForm-name}

Обязательно и уникально в проекте. Репозитории и инвентари показывают прокси под этим именем.

## Тип {#proxyForm-type}

- **SSH (jump host)**: Semaphore подключается к хосту по SSH и оттуда открывает соединение с
  сервером. Только этот тип может требовать другой прокси.
- **SOCKS5**, **HTTP**, **HTTPS**: прокси-сервер, который передаёт соединение. Git сам использует
  его для репозитория `https`; SSH-соединение Semaphore проводит через него, поэтому другие
  инструменты устанавливать не нужно.

## Host {#proxyForm-host}

Обязательно. Имя хоста или IP-адрес, без пользователя, порта и схемы. Имя хоста может содержать
только буквы, цифры, точки, дефисы и подчёркивания.

## Port {#proxyForm-port}

Необязательно, от 1 до 65535. Пустое значение означает `22` для SSH jump host. Для остальных типов
укажите порт: без него Git и SSH-соединения предполагают разные порты.

## User {#proxyForm-user}

Только SSH: логин на jump host. Пустое значение означает пользователя, от имени которого работает
Semaphore. Буквы, цифры, точки, дефисы и подчёркивания, без дефиса в начале. Прокси SOCKS5 или HTTP
берёт логин из поля **Ключ доступа**.

## Ключ доступа {#proxyForm-sshKeyId}

Необязательно. Ключ из хранилища ключей, с которым выполняется вход на сам прокси, обычно не ключ
серверов за ним:

- **SSH ключ** для SSH jump host;
- **Логин с паролем** для SOCKS5, HTTP и HTTPS. Пароль передаётся через окружение, никогда через
  командную строку.

## Requires Proxy {#proxyForm-requiresProxyId}

Только SSH, необязательно. Другой SSH-прокси проекта, через который нужно пройти сначала, для jump
host, доступного только с другого. Цепочка содержит не более 5 прокси и не может возвращаться к
прокси, который уже в ней есть.
