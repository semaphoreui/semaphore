# New Token

API 토큰을 사용하면 스크립트나 다른 서비스가 계정과 같은 권한으로 사용자를 대신하여 Semaphore API를 호출할 수
있습니다. 요청의 `Authorization` 헤더에 `Bearer`와 토큰을 넣어 보내세요. 토큰은 만든 직후 한 번만 표시되므로,
그때 복사하세요.

## Token Name {#token-name}

선택 사항입니다. 토큰 목록에서 토큰을 구별하는 이름입니다. 예: 토큰을 사용하는 스크립트의 이름. 토큰의 일부가
아니며 토큰이 할 수 있는 일을 바꾸지 않습니다.

## Expires {#token-expires}

토큰이 작동을 멈추는 시점입니다. 지금부터 계산되는 기간을 선택하거나, 삭제될 때까지 작동하는 토큰에는 **Never**를,
시점을 직접 선택하려면 **Custom**을 선택하세요.

만료되지 않는 토큰은 목록에서 삭제할 때까지 작동합니다. 스크립트나 다른 서비스에 주는 토큰에는 기간을 지정하는
것이 좋습니다.

## Expiration date {#token-expiresAt}

**Expires**가 **Custom**일 때 표시됩니다.

토큰이 작동을 멈추는 날짜와 시간으로, 브라우저의 시간대 기준입니다. 시점은 미래여야 하며, 서버는 이미 만료되었을
토큰을 거부합니다.
