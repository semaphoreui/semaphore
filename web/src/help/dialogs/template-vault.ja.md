# ボールト

ボールトは、プレイブックのリポジトリで Ansible Vault によって暗号化されたファイルと変数のパスワードを Ansible に渡します。テンプレートの各ボールトは、`ansible-playbook` の `--vault-id` オプション 1 つになります。ボールトは、テンプレートのダイアログを保存したときにテンプレートとともに保存されます。

## ボールトID {#templateVaultDialog-name}

任意です。パスワードの対象となる Vault ID で、内容の暗号化に使われたラベルです (`ansible-vault encrypt --vault-id prod@prompt`)。Vault ID `default` にする場合は空のままにします。

ID は小文字で保存されます。テンプレートの各ボールトには独自の ID が必要で、空にできるのは 1 つだけです。

## タイプ {#templateVaultDialog-type}

パスワードの取得元です。

- **パスワード**: キーのストアのキーです。Ansible がパスワードを求めたときに Semaphore がそれを入力するため、パスワードがファイルに書き込まれることはありません。
- **クライアントスクリプト**: パスワードを出力する Vault パスワードクライアントスクリプトです。Ansible がそれを実行します。

## ボールトパスワード {#templateVaultDialog-vaultKeyId}

タイプが **パスワード** の場合に表示されます。

Vault のパスワードを保持するキーです。**パスワードでログイン** タイプのキーだけが一覧表示されます。Semaphore はそのパスワードを使い、ログインは無視します。このフィールドは必須です。

## スクリプトパス {#templateVaultDialog-script}

タイプが **クライアントスクリプト** の場合に表示されます。

スクリプトへのパスです。例: `scripts/vault-pass-client.py`。相対パスは、Ansible が実行されるディレクトリからのパスです。リポジトリのルート、またはテンプレートに作業ディレクトリがある場合はそのディレクトリです。このフィールドは必須です。

ファイル名は、拡張子の有無にかかわらず `-client` で終わる必要があります。そうなっている場合にのみ、Ansible はファイルをクライアントスクリプトとして実行し、`--vault-id` で Vault ID を渡します。スクリプトは、タスクを実行するマシン上で、Semaphore が実行されているユーザーとして実行されます。
