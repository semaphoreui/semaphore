# Edit mapping

매핑은 SSH 호스트나 Git URL에 키 저장소의 어떤 자격 증명을 사용할지 Semaphore에 알려 줍니다. 리포지토리에는
키가 하나뿐이지만, 작업은 다른 서버에도 접근할 수 있습니다. 서브모듈, `requirements.yml`의 롤과 컬렉션,
Terraform 모듈, 인벤토리 리포지토리 등이 그렇습니다. 프로젝트의 매핑은 그 프로젝트 작업의 모든 Git 및 SSH
연결과, Semaphore가 프로젝트를 위해 실행하는 Git 명령(예: 리포지토리의 새 커밋 확인)에 적용됩니다.
리포지토리의 파일은 변경되지 않습니다.

## 유형 {#hostConfigForm-type}

매핑이 일치시키는 대상입니다.

- **Host**: SSH 호스트 이름입니다. 작업이 그 호스트에 연결하는 모든 SSH 연결에 매핑의 키가 사용됩니다.
  SSH를 통한 Git, 그리고 그 이름의 인벤토리 호스트에 연결하는 Ansible이 해당합니다. 같은 호스트에 대해서는
  매핑이 서버의 SSH 구성보다 우선합니다.
- **URL**: Git URL 또는 그 앞부분입니다. Git은 그 URL 아래의 모든 리포지토리에 매핑의 자격 증명으로
  연결합니다.

**Host**로 전환하면 호스트 매핑에서 사용할 수 없는 **Credential**이 지워집니다.

## Host 또는 URL {#hostConfigForm-host}

이 필드는 필수입니다. 각 호스트나 URL마다 유형별로 매핑을 하나만 만들 수 있습니다.

**Host**의 경우: Git이나 Ansible이 연결하는 그대로의 호스트 이름입니다. 예: `github.com` 또는
`10.0.0.21`. 문자, 숫자, 점, 하이픈, 밑줄만 사용할 수 있으며 사용자, 포트, 와일드카드는 사용할 수 없습니다.

**URL**의 경우: `https://` 또는 `http://`로 시작하는 주소로, 로그인이 들어 있지 않고 공백, 따옴표, `=`가
없어야 합니다. 리포지토리 전체를 지정하거나, 여러 리포지토리를 포함하려면 `/`로 끝나는 접두사를 지정하세요.

```
https://github.com/acme/
https://github.com/acme/infra.git
```

여러 매핑이 일치하면 가장 긴 매핑이 우선합니다. 위의 리포지토리 매핑은 그 하나의 리포지토리에 대해
`acme` 매핑을 재정의합니다.

SSH 키를 사용하면 URL 매핑은 URL에 지정된 포트와 관계없이 Git이 URL의 호스트에 포트 `22`로 SSH 연결을 하게
합니다.

## Credential {#hostConfigForm-sshKeyId}

매핑이 일치하는 연결에 사용되는 키 저장소의 키입니다. 이 필드는 필수입니다.

- **Host**는 **SSH 키**만 허용합니다. 키에 로그인이 있으면 SSH는 그 사용자로 연결합니다.
- **URL**은 **SSH 키** 또는 **비밀번호로 로그인**을 허용합니다. SSH 키는 그 로그인으로 연결하며, 로그인이
  없으면 `git`으로 연결합니다. 비밀번호로 로그인은 `https://` URL에서만 작동합니다. 토큰을 사용하려면 토큰을
  비밀번호에 넣고 로그인은 비워 두세요.

비밀번호로 로그인은 명령줄이 아니라 환경을 통해 Git에 전달되며, 작업 로그에는 원래 URL만 표시됩니다.
