# Редагувати Secret Storage

Сховище секретів — це зовнішній менеджер секретів, у якому Semaphore зберігає секрети і з якого
їх зчитує: HashiCorp Vault, OpenBao, Devolutions Server, AWS Secrets Manager або Azure Key Vault.
Група змінних, створена зі сховищем, зберігає в ньому свої секрети, а сховище з увімкненою
синхронізацією імпортує свої секрети до «Сховища ключів» проєкту. Вид сховища вибирається в меню
**New Storage** і не може бути змінений у цьому діалозі; поля нижче залежать від нього.

## Назва {#secretStorage-name}

Назва, під якою сховище відображається на вкладці **Storages** «Сховища ключів» і в списку вибору
**Secret storage** нової групи змінних. Поле обов’язкове.

## Server URL {#secretStorage-vaultURL}

Відображається, коли сховище — HashiCorp Vault, OpenBao або Devolutions Server.

Адреса сервера зі схемою, наприклад `https://vault.example.com:8200`. Поле обов’язкове.

## Mount {#secretStorage-vaultMount}

Відображається, коли сховище — HashiCorp Vault або OpenBao. Необов’язкове поле.

Шлях монтування механізму секретів, який містить секрети. Залиште поле порожнім, щоб використати
`secret` — значення за замовчуванням.

## Namespace {#secretStorage-vaultNamespace}

Відображається, коли сховище — HashiCorp Vault або OpenBao. Необов’язкове поле.

Простір імен, у якому розміщено секрети. Простори імен є у Vault Enterprise і HCP Vault Dedicated,
а також в OpenBao починаючи з версії 2.3. Залиште поле порожнім для сервера без просторів імен.

## Джерело секрету {#secretSource-options}

Відображається для кожного виду сховища над секретом, з яким входить Semaphore: **Token** для
Vault або OpenBao, секрет застосунку для Devolutions Server, секретний ключ для AWS, секрет
клієнта для Azure.

Звідки Semaphore бере цей секрет:

- **Store in DB**: ви вводите секрет у цьому діалозі; Semaphore шифрує його і зберігає у своїй
  базі даних.
- **From ENV**: ви вводите назву змінної середовища сервера Semaphore; секрет зчитується з неї
  щоразу, коли використовується сховище.
- **From File**: ви вводите абсолютний шлях до файлу на сервері Semaphore; секрет щоразу
  зчитується з нього без кінцевого розриву рядка. Файл має бути всередині каталогу секретів
  сервера (`dirs.secrets` у конфігурації, за замовчуванням `/tmp/semaphore`), а шлях із `..`
  відхиляється.

Перемикання джерела очищає поле під ним.

## Token {#secretStorage-vaultToken}

Відображається, коли сховище — HashiCorp Vault або OpenBao, а джерело секрету —
**Store in DB**.

Токен, з яким Semaphore автентифікується на сервері. Він має дозволяти читати секрети, а якщо
сховище не **Read only**, — також записувати і видаляти їх.

Поле обов’язкове для нового сховища. Коли ви відкриваєте наявне сховище, воно порожнє: залиште
його порожнім, щоб зберегти збережений токен, або введіть новий, щоб його замінити.

## Env var name / Path to the file {#secretStorage-vaultTokenSource}

Відображається, коли сховище — HashiCorp Vault або OpenBao, а джерело секрету —
**From ENV** або **From File**.

Назва змінної середовища або шлях до файлу, що містить токен. Поле обов’язкове для нового
сховища.

## Skip TLS certificate verification {#secretStorage-dvlsInsecureTls}

Відображається, коли сховище — Devolutions Server.

Semaphore під’єднується до сервера, не перевіряючи його TLS-сертифікат. Тоді будь-хто між
Semaphore і сервером може прочитати секрети. Залиште це вимкненим, а натомість видайте серверу
сертифікат, якому довіряє Semaphore.

## Vault ID {#secretStorage-dvlsKey}

Відображається, коли сховище — Devolutions Server.

ID сховища (vault) Devolutions Server, яке містить секрети. Поле обов’язкове для нового сховища.

## App Key {#secretStorage-dvlsAppKey}

Відображається, коли сховище — Devolutions Server.

Ключ застосунку для ідентичності застосунку, з якою входить Semaphore, — тієї, чий секрет
вводиться в **Secret**. Поле обов’язкове для нового сховища.

## Secret {#secretStorage-dvlsSecret}

Відображається, коли сховище — Devolutions Server, а джерело секрету — **Store in DB**.

Секрет застосунку для ідентичності застосунку з **App Key**. Поле обов’язкове для нового
сховища. Коли ви відкриваєте наявне сховище, воно порожнє: залиште його порожнім, щоб зберегти
збережений секрет, або введіть новий, щоб його замінити.

## Env var name / Path to the file {#secretStorage-dvlsEnv}

Відображається, коли сховище — Devolutions Server, а джерело секрету — **From ENV** або
**From File**.

Назва змінної середовища або шлях до файлу, що містить секрет застосунку. Поле обов’язкове для
нового сховища.

## Region {#secretStorage-awsRegion}

Відображається, коли сховище — AWS Secrets Manager.

Регіон AWS, у якому розміщено секрети, наприклад `us-east-1`. Поле обов’язкове.

## Endpoint URL {#secretStorage-awsEndpointURL}

Відображається, коли сховище — AWS Secrets Manager. Необов’язкове поле.

Адреса API Secrets Manager, яку слід викликати замість стандартної кінцевої точки регіону,
наприклад кінцева точка VPC. Залиште поле порожнім, щоб використати стандартну кінцеву точку AWS.

## Use IAM Role / Instance Profile {#secretStorage-awsUseIamRole}

Відображається, коли сховище — AWS Secrets Manager.

Коли ввімкнено, Semaphore не зберігає ключ доступу і бере облікові дані AWS із середовища, в
якому працює сервер, наприклад з IAM-ролі його інстансу. Поля ключа доступу нижче тоді
неактивні.

Увімкнення видаляє збережений ключ доступу під час збереження. Щоб знову вимкнути цю опцію,
потрібен новий **Secret Access Key**.

## Access Key ID {#secretStorage-awsAccessKeyId}

Відображається, коли сховище — AWS Secrets Manager. Неактивне, коли ввімкнено
**Use IAM Role / Instance Profile**.

ID ключа доступу, з яким входить Semaphore, наприклад `AKIAIOSFODNN7EXAMPLE`. Поле обов’язкове,
коли IAM-роль вимкнено. ID не є секретом: він зберігається і показується як є.

## Secret Access Key {#secretStorage-awsSecretKey}

Відображається, коли сховище — AWS Secrets Manager, а джерело секрету — **Store in DB**.
Неактивне, коли ввімкнено **Use IAM Role / Instance Profile**.

Секрет ключа доступу. Поле обов’язкове для нового сховища і після вимкнення IAM-ролі. В інших
випадках воно порожнє, коли ви відкриваєте сховище: залиште його порожнім, щоб зберегти
збережений ключ, або введіть новий, щоб його замінити.

## Env var name / Path to the file {#secretStorage-awsSecretKeySource}

Відображається, коли сховище — AWS Secrets Manager, а джерело секрету — **From ENV** або
**From File**. Неактивне, коли ввімкнено **Use IAM Role / Instance Profile**.

Назва змінної середовища або шлях до файлу, що містить секретний ключ доступу. Поле обов’язкове в
тих самих випадках, що й **Secret Access Key**.

## Vault URL {#secretStorage-azureVaultURL}

Відображається, коли сховище — Azure Key Vault.

Адреса сховища ключів, наприклад `https://my-vault.vault.azure.net`. Поле обов’язкове.

## Tenant ID {#secretStorage-azureTenantId}

Відображається, коли сховище — Azure Key Vault.

ID тенанта Microsoft Entra застосунку, від імені якого входить Semaphore. Поле обов’язкове.

## Client ID {#secretStorage-azureClientId}

Відображається, коли сховище — Azure Key Vault.

ID застосунку (клієнта) цього застосунку. Він потребує доступу до секретів сховища ключів. Поле
обов’язкове.

## Client Secret {#secretStorage-azureClientSecret}

Відображається, коли сховище — Azure Key Vault, а джерело секрету — **Store in DB**.

Секрет клієнта застосунку. Поле обов’язкове для нового сховища. Коли ви відкриваєте наявне
сховище, воно порожнє: залиште його порожнім, щоб зберегти збережений секрет, або введіть новий,
щоб його замінити.

## Env var name / Path to the file {#secretStorage-azureClientSecretSource}

Відображається, коли сховище — Azure Key Vault, а джерело секрету — **From ENV** або
**From File**.

Назва змінної середовища або шлях до файлу, що містить секрет клієнта. Поле обов’язкове для
нового сховища.

## Read only {#secretStorage-readonly}

Коли ввімкнено, Semaphore лише читає зі сховища. Секрет групи змінних не можна в ньому створити
чи змінити: збереження завершується з помилкою. Видалення секрету, ключа або групи змінних у
Semaphore залишає їхній секрет у сховищі.

Коли вимкнено, Semaphore записує в сховище секрети груп змінних, які його використовують, і
видаляє їх звідти разом із групами.

## Sync keys enabled {#secretStorage-syncEnabled}

Увімкніть, щоб імпортувати секрети зі сховища до «Сховища ключів» проєкту зі шляхів, заданих у
**Sync paths**. Імпорт виконується, коли ви натискаєте кнопку синхронізації сховища на вкладці
**Storages**, а також автоматично з інтервалом, заданим у **Sync paths**.

Імпортований ключ позначається як синхронізований: його назву і тип змінити не можна, а його
видалення в Semaphore залишає секрет у сховищі. Видалення сховища з увімкненою синхронізацією
видаляє також імпортовані ним ключі.

## Sync paths {#secretStorage-syncPaths}

Відображається, коли ввімкнено **Sync keys enabled**.

Відкриває діалог зі шляхами сховища, з яких виконується імпорт, та інтервалом автоматичного
імпорту. Число на кнопці — це кількість шляхів. Кнопка синхронізації сховища залишається
неактивною, доки немає принаймні одного шляху.

Діалог має лише **Закрити**: те, що ви в ньому змінюєте, зберігається разом зі сховищем кнопкою
**Зберегти** цього діалогу (**Створити** для нового сховища).
