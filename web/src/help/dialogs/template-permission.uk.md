# Права шаблону

Надає ролі додаткові права на цей окремий шаблон. Учасник із цією роллю отримує їх на додачу до
прав, які роль має в усьому проєкті: надання тут лише додає, воно ніколи не забирає права.
Учасник із кількома ролями отримує кожне право, надане будь-якій із них.

## Роль {#templatePerm-roleSlug}

Роль, яка отримує права. Список показує ролі цього проєкту, спільні ролі та вбудовані ролі. Поле
обов’язкове, і роль може мати лише одне надання на шаблон: сервер відхиляє друге.

Роль збереженого надання змінити не можна. Сервер зберігає роль і записує лише права, що б ви тут
не вибрали. Щоб надати права іншій ролі, видаліть це надання зі списку і додайте нове.

## Права {#templatePerm-permissionsTitle}

Що учасник із цією роллю може робити з цим шаблоном:

- **Can see this template**: шаблон є у списку шаблонів разом із його завданнями та їхніми
  логами.
- **Can run this template**: запускати завдання із шаблону, а також зупиняти, підтверджувати або
  відхиляти його завдання.
- **Can edit this template**: змінювати й видаляти шаблон, зупиняти всі його завдання і керувати
  цими правами.

Запуск або редагування включає перегляд шаблону: коли ви позначаєте будь-яке з них,
**Can see this template** теж позначається, і його не можна зняти. Залиште всі прапорці
знятими, щоб зберегти надання, яке нічого не дає.
