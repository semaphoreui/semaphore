# Workflow permissions

Дает роли дополнительные права на этот workflow. Участник с этой ролью получает их в дополнение
к правам, которые роль имеет во всем проекте: выдача прав здесь только добавляет права и никогда
не отбирает их. Участник с несколькими ролями получает все права, выданные любой из них.

## Роль {#templatePerm-roleSlug}

Роль, которая получает права. В списке показаны роли этого проекта, общие роли и встроенные роли.
Поле обязательное, и у роли может быть только одна выдача прав на workflow: вторую сервер
отклоняет.

Роль сохраненной выдачи прав нельзя изменить. Сервер сохраняет роль и записывает только права,
что бы вы здесь ни выбрали. Чтобы дать права другой роли, удалите эту выдачу из списка и добавьте
новую.

## Permissions {#templatePerm-permissionsTitle}

Что участник с этой ролью может делать с этим workflow:

- **Can see this workflow**: workflow есть в списке workflow вместе с его выполнениями.
- **Can run this workflow**: запускать выполнения workflow.
- **Can edit this workflow**: изменять и удалять workflow и управлять этими правами.
- **Can approve this workflow**: одобрять или отклонять шаги одобрения его выполнений.

Запуск, изменение или одобрение включают просмотр workflow: когда вы отмечаете любое из них,
**Can see this workflow** тоже отмечается, и снять его нельзя. Оставьте все флажки снятыми, чтобы
сохранить выдачу, которая ничего не дает.
