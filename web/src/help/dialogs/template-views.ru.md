# Редактировать представления

Представления — это вкладки над списком шаблонов задач. Представление показывает шаблоны, которые
вы в него поместили, или все шаблоны проекта. Диалог сохраняет каждое изменение сразу: кнопки
сохранения для всего диалога нет. Перетащите представление за его маркер, чтобы изменить порядок
вкладок.

## Название {#viewsForm-title}

Имя вкладки. Введите его и подтвердите галочкой рядом с полем; крестик возвращает сохраненное
название. Новое представление сохраняется, когда у него есть название и вы его подтверждаете или
меняете одну из его настроек. Закрытие диалога не сохраняет неподтвержденное название.

Шестеренка открывает настройки представления под его названием.

## Удалить {#viewsForm-viewDelete}

Значок корзины сразу удаляет представление, без вопроса. Шаблоны представления не удаляются: они
остаются в проекте и больше не входят ни в одно представление.

## Type {#viewsForm-type}

Какие шаблоны показывает вкладка:

- **Custom**: шаблоны, в поле **Представление** которых, в диалоге шаблона, указано это
  представление. Это значение по умолчанию.
- **All**: все шаблоны проекта, независимо от их представления.

Участник видит в любом представлении только те шаблоны, которые ему разрешено видеть.

## Sort by {#viewsForm-sortColumn}

Столбец, по которому сортируются шаблоны вкладки; доступен только **Name**. Вкладка без него тоже
сортируется по имени, поэтому поле имеет значение вместе с **Reverse**.

## Reverse {#viewsForm-sortReverse}

Сортирует вкладку в порядке убывания. Работает, только когда задано **Sort by**.

## Hidden {#viewsForm-hidden}

Скрывает вкладку от участников, которые не могут управлять ресурсами проекта. Те, кто может,
по-прежнему видят ее зачеркнутой. Скрытие вкладки не скрывает ее шаблоны: представление типа **All**
по-прежнему их показывает.

## Show task counts {#viewsForm-showTemplateStats}

Показывает на вкладке, сколько ее шаблонов находится в каждом состоянии, одним чипом из цветных
сегментов: зеленый — последняя задача завершилась успешно, красный — с ошибкой, серый — задача
остановлена или шаблон ни разу не запускался, оранжевый — задача ожидает подтверждения, синий —
задача в очереди или выполняется. По умолчанию выключено, и счетчики вычисляются только для
представлений, у которых это включено.

## Добавить представление {#viewsForm-add}

Добавляет представление в конец списка с пустым названием, которое нужно ввести.
