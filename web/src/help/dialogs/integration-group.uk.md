# Редагувати інтеграцію

Інтеграція — це набір запусків, які спрацьовують від одного ендпоінта. Коли запит на URL цього
ендпоінта проходить авторизацію, спрацьовує кожен запуск інтеграції, умови якого приймають запит.

## Назва {#integrationGroupForm-name}

Назва, під якою інтеграцію показано на сторінці «Інтеграції». Поле обов'язкове.

## Ендпоінт {#integrationGroupForm-endpointId}

Ендпоінт, URL якого запускають запуски цієї інтеграції. Один ендпоінт можуть використовувати кілька
інтеграцій. Поле обов'язкове.

## Перевизначити авторизацію {#integrationGroupForm-authOverride}

Залиште вимкненим, щоб запити перевірялися так само, як в ендпоінта. Увімкніть, щоб перевіряти
запити цієї інтеграції власним методом і секретом, заданими в полях, які з'являться нижче;
налаштування ендпоінта тоді до цієї інтеграції не застосовуються.

## Метод авторизації {#integrationAuthForm-authMethod}

Як Semaphore перевіряє, що запит надходить від очікуваного сервісу. Запит, який не пройшов
перевірку, нічого не запускає, і webhook відповідає на нього так само, як на будь-який інший
запит.

- **Немає**: без перевірки. Будь-хто, хто знає URL, може запустити завдання.
- **GitHub Webhooks**: заголовок `X-Hub-Signature-256` має містити підпис HMAC-SHA256 тіла,
  створений із секретом, так, як його надсилає GitHub.
- **Bitbucket Webhooks**: та сама перевірка заголовка `X-Hub-Signature`, так, як його надсилає
  Bitbucket.
- **Token**: заголовок, указаний у **Заголовок авторизації**, має містити сам секрет.
- **HMAC** і **HMAC (SHA-512)**: заголовок, указаний у **Заголовок авторизації**, має містити HMAC-SHA256
  або HMAC-SHA512 тіла, створений із секретом, у шістнадцятковому вигляді малими літерами, без
  префікса на зразок `sha256=`.
- **BasicAuth**: запит має передавати логін і пароль ключа з **Секрет автентифікації** у своєму
  заголовку `Authorization`.

## Заголовок авторизації {#integrationAuthForm-authHeader}

Відображається, коли в полі **Метод авторизації** вибрано **Token**, **HMAC** або **HMAC (SHA-512)**.

Назва заголовка запиту, який передає токен або підпис, наприклад `X-Webhook-Token`. Регістр назви
не має значення. Запит без цього заголовка відхиляється.

## Секрет автентифікації {#integrationAuthForm-authSecretId}

Відображається, коли в полі **Метод авторизації** вибрано не **Немає**.

Ключ зі «Сховища ключів», за яким перевіряється запит. Для **BasicAuth** підходить лише ключ типу
**Логін з паролем**. Для інших методів підходить також ключ типу **Рядок**: перевірка використовує
його значення або пароль ключа **Логін з паролем**.

Поле потрібне для всіх методів, крім **Немає**: без ключа або з порожнім секретом кожен запит
відхиляється.
