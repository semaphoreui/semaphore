# Редактировать исполнителя

Исполнитель — это отдельный процесс `semaphore runner`, который выполняет задачи на своей
собственной машине, а не на сервере Semaphore. Задача передается исполнителю, когда сервер
настроен выполнять задачи на исполнителях или когда у шаблона задачи или его инвентаря есть тег
исполнителя. Тогда сервер выбирает исполнителя, который включен, зарегистрирован, находится в
сети и не достиг своего лимита параллельных задач: сначала исполнителей проекта, затем глобальных
исполнителей, в случайном порядке внутри каждой группы. Если все подходящие исполнители не в сети
или заняты, задача ждет в очереди; если не подходит ни один исполнитель, задача завершается с
ошибкой.

## Имя {#runner-name}

Обязательное поле. Имя, под которым исполнитель показан на странице «Исполнители», например хост,
на котором он работает. Оно не влияет на то, какие задачи получает исполнитель.

## Tags {#runner-tags}

Доступно в Semaphore Pro; в других версиях поле заблокировано.

Теги, по которым выбираются задачи этого исполнителя. Задача с тегом исполнителя передается только
исполнителям с этим тегом; тег шаблона задачи имеет приоритет над тегом инвентаря. Введите тег и
нажмите Enter или выберите тег, который используют другие исполнители. Пустые и повторяющиеся
теги отбрасываются при сохранении.

Исполнителю проекта нужен хотя бы один тег, если не установлен флажок **Is default**.

## Is default {#runner-isDefault}

Задача без тега исполнителя передается только исполнителям, отмеченным как исполнители по
умолчанию. Снимите флажок для исполнителя, который должен брать только задачи с одним из своих
тегов.

Для нового глобального исполнителя флажок установлен, для нового исполнителя проекта — снят.

## Register {#runner-registered}

Показывается при создании исполнителя.

- Флажок установлен (по умолчанию): сервер создает исполнителя вместе с его токеном. После нажатия
  **Создать** диалог показывает токен и команды, которые запускают исполнителя с ним.
- Флажок снят: исполнитель создается без токена. Позже нажмите **Regenerate registration token**
  (значок с двумя стрелками) в строке исполнителя, чтобы получить одноразовый регистрационный
  токен, действительный в течение одного часа, и зарегистрируйте исполнителя командой
  `semaphore runner register`.

Незарегистрированный исполнитель не получает задач.

## Webhook {#runner-webhook}

Необязательное поле. URL, к которому обращается сервер, когда передает задачу этому исполнителю,
например чтобы запустить исполнителя по требованию. Сервер отправляет запрос `POST` с телом JSON:

```json
{"action": "start", "project_id": 1, "task_id": 42, "template_id": 7, "runner_id": 3}
```

URL должен ответить со статусом 200 или 204 в течение 30 секунд; иначе задача завершается с
ошибкой. Исполнитель с webhook всегда считается находящимся в сети, даже если он давно не
опрашивал сервер. Оставьте поле пустым для исполнителя, который работает постоянно.

## Максимальное количество параллельных задач {#runner-maxParallelTasks}

Сколько задач исполнитель может выполнять одновременно. Когда лимит достигнут, следующая задача
передается другому подходящему исполнителю или ждет в очереди. Оставьте поле пустым или укажите
`0`, чтобы не было лимита.

## Включено {#runner-active}

Новые задачи получает только включенный исполнитель. Снимите флажок, чтобы вывести исполнителя из
работы, не удаляя его; переключатель в списке исполнителей делает то же самое.

Для нового исполнителя флажок снят: установите его или включите исполнителя позже в списке.
