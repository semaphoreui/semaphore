# Run Workflow

在您回答工作流程的調查之後，啟動工作流程的一次執行。此對話方塊只會為有調查的工作流程開啟：沒有調查的工作流程會立即啟動。按下
**Run** 後，會開啟新執行的頁面；若伺服器拒絕這些值，對話方塊會保持開啟並保留您的答案。

## Variables {#workflowRunDialog-survey}

工作流程調查中的每個變數各有一個欄位，依調查的順序排列，並填入其預設值。標有 `*` 的欄位為必填，Integer 欄位只接受數字，
清單欄位接受一個值，若變數允許多個值，則可接受任意數量的值。在每個欄位都有效之前，**Run** 不會啟動任何東西。

這些值會隨執行一起儲存，並顯示在其頁面的 **Variables** 之下。工作流程的任務不會自動取得它們：只有當任務的節點將其範本的某個變數繫結到工作流程的變數時，
該變數才會取得值。單靠名稱相同不會傳遞任何值。

工作流程調查不保存機密值，因為執行會以明文保存其值。請改將密碼和權杖放在金鑰或變數群組中。
