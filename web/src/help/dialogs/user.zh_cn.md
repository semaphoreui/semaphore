# 编辑用户

用户是登录 Semaphore 的账户。**Settings** 标签页包含账户的个人资料及其标志；**保存**会写入它们。**Security**
标签页包含密码、双因素认证和已关联的登录账户，**Roles** 标签页包含用户的全局角色：这两个标签页中的操作会立即生效，无需**保存**。
用户在项目内可以执行的操作是在该项目的**团队**页面中设置的，而不是在这里。

## 名称 {#user-name}

用户的全名，显示在侧边栏以及用户列表和项目成员列表中。此字段为必填项。

对于**外部**用户，如果身份提供方在登录时发送了名称，Semaphore 会采用该名称，因此在这里所做的更改可能在下次登录后失效。

## 用户名 {#user-username}

用户的登录名。此字段为必填项。用户使用用户名或电子邮件以及密码登录。

**外部**用户的用户名无法更改：服务器会拒绝保存它。

## 电子邮件 {#user-email}

用户的电子邮件地址。此字段为必填项。Semaphore 会将用户的任务警报发送到此地址，身份验证器应用会将其显示为账户名称。
它是私密的：只有用户本人以及可以管理用户的人员才能看到它。

对于**外部**用户，电子邮件来自身份提供方：此字段为只读，并且 Semaphore 会在每次登录时更新该地址。

## 密码 {#user-password}

在创建新用户时显示。

用户登录时使用的密码。此字段为必填项，但**外部**用户除外，因为他们在 Semaphore 中没有密码。要更改已有用户的密码，请使用
**Security** 标签页中的 **Change password**。

## 发送警报 {#user-alert}

当用户有权查看的任务在某个项目中失败时，向该用户发送电子邮件。项目必须允许警报，并且服务器管理员必须已启用电子邮件警报。
任务模板可以阻止其失败的任务发送警报。

此标志不影响项目发送到 Telegram、Slack 和其他即时通讯工具的警报。

## 管理员用户 {#user-admin}

当您是管理员时显示。

管理员可以在服务器上执行所有操作：管理用户、全局角色和服务器的设置，并以完全权限打开每个项目。

您无法取消自己账户的此标志，并且服务器至少保留一位管理员：它会拒绝取消最后一位管理员的此标志。

## Pro user {#user-pro}

在 Pro 版本中显示。只有管理员可以更改此标志。

为用户分配一个 Pro 订阅席位。订阅中的 Pro 用户数量是固定的：达到上限后，服务器会拒绝保存此标志。如果没有有效的订阅，此标志不起作用。

## 外部 {#user-external}

当您是管理员时显示。只能在创建用户时设置。

外部用户通过 LDAP 或 OpenID Connect 登录，而不是使用 Semaphore 的密码：密码字段处于禁用状态，使用密码登录会被拒绝。
名称和电子邮件会在每次登录时从身份提供方获取。对于使用密码登录的用户，请不要勾选此框。

## Change password {#user-changePassword}

当服务器允许使用密码登录时，在非**外部**的已有用户的 **Security** 标签页中显示。

打开一个用于设置新密码的对话框。要更改您自己的密码，必须提供当前密码；要重置其他用户的密码，则不需要。

## Time-based one-time password {#user-totp}

当管理员已为服务器启用双因素认证时，在 **Security** 标签页中显示。

为此用户启用双因素认证。打开此开关时，Semaphore 会立即创建一个密钥并将其显示为二维码：请用身份验证器应用扫描它。
从此以后，登录时会在输入密码之后要求输入应用中的验证码。

如果服务器允许恢复，二维码下方会显示一个恢复码。它只显示一次：请复制并妥善保管。关闭此开关会立即删除该密钥。

## LDAP 提供方 {#user-ldapProvider}

当服务器有一个您的账户尚未关联的 LDAP 提供方时，在您自己账户的 **Security** 标签页中显示。

当有多个 LDAP 服务器时，要将您的账户关联到的那个 LDAP 服务器。

## LDAP username {#user-ldapUsername}

与 **LDAP 提供方**一起显示。

您在 LDAP 服务器上的用户名。关联之后，您也可以通过 LDAP 登录此账户。

## LDAP password {#user-ldapPassword}

与 **LDAP 提供方**一起显示。

您在 LDAP 服务器上的密码。Semaphore 只使用它一次，用于确认该 LDAP 账户属于您，并且不会保存它。

## Link {#user-ldapLink}

与 **LDAP 提供方**一起显示。

将您的账户关联到上面的 LDAP 账户。如果凭据错误、该 LDAP 账户已关联到其他用户，或者您的账户已经关联到该提供方，关联会被拒绝。
已关联的账户显示在 **Linked accounts** 下；关闭其标签即可取消关联。

## Global role {#global-role-select}

在 Pro 版本中，当您可以管理全局角色时，在已有用户的 **Roles** 标签页中显示。

要授予用户的全局角色，从用户尚未持有的角色中选择。全局角色授予针对整个服务器的权限：管理用户、全局角色或服务器的设置，
或者读取审计日志。全局角色本身是在用户页面的**全局角色**标签页中创建的。

## Assign {#globalRoleAssign-assign}

与 **Global role** 一起显示。

立即将所选角色授予用户。用户持有的角色列在下方，每个角色都带有一个用于收回它的按钮。**Effective global permissions**
显示用户最终可以执行的操作，以及每项权限的来源。
