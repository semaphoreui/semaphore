# ソースを編集

ソースは、Git リポジトリ内のファイルから管理対象インベントリのホストとグループを取り込みます。ファイルは Sync を押すたびに読み込まれ、そこに書かれたホストとグループがファイルと同じ状態に保たれます。サーバーには Ansible とリポジトリへのアクセスが必要です。

## 名前 {#inventorySourceForm-name}

ソースの名前です。カードと、ソースが取り込んだホストの横に表示されます。必須の項目です。

## リポジトリ {#inventorySourceForm-repository}

ファイルを読み込むプロジェクトのリポジトリです。必須の項目です。そのブランチが使われます。

## パス {#inventorySourceForm-path}

リポジトリ内のインベントリファイルのパス (例: `inventory/prod.yml`)、またはインベントリファイルを置いたディレクトリのパスです。必須の項目です。

ファイルは静的な YAML または INI として読み込まれ、スクリプトとプラグインの設定ファイルは拒否されます。ディレクトリでは、Ansible が読み飛ばさないファイルはすべて有効なインベントリである必要があり、そうでなければ同期は失敗し、何も変わりません。Ansible はディレクトリ内で `.cfg`、`.md`、`.txt` など一部の拡張子を読み飛ばします。リポジトリの外を指すリンクを含むリポジトリは拒否されます。
