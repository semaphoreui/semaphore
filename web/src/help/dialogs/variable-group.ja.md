# 変数グループを編集

変数グループは、グループを使うタスクテンプレートのすべてのタスクに Semaphore が渡す、追加の変数、環境変数、シークレットを保持します。Ansible は追加の変数を `--extra-vars` として、Terraform と OpenTofu は `-var` として受け取ります。環境変数はタスクのプロセスに設定されます。テンプレートは複数のグループを使えます。2 つのグループが同じ名前を定義している場合は、テンプレートで後にあるグループが優先されます。

## グループ名 {#varGroup-name}

変数グループ ページと、タスクテンプレートの変数グループ選択欄に表示されるグループの名前です。このフィールドは必須です。

## Secret storage {#varGroup-secretStorageId}

グループが新しく、サーバーがシークレットストレージをサポートしている場合に表示されます。任意です。

このグループのシークレットを保管するシークレットストレージです。例: HashiCorp Vault。シークレットを Semaphore のデータベースに暗号化して保管する場合は、このフィールドを空のままにします。

ストレージはグループの作成時に一度だけ選択します。既存のグループはそのストレージを保持し、このフィールドは表示されなくなります。**Read only** とマークされたストレージは新しいシークレットを受け付けず、シークレットの保存は失敗します。

## Secret key prefix {#varGroup-secretStorageKeyPrefix}

グループが新しく、サーバーがシークレットストレージをサポートしている場合に表示されます。**Secret storage** を選択すると利用可能になります。

このグループの各シークレットがストレージ内で持つパスの先頭部分です。Semaphore はこれに 10 文字のランダムな文字を追加します。接頭辞が `semaphore/prod/` の場合、シークレットは `semaphore/prod/` の後にそれらの文字が続く形で保存されます。接頭辞はそのまま使われるため、シークレットをフォルダーのようにその下に置く場合は `/` で終わらせてください。

接頭辞はグループの作成時に一度だけ設定します。**Secrets** タブには、これがソースパスのパターンとして表示されます。

## Table、JSON、YAML {#varGroup-extraVarsMode}

追加の変数を編集する方法です。

- **Table**: 変数ごとに 1 行で、それぞれにタイプがあります。スイッチの横の **+** ボタンで行を追加します。
- **JSON**: すべての変数を 1 つの JSON オブジェクトとして記述します。
- **YAML**: すべての変数を 1 つの YAML マッピングとして記述します。

ダイアログは **Table** で開きます。切り替えると入力した内容が変換されます。読み取れない場合、ダイアログは元のモードのままでエラーを表示します。モードに関係なく、変数は名前と値の 1 つのオブジェクトとして保存されます。

## JSON の追加の変数 {#varGroup-extraVarsJson}

追加の変数を **JSON** で編集する場合に表示されます。

1 つの JSON オブジェクトとしての追加の変数です。名前は空にできません。値には文字列、数値、リスト、オブジェクトを使えます。

```json
{
  "app_version": "1.4.2",
  "replicas": 3,
  "regions": ["eu-west-1", "us-east-1"]
}
```

## YAML の追加の変数 {#varGroup-extraVarsYaml}

追加の変数を **YAML** で編集する場合に表示されます。

1 つの YAML マッピングとしての追加の変数です。テキストは JSON が知っている型で読み取られます。`2024-01-01` のような引用符のない日付は文字列のままで、`.inf` や `.nan` は拒否されます。最上位のリストやスカラーも拒否されます。

```yaml
app_version: 1.4.2
replicas: 3
regions:
  - eu-west-1
  - us-east-1
```

## 変数名 {#varGroup-varName}

追加の変数を **Table** で編集する場合に、各行に表示されます。

プレイブックや Terraform のコードから見た変数の名前です。例: `app_version`。

## 変数のタイプ {#varGroup-varType}

追加の変数を **Table** で編集する場合に、各行に表示されます。

行の値の読み取り方です。

- **String**: テキストそのままです。
- **Number**: 数値です。例: `42`。
- **List**: JSON の配列です。例: `["a", "b"]`。
- **Dict**: JSON のオブジェクトです。例: `{"key": "value"}`。

値がタイプに合わない場合、変数の名前とともに保存が中止されます。

## 変数の値 {#varGroup-varValue}

追加の変数を **Table** で編集する場合に、各行に表示されます。

変数の値で、そのタイプの形式で記述します。**List** と **Dict** では、フィールドの末尾のボタンで大きなエディターが開きます。

Semaphore は値をデータとして Ansible に渡します。値の中の `{{ … }}` 式は評価されず、プレイブックはテキストをそのまま受け取ります。

## 環境変数名 {#varGroup-envName}

**Variables** タブの **環境変数** の下で、各行に表示されます。セクションの **+** ボタンで行を追加します。

タスクを実行するプロセスの環境に設定される変数の名前です。例: `AWS_REGION`。

## 環境変数の値 {#varGroup-envValue}

**Variables** タブの **環境変数** の下で、各行に表示されます。

変数の値で、テキストです。平文で保存され、グループを開くすべての人に表示されます。パスワードとトークンは、代わりに **Secrets** タブに入れてください。

## Sync keys enabled {#varGroup-syncEnabled}

シークレットストレージを持つグループの **Secrets** タブに表示されます。

オンにすると、**Sync paths** で設定したパスから、ストレージのシークレットをこのグループにインポートします。インポートは、変数グループ ページでグループの同期ボタンを押したとき、および **Sync paths** で設定した間隔で自動的に実行されます。オフの場合、何もインポートされません。

## Sync paths {#varGroup-syncPaths}

**Sync keys enabled** がオンの場合に表示されます。

インポート元となるストレージのパスと、自動インポートの間隔を設定するダイアログを開きます。ボタンの数字はパスの数です。グループに少なくとも 1 つのパスがあるまで、変数グループ ページのグループの同期ボタンは無効のままです。

そのダイアログには **閉じる** しかありません。そこで変更した内容は、このダイアログの **保存** によってグループとともに保存されます。

## シークレット変数名 {#varGroup-secretVarName}

**Secrets** タブの **追加の変数** の下で、各行に表示されます。セクションの **+** ボタンで行を追加します。

値がシークレットである追加の変数の名前です。タスクは、**Variables** タブの追加の変数と同じようにこれを受け取ります。シークレットは同じ名前の追加の変数より優先されます。Ansible はシークレットを Ansible Vault で暗号化されたファイルで受け取り、Terraform と OpenTofu は `-var` として受け取ります。ダイアログが警告するとおり、この方法で渡したシークレットも、Ansible のログに平文で表示されることがあります。

## シークレット変数の値 {#varGroup-secretVarValue}

**Secrets** タブの **追加の変数** の下で、各行に表示されます。

シークレットの値です。Semaphore はこれを暗号化するか、グループのシークレットストレージに書き込み、二度と表示しません。後でグループを開くと、このフィールドは空になっています。保存された値を保持するには空のままにし、置き換えるには新しい値を入力します。行を削除すると、グループを保存したときにシークレットが削除されます。

## シークレット環境変数名 {#varGroup-secretEnvName}

**Secrets** タブの **環境変数** の下で、各行に表示されます。セクションの **+** ボタンで行を追加します。

値がシークレットである環境変数の名前です。例: `DB_PASSWORD`。**Variables** タブの環境変数と同じように、タスクを実行するプロセスの環境に設定されます。

## シークレット環境変数の値 {#varGroup-secretEnvValue}

**Secrets** タブの **環境変数** の下で、各行に表示されます。

シークレットの値です。シークレットの追加の変数と同じく、二度と表示されません。保存された値を保持するにはフィールドを空のままにし、置き換えるには新しい値を入力します。
