# Edit Matcher

Условие сопоставления (matcher) — это условие на входящий запрос. Условия решают, какую интеграцию
запускает запрос к псевдониму проекта, поэтому один URL может обслуживать несколько интеграций:
интеграция запускается, только если выполняются все ее условия. Они используются, только если
для интеграции включено **Использовать псевдоним проекта**; когда этот параметр включен,
интеграция доступна только через псевдоним проекта.

Интеграция, найденная по псевдониму проекта и не имеющая условий, никогда не запускается:
добавьте хотя бы одно.

## Name {#integrationMatcherForm-name}

Имя, под которым условие показано на странице интеграции. Оно не меняет того, что проверяет
условие. Поле обязательное.

## Match on {#integrationMatcherForm-matchType}

Часть запроса, которую читает условие:

- **Header**: значение заголовка запроса.
- **Body**: тело запроса.

## Body Data Format {#integrationMatcherForm-bodyDataType}

Показывается, когда в поле **Match on** выбрано **Body**.

Как читается тело:

- **JSON**: тело разбирается как JSON, а **Key** — это путь к одному значению в нем.
- **String**: все тело сравнивается как текст, а **Key** не используется.

## Key {#integrationMatcherForm-key}

Что прочитать из запроса. Поле обязательное.

- Для **Header**: имя заголовка, например `X-GitHub-Event`. Регистр не важен.
- Для **Body** в формате **JSON**: путь к значению, части которого соединены точками; элемент
  массива записывается как `.[0]`, например `repository.full_name` или `commits.[0].id`.
- Для **Body** в формате **String**: не используется, но форме нужно значение; введите что
  угодно.

## Comparison Method {#integrationMatcherForm-method}

Как значение, прочитанное из запроса, сравнивается с **Value**:

- **==**: значения равны.
- **!=**: значения различаются. Заголовок или ключ, которого нет в запросе, считается отличающимся.
- **Contains**: значение, прочитанное из запроса, содержит **Value**.

## Value {#integrationMatcherForm-value}

Текст для сравнения, например `push` или `refs/heads/main`. Сравнение точное и учитывает регистр.
Число или логическое значение из JSON-тела сравнивается в текстовом виде: `42`, `true`. Поле
обязательное.
