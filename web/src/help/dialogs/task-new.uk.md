# Нове завдання

Запускає завдання шаблону: одне виконання його playbook, коду Terraform або скрипта. Шаблон
визначає, які поля показує цей діалог, і кожен розділ нижче пояснює, коли є його поле. Кнопка
внизу — **Запуск**, **Збірка** або **Розгортання**, залежно від типу шаблону.

Коли шаблон має опитування, його запитання — це поля після **Повідомлення**. Поле, позначене `*`,
обов’язкове, поле Integer приймає лише цифри, а відповіді за замовчуванням уже заповнено.
Semaphore передає відповіді в завдання як змінні: extra vars для Ansible, `-var` для Terraform,
аргументи `name=value` для скрипта або змінні середовища для запитання, налаштованого так.
Відповідь замінює змінну з такою самою назвою в групах змінних шаблону. Секретна відповідь
приховується під час введення і не зберігається із завданням.

## Коміт {#newTask-commit}

Відображається, коли ви знову запускаєте попереднє завдання, і це завдання виконувалося на
відомому коміті.

Завдання отримує цей коміт репозиторію замість найновішого коміту гілки. Закрийте це поле, щоб
запустити найновіший коміт.

Коміт використовується, лише коли шаблон дозволяє перевизначати гілку, і ніколи — для
репозиторію, позначеного як монорепозиторій. Інакше завдання запускає найновіший коміт.

## Версія збірки {#newTask-buildTaskId}

Відображається, коли тип шаблону — **Розгортання**.

Збірка для розгортання: одне з останніх 20 успішних завдань шаблону збірки, показаних за версією
і повідомленням. Вибрано найновіше. Поле обов’язкове.

Версія збірки потрапляє в завдання: як `semaphore_vars.task_details.incoming_version` в Ansible,
як змінна середовища `SEMAPHORE_TASK_DETAILS_INCOMING_VERSION` у скрипті. Список порожній, якщо
вам не можна бачити шаблон збірки.

## Повідомлення {#newTask-message}

Необов’язкове поле. Примітка про те, навіщо запускається завдання, наприклад
`Hotfix for the login page`. Вона показується разом із завданням в історії завдань і нічого не
змінює у виконанні.

Playbook може прочитати її як `semaphore_vars.task_details.message`, а скрипт — як змінну
середовища `SEMAPHORE_TASK_DETAILS_MESSAGE`.

## Гілка {#newTask-gitBranch}

Відображається, коли шаблон дозволяє перевизначати гілку, якщо репозиторій не є
монорепозиторієм.

Гілка або тег репозиторію, які отримує завдання. Спочатку поле містить гілку шаблону. Коли воно
порожнє, завдання використовує гілку шаблону або, якщо в шаблоні її немає, гілку репозиторію.
Назва, яка не є допустимою назвою гілки Git, відхиляється.

## Інвентар {#newTask-inventoryId}

Відображається, коли шаблон дозволяє вибирати інвентар у завданні і вам можна бачити проєкт. Для
шаблону Terraform, OpenTofu або Terragrunt поле має підпис **Workspace**, але сервер використовує
вибір лише для шаблонів Ansible: завдання Terraform, OpenTofu або Terragrunt виконується у workspace
шаблону, хоч би що ви тут вибрали.

Інвентар, з яким виконується завдання. Спочатку поле містить інвентар шаблону і пропонує
інвентарі проєкту, створені для застосунку шаблону. Якщо на момент запуску завдання вибраного
інвентарю вже немає, завдання виконується з інвентарем шаблону.

## Обмеження {#taskParams-limit}

Відображається для шаблону Ansible, який дозволяє перевизначати обмеження.

Хости або групи інвентарю, на яких виконується playbook, по одному шаблону на чип, наприклад
`web` або `10.0.0.11`. Semaphore передає їх як `--limit`, з’єднані комами. Спочатку список
містить обмеження шаблону. Видаліть усі чипи, щоб виконати на всіх хостах інвентарю.

## Теги {#taskParams-tags}

Відображається для шаблону Ansible, який дозволяє перевизначати теги.

Виконуються лише ті завдання і ролі playbook, що мають один із цих тегів: Semaphore передає їх як
`--tags`, по одному тегу на чип. Спочатку список містить теги шаблону. Видаліть усі чипи, щоб
виконати весь playbook.

## Пропустити теги {#taskParams-skipTags}

Відображається для шаблону Ansible, який дозволяє перевизначати пропущені теги.

Завдання і ролі playbook, що мають один із цих тегів, не виконуються: Semaphore передає їх як
`--skip-tags`, по одному тегу на чип. Спочатку список містить пропущені теги шаблону.

## Налагодження {#taskParams-debug}

Відображається для шаблону Ansible, який дозволяє налагодження.

Запускає `ansible-playbook` із прапорцем докладності, тож лог завдання показує більше подробиць.
Підпис показує прапорець: `-v` стільки разів, скільки вказує **Рівень налагодження**.

## Рівень налагодження {#taskParams-debugLevel}

Відображається разом із **Налагодження** і стає активним, коли **Налагодження** встановлено.

Наскільки докладний лог, від 1 (`-v`) до 6 (`-vvvvvv`). За замовчуванням 4 (`-vvvv`), що також
показує подробиці з’єднань із хостами.

## Тестовий запуск {#taskParams-dryRun}

Відображається для шаблону Ansible, якщо шаблон його не приховує.

Запускає playbook з `--check`: Ansible повідомляє, що він змінив би на хостах, і нічого не
змінює.

## Порівняння {#taskParams-diff}

Відображається для шаблону Ansible, якщо шаблон його не приховує.

Запускає playbook з `--diff`: лог показує зміни, внесені у файли і шаблони на хостах. Встановіть
також **Тестовий запуск**, щоб побачити зміни, не вносячи їх.

## Skip Galaxy install {#taskParams-skipGalaxyInstall}

Відображається для шаблону Ansible, який дозволяє перевизначати встановлення Galaxy.

Перед запуском playbook Semaphore встановлює ролі та колекції, перелічені у файлах
`requirements.yml` репозиторію, якщо файл змінився після останнього встановлення. Встановіть
прапорець, щоб пропустити цей крок для цього завдання.

Спочатку прапорець знято незалежно від налаштування шаблону, а знятий прапорець встановлює
залежності.

## Plan {#taskParams-plan}

Відображається для шаблону Terraform, OpenTofu або Terragrunt.

Виконує `plan` і на цьому завершує завдання: нічого не застосовується. Використовуйте це, щоб
спершу переглянути зміни. Без цього завдання переходить до застосування плану, якщо в ньому є
зміни.

## Destroy {#taskParams-destroy}

Відображається для шаблону Terraform, OpenTofu або Terragrunt.

Додає `-destroy` до `plan` і `apply`: завдання планує, а потім застосовує видалення кожного
ресурсу зі стану workspace. Встановіть також **Plan**, щоб побачити, що буде знищено, нічого не
знищуючи.

## Auto Approve {#taskParams-autoApprove}

Відображається для шаблону Terraform, OpenTofu або Terragrunt.

Застосовує план, щойно його створено. Без цього завдання зупиняється після плану і чекає, доки
хтось не підтвердить або не відхилить його на сторінці завдання.

Прапорець діє, лише коли шаблон дозволяє автоматичне підтвердження. Шаблон, налаштований завжди
підтверджувати, застосовує без запитання, що б не показував прапорець.

## Upgrade {#taskParams-upgrade}

Відображається для шаблону Terraform, OpenTofu або Terragrunt.

Запускає `init` з `-upgrade`: провайдери і модулі оновлюються до найновіших версій, які
дозволяють їхні обмеження версій.

## Reconfigure {#taskParams-reconfigure}

Відображається для шаблону Terraform, OpenTofu або Terragrunt.

Запускає `init` з `-reconfigure`: бекенд налаштовується заново, а збережена конфігурація бекенду
ігнорується. Без цього Semaphore запускає `init -migrate-state`, що переносить наявний стан до
зміненого бекенду.

## CLI args {#newTask-args}

Відображається, коли шаблон дозволяє перевизначати CLI-аргументи.

Додаткові аргументи для командного рядка завдання, по одному на чип: `--forks=10` — це один чип,
`--forks` і `10` — два. Натисніть чип, щоб його відредагувати, перетягніть його, щоб змінити
порядок, і використовуйте останній чип, щоб додати новий.

Спочатку список містить аргументи шаблону. Semaphore завжди передає аргументи шаблону і додає цей
список після них, тож щойно ви змінюєте список, аргументи шаблону, що в ньому залишилися,
передаються двічі. Видаліть їх і залиште лише ті аргументи, які ви додаєте.
