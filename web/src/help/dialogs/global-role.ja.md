# Edit Global Role

グローバルロールは、割り当てられたユーザーに Semaphore のインスタンス全体に対する権限を付与します。ロールはユーザーのダイアログで割り当てます。グローバルロールはプロジェクト内のアクセス権を与えません。プロジェクト内のアクセス権は、ユーザーがプロジェクトのメンバーとして持つロールからのみ得られます。管理者は、割り当てられたロールに関係なく、すべてのグローバル権限を持ちます。グローバルロールは Pro の機能です。

## 名前 {#globalRole-name}

ユーザーページの グローバルロール タブと、ユーザーのダイアログに表示されるロールの名前です。このフィールドは必須です。ロールの名前はいつでも変更できます。

## Slug {#globalRole-slug}

ロールの識別子です。名前を入力している間、自分でスラッグを編集するまで、Semaphore が名前からこれを入力します。1 から 100 文字の英字、数字、アンダースコア、ハイフンを使えます。例: `user-admins`。

スラッグはグローバルロールの間で一意である必要があります。プロジェクトロールは同じスラッグを持つことができます。ロールを保存した後は変更できません。ロールを編集するときは、このフィールドはロックされています。

## Global permissions {#globalRole-permissionsTitle}

ロールを持つユーザーがインスタンス全体で行えることです。新しいロールでは何もチェックされていません。ユーザーのすべてのグローバルロールの権限は合算されます。

- **Can manage users**: ユーザーを作成、変更、削除し、ユーザーの一覧でその詳細を表示します。このユーザーは、ユーザーを管理者または Pro ユーザーにすることはできず、管理者や、自分が持っていないグローバル権限を持つユーザーを変更または削除することもできません。
- **Can manage global roles**: グローバルロールと共有のプロジェクトロールを作成、変更、削除し、どのユーザーがどのグローバルロールを持つかを決めます。インスタンス全体を任せられる人にのみ付与してください。
- **Can manage system settings**: インスタンスの設定、アプリケーション、グローバルランナー、グループのマッピングを変更します。クラスターとサーバーの情報を表示します。すべてのプロジェクトのタスクを表示し、削除します。サーバーのキャッシュをクリアします。
- **Can read the audit log**: インスタンスの監査ログを読み、エクスポートします。
