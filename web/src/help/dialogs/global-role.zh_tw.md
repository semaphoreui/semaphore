# Edit Global Role

全域角色會將涵蓋整個 Semaphore 執行個體的權限授予被指派此角色的使用者；您可以在使用者的對話方塊中指派它。它不會授予專案內的任何存取權：
專案內的存取權只來自使用者身為專案成員所擁有的角色。無論被指派了哪些角色，管理員都擁有所有全域權限。全域角色是 Pro 功能。

## 名稱 {#globalRole-name}

角色在「使用者」頁面的「全域角色」分頁以及使用者對話方塊中列出時所用的名稱。此欄位為必填。您可以隨時重新命名角色。

## Slug {#globalRole-slug}

角色的識別碼。在您輸入名稱時，Semaphore 會根據名稱自動填入，直到您自行編輯 Slug 為止。它由 1 到 100 個字母、數字、
底線和連字號組成，例如 `user-admins`。

Slug 在全域角色之間必須是唯一的；專案角色可以使用相同的 Slug。角色儲存後就無法再變更：編輯角色時此欄位會被鎖定。

## Global permissions {#globalRole-permissionsTitle}

擁有此角色的使用者可以在整個執行個體中執行的操作。新角色預設不勾選任何權限。使用者所有全域角色的權限會累加。

- **Can manage users**：建立使用者、修改及刪除使用者，並在使用者清單中檢視其詳細資訊。這樣的使用者無法將某個使用者設為管理員或
  Pro 使用者，也無法修改或刪除管理員，或擁有其本身所沒有之全域權限的使用者。
- **Can manage global roles**：建立、修改及刪除全域角色和共用的專案角色，並決定哪些使用者擁有哪個全域角色。請只將此權限授予您可以託付整個執行個體的人。
- **Can manage system settings**：變更執行個體的設定、應用程式、全域執行器和群組對應；檢視叢集和伺服器的相關資訊；
  檢視及移除所有專案的任務；清除伺服器的快取。
- **Can read the audit log**：讀取執行個體的稽核日誌並將其匯出。
