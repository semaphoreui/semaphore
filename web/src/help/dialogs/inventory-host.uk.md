# Редагувати хост

Хост керованого інвентаря. Завдання, яке використовує інвентар, виконується на тих його хостах, які
ввімкнено у списку хостів.

## Назва {#inventoryHostForm-name}

Ім’я, під яким Ansible знає хост, і адреса, до якої він під’єднується, якщо у змінних не задано
`ansible_host`. Поле обов’язкове. Ім’я унікальне в межах інвентаря, регістр літер має значення:
`web1` і `Web1` — це два хости. Ім’я не може містити пробіли, коми, квадратні дужки та двокрапки,
його довжина не більша за 250 символів.

## Опис {#inventoryHostForm-description}

Необов’язкове поле. Нотатка для людей, її видно у списку хостів. Ansible її не отримує.

## Змінні {#inventoryHostForm-variables}

Необов’язкове поле. Змінні цього хоста, записані як словник YAML або JSON:

```yaml
ansible_host: 10.0.0.11
ansible_port: 2222
```

Змінна хоста має пріоритет над змінною інвентаря з тим самим ім’ям. Якорі, посилання та ключі злиття
YAML не приймаються.
