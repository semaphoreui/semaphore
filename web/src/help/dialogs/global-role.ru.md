# Edit Global Role

Глобальная роль дает пользователям, которым она назначена, права на весь экземпляр Semaphore;
назначается она в диалоге пользователя. Она не дает доступа внутри проектов: его дают только роли,
которые пользователь имеет как участник проекта. Администратор имеет все глобальные права
независимо от назначенных ролей. Глобальные роли — функция версии Pro.

## Имя {#globalRole-name}

Имя, под которым роль показана на вкладке «Глобальные роли» страницы «Пользователи» и в диалоге
пользователя. Поле обязательное. Роль можно переименовать в любой момент.

## Slug {#globalRole-slug}

Идентификатор роли. Semaphore заполняет его по имени, пока вы вводите имя, до тех пор, пока вы
сами не измените slug. Он состоит из 1–100 букв, цифр, знаков подчеркивания и дефисов, например
`user-admins`.

Slug должен быть уникальным среди глобальных ролей; у роли проекта может быть такой же slug. Его
нельзя изменить после сохранения роли: при редактировании роли поле заблокировано.

## Global permissions {#globalRole-permissionsTitle}

Что пользователь с этой ролью может делать во всем экземпляре. У новой роли не отмечено ни одно
право. Права всех глобальных ролей пользователя складываются.

- **Can manage users**: создавать пользователей, изменять и удалять их и видеть их данные в
  списке пользователей. Такой пользователь не может сделать пользователя администратором или
  пользователем Pro и не может изменить или удалить администратора или пользователя, у которого
  есть глобальное право, которого нет у него самого.
- **Can manage global roles**: создавать, изменять и удалять глобальные роли и общие роли
  проектов и решать, какие пользователи имеют какую глобальную роль. Давайте это право только
  тем, кому вы доверяете весь экземпляр.
- **Can manage system settings**: изменять настройки экземпляра, приложения, глобальных
  исполнителей и сопоставления групп; видеть кластер и сведения о сервере; видеть и удалять
  задачи всех проектов; очищать кэш сервера.
- **Can read the audit log**: читать журнал аудита экземпляра и экспортировать его.
