# 워크플로 실행

워크플로의 설문에 답하면 워크플로 실행을 시작합니다. 이 대화 상자는 설문이 있는 워크플로에만 열리며, 설문이 없는
워크플로는 즉시 시작됩니다. **실행** 후에는 새 실행의 페이지가 열립니다. 서버가 값을 거부하면 대화 상자는 답을
유지한 채 열려 있습니다.

## 변수 {#workflowRunDialog-survey}

워크플로 설문의 변수마다 필드가 하나씩, 설문의 순서대로 기본값이 채워진 채 표시됩니다. `*` 표시가 있는 필드는
필수이고, Integer 필드에는 숫자만 입력할 수 있으며, 목록 필드에는 값 하나를 입력하거나 변수가 허용하면 원하는
개수의 값을 입력합니다. 모든 필드가 유효할 때까지 **실행**은 아무것도 시작하지 않습니다.

값은 실행과 함께 저장되며 실행 페이지의 **Variables** 아래에 표시됩니다. 워크플로의 작업은 이 값을 자동으로 받지
않습니다. 템플릿의 변수는 해당 노드가 그 변수를 워크플로의 변수에 연결할 때만 값을 받습니다. 이름만으로는 아무것도
전달되지 않습니다.

실행은 값을 평문으로 보관하므로 워크플로 설문에는 비밀 값이 없습니다. 비밀번호와 토큰은 대신 키나 변수 그룹에
넣으세요.
