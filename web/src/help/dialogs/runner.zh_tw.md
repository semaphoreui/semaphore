# 編輯執行器

執行器是一個獨立的 `semaphore runner` 程序，它在自己的機器上執行任務，而不是在 Semaphore 伺服器上執行。當伺服器設定為在執行器上執行任務，
或任務範本或其清單設有執行器標籤時，任務就會交給執行器。伺服器接著會挑選一個已啟用、已註冊、在線上且未達平行任務上限的執行器：
先挑選專案的執行器，再挑選全域執行器，每一組內的順序為隨機。當所有符合的執行器都離線或忙碌時，任務會在佇列中等候；當完全沒有符合的執行器時，任務會失敗。

## 名稱 {#runner-name}

必填。執行器在「執行器」頁面上列出時所用的名稱，例如它所在的主機。它不會改變執行器取得哪些任務。

## Tags {#runner-tags}

在 Semaphore Pro 中提供；在其他版本中此欄位會被鎖定。

用來為此執行器挑選任務的標籤。帶有執行器標籤的任務只會交給帶有該標籤的執行器；任務範本的標籤優先於清單的標籤。輸入標籤並按下
Enter，或選擇其他執行器使用的標籤。空白和重複的標籤會在儲存時被捨棄。

除非勾選了 **Is default**，否則專案執行器至少需要一個標籤。

## Is default {#runner-isDefault}

沒有執行器標籤的任務只會交給標示為預設的執行器。若執行器只應接收帶有其某個標籤的任務，請取消勾選此方塊。

新的全域執行器預設勾選此方塊，新的專案執行器預設不勾選。

## Register {#runner-registered}

在您建立執行器時顯示。

- 勾選（預設）：伺服器會建立執行器及其權杖。按下**建立**後，對話方塊會顯示權杖，以及使用它啟動執行器的命令。
- 取消勾選：建立的執行器不帶任何權杖。之後，請在執行器所在的列中點選 **Regenerate registration token**（兩個箭頭的圖示），
  以取得有效期一小時的一次性註冊權杖，並使用 `semaphore runner register` 註冊執行器。

未註冊的執行器不會取得任何任務。

## Webhook {#runner-webhook}

選填。伺服器將任務交給此執行器時呼叫的 URL，例如用來按需啟動執行器。伺服器會傳送一個帶有 JSON 主體的 `POST` 請求：

```json
{"action": "start", "project_id": 1, "task_id": 42, "template_id": 7, "runner_id": 3}
```

該 URL 必須在 30 秒內以狀態 200 或 204 回應；否則任務會失敗。設有 Webhook 的執行器一律被視為在線上，即使它最近沒有輪詢伺服器。
若執行器一直在執行，請將此欄位留空。

## 最大平行任務數 {#runner-maxParallelTasks}

執行器可以同時執行的任務數量。達到上限時，下一個任務會交給另一個符合的執行器，或在佇列中等候。將此欄位留空或設為 `0` 表示不設上限。

## 已啟用 {#runner-active}

只有已啟用的執行器才會取得新任務。取消勾選此方塊，即可在不刪除執行器的情況下讓它停止服務；執行器清單中的開關也有相同作用。

新的執行器預設不勾選此方塊：請勾選它，或之後在清單中啟用執行器。
