# Edit Matcher

Аналізатор — це умова щодо вхідного запиту. Аналізатори визначають, яку інтеграцію запускає
запит до псевдоніма проєкту, тож одна URL-адреса може обслуговувати кілька інтеграцій: інтеграція
запускається, лише коли виконуються всі її аналізатори. Вони використовуються, лише коли для
інтеграції ввімкнено **Використовувати псевдонім проєкту**; коли це ввімкнено, до інтеграції
можна звернутися лише через псевдонім проєкту.

Інтеграція, знайдена за псевдонімом проєкту, без аналізаторів ніколи не запускається: додайте
принаймні один.

## Name {#integrationMatcherForm-name}

Назва, під якою аналізатор відображається на сторінці інтеграції. Вона не змінює того, що
перевіряє аналізатор. Поле обов’язкове.

## Match on {#integrationMatcherForm-matchType}

Частина запиту, яку читає аналізатор:

- **Header**: значення заголовка запиту.
- **Body**: тіло запиту.

## Body Data Format {#integrationMatcherForm-bodyDataType}

Відображається, коли в полі **Match on** вибрано **Body**.

Як читається тіло:

- **JSON**: тіло розбирається як JSON, а **Key** — це шлях до одного значення в ньому.
- **String**: усе тіло порівнюється як текст, а **Key** не використовується.

## Key {#integrationMatcherForm-key}

Що читати із запиту. Поле обов’язкове.

- Для **Header**: назва заголовка, наприклад `X-GitHub-Event`. Регістр не має значення.
- Для **Body** у форматі **JSON**: шлях до значення, частини якого з’єднано крапками; елемент
  масиву записується як `.[0]`, наприклад `repository.full_name` або `commits.[0].id`.
- Для **Body** у форматі **String**: не використовується, але формі потрібне значення; введіть
  будь-що.

## Comparison Method {#integrationMatcherForm-method}

Як значення, прочитане із запиту, порівнюється з **Value**:

- **==**: обидва однакові.
- **!=**: обидва відрізняються. Заголовок або ключ, якого немає в запиті, вважається відмінним.
- **Contains**: значення, прочитане із запиту, містить **Value**.

## Value {#integrationMatcherForm-value}

Текст для порівняння, наприклад `push` або `refs/heads/main`. Порівняння точне і враховує
регістр. Число або логічне значення з тіла JSON порівнюється в текстовому вигляді: `42`, `true`.
Поле обов’язкове.
