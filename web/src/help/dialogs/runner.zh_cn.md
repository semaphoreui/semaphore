# 编辑运行器

运行器是一个独立的 `semaphore runner` 进程，它在自己的机器上而不是在 Semaphore 服务器上运行任务。
当服务器被设置为在运行器上运行任务，或者任务模板或其库存带有运行器标签时，任务会交给运行器。随后服务器会选择一个已启用、
已注册、在线且未达到并行任务上限的运行器：先选择项目的运行器，再选择全局运行器，每组内按随机顺序选择。
当所有匹配的运行器都离线或繁忙时，任务会在队列中等待；当没有任何运行器匹配时，任务会失败。

## 名称 {#runner-name}

必填。运行器在运行器页面中显示的名称，例如它所在的主机。名称不会改变运行器获得哪些任务。

## Tags {#runner-tags}

在 Semaphore Pro 中可用；在其他版本中此字段处于锁定状态。

用于为此运行器挑选任务的标签。带有运行器标签的任务只会交给带有该标签的运行器；任务模板的标签优先于库存的标签。
输入一个标签并按 Enter，或者选择其他运行器使用的标签。保存时会丢弃空白和重复的标签。

除非勾选了 **Is default**，否则项目运行器至少需要一个标签。

## Is default {#runner-isDefault}

没有运行器标签的任务只会交给标记为默认的运行器。如果运行器只应接收带有其某个标签的任务，请取消勾选此框。

新建全局运行器时此框默认勾选，新建项目运行器时默认不勾选。

## Register {#runner-registered}

在创建运行器时显示。

- 勾选（默认）：服务器会创建运行器及其令牌。点击**创建**后，对话框会显示令牌以及使用该令牌启动运行器的命令。
- 不勾选：创建的运行器不带任何令牌。之后，在运行器所在行中点击 **Regenerate registration token**（两个箭头的图标）
  获取一个一次性注册令牌，有效期为一小时，然后使用 `semaphore runner register` 注册运行器。

未注册的运行器不会获得任务。

## Webhook {#runner-webhook}

可选。服务器将任务交给此运行器时调用的 URL，例如用于按需启动运行器。服务器会发送一个带有 JSON 正文的 `POST`
请求：

```json
{"action": "start", "project_id": 1, "task_id": 42, "template_id": 7, "runner_id": 3}
```

该 URL 必须在 30 秒内以状态 200 或 204 响应；否则任务会失败。带有 webhook 的运行器始终被视为在线，
即使它最近没有轮询服务器。对于一直运行的运行器，请将此字段留空。

## 最大并行任务数 {#runner-maxParallelTasks}

运行器可以同时运行的任务数量。达到上限后，下一个任务会交给另一个匹配的运行器，或在队列中等待。将此字段留空或设为
`0` 表示不设限制。

## 启用 {#runner-active}

只有已启用的运行器才会获得新任务。取消勾选此框可以让运行器停止服务而不删除它；运行器列表中的开关作用相同。

新建运行器时此框默认不勾选：请勾选它，或者以后在列表中启用运行器。
