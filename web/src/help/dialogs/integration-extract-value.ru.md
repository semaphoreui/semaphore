# Edit Extract Value

Извлекаемое значение берет часть входящего запроса, например ветку из события push, и передает
ее задаче, которую запускает интеграция. Каждое значение интеграции берется из каждого запроса,
который запускает задачу.

## Name {#integrationValueForm-name}

Имя, под которым значение показано на странице интеграции. Оно не меняет того, что берется и
куда передается. Поле обязательное.

## Source of the Value {#integrationValueForm-valueSource}

Часть запроса, из которой берется значение:

- **Header**: значение заголовка запроса.
- **Body**: тело запроса.

## Data Type of Body {#integrationValueForm-bodyDataType}

Показывается, когда в поле **Source of the Value** выбрано **Body**.

Как читается тело:

- **JSON**: тело разбирается как JSON, а **Key** — это путь к одному значению в нем. Значение
  сохраняет свой тип JSON: число, список или объект доходят до задачи как есть.
- **String**: все тело берется как текст, а **Key** не используется.

## Key {#integrationValueForm-key}

Что взять из запроса. Поле обязательное.

- Для **Header**: имя заголовка, например `X-GitHub-Event`. Регистр не важен. Заголовок,
  которого нет в запросе, дает пустое значение.
- Для **Body** в формате **JSON**: путь к значению, части которого соединены точками; элемент
  массива записывается как `.[0]`, например `repository.full_name` или `commits.[0].id`. Путь,
  которого нет в теле, не дает значения, и задача сохраняет значение, заданное в интеграции.
- Для **Body** в формате **String**: не используется, но форме нужно значение; введите что
  угодно.

## Variable Usage {#integrationValueForm-variableType}

Куда значение попадает в задаче шаблона:

- **Variables**: дополнительная переменная задачи, так же как передается ответ на переменную
  опроса. Она заменяет ответ или переменную группы переменных с тем же именем.
- **Task Params**: параметр задачи, так же как хранятся параметры диалога задачи. Имя
  `git_branch` задает ветку задачи, если шаблон разрешает переопределять ветку; начальный
  `refs/heads/` удаляется.

Интеграция, которая запускает workflow, игнорирует это поле: каждое значение становится ответом на
переменную опроса workflow, указанную в поле **Variable**.

## Variable {#integrationValueForm-variable}

Имя, под которым передается значение, например `branch` для дополнительной переменной, которую
плейбук читает как `{{ branch }}`. Поле обязательное.
