# Редактировать расписание

Расписание запускает задачу шаблона задачи без того, чтобы кто-то нажимал **Запуск**: снова и снова
по выражению cron или один раз в заданный момент. Задача получает параметры, сохраненные в этом
диалоге. Все время указывается в часовом поясе сервера Semaphore, который показан рядом с полями
времени: `UTC`, если администратор не задал `schedule.timezone` или `SEMAPHORE_SCHEDULE_TIMEZONE`.

## Name {#scheduleForm-name}

Имя, под которым расписание показано на странице «Расписание». Поле обязательное. Оно не меняет
того, что делает расписание.

## Template {#scheduleForm-templateId}

Шаблон задачи, который запускает расписание. Поле обязательное. Задача выполняется так, как если
бы она была запущена из шаблона, с собственными инвентарем, репозиторием, группой переменных и
другими настройками шаблона, а также с параметрами ниже там, где шаблон позволяет задаче их
менять.

## Параметры задачи {#scheduleForm-taskParams}

Показывается, когда выбран шаблон.

Параметры каждой задачи, которую запускает расписание. Какие поля появляются, зависит от шаблона:
его переменные опроса и параметры, которые он позволяет менять в задаче, например ветка,
инвентарь, **Лимит**, **Теги**, **Пропустить теги** или **CLI args**, а также параметры Ansible
или Terraform, OpenTofu и Terragrunt.

Сервер проверяет шаблон при каждом срабатывании расписания: значение, сохраненное здесь,
игнорируется, как только шаблон перестает позволять задаче его менять.

## Сообщение {#taskParams-message}

Необязательное поле. Заметка, которая сохраняется с каждой задачей, запущенной расписанием, и
показывается в истории задач, например `Nightly deploy`. Она не меняет того, как выполняется
задача.

## Переменные опроса {#taskParams-survey}

Показывается, когда у шаблона есть переменные опроса.

Значения переменных опроса шаблона для задач по расписанию. Они доходят до задачи так же, как
когда кто-то заполняет опрос вручную. Обязательной переменной нужно задать значение, прежде чем
расписание можно будет сохранить.

Значения по умолчанию из шаблона копируются при открытии диалога и сохраняются вместе с
расписанием. Значение по умолчанию, позже измененное в шаблоне, не доходит до расписания,
сохраненного ранее.

Значение переменной типа secret не сохраняется вместе с расписанием: задача по расписанию
выполняется без него.

## Ветка {#taskParams-gitBranch}

Показывается, когда шаблон позволяет задаче переопределять ветку.

Ветка или тег репозитория, которые извлекает задача по расписанию. Изначально в поле указана ветка
шаблона. Сервер использует значение, только пока шаблон разрешает переопределение.

## Инвентарь {#taskParams-inventoryId}

Показывается, когда шаблон позволяет задаче выбирать инвентарь.

Инвентарь, с которым выполняется задача по расписанию, вместо инвентаря шаблона. Для шаблона
Terraform или OpenTofu поле называется **Workspace**, но сервер применяет выбор только к шаблонам
Ansible, а для остальных сохраняет workspace шаблона.

## Отладка {#taskParams-debug}

Показывается для шаблона Ansible, который разрешает отладку.

Запускает `ansible-playbook` с более подробным выводом: `-v` повторяется столько раз, сколько
задает **Уровень отладки**.

## Уровень отладки {#taskParams-debugLevel}

Показывается для шаблона Ansible, который разрешает отладку; активен, когда установлен флажок
**Отладка**.

Насколько подробен вывод, от `1` (`-v`) до `6` (`-vvvvvv`). По умолчанию `4`.

## Пробный запуск {#taskParams-dryRun}

Показывается для шаблона Ansible, если шаблон его не скрывает.

Запускает плейбук с `--check`: Ansible сообщает, что он изменил бы, и ничего не меняет.

## Различия {#taskParams-diff}

Показывается для шаблона Ansible, если шаблон его не скрывает.

Запускает плейбук с `--diff`: Ansible показывает изменения, которые он вносит в файлы и шаблоны.

## Пропустить установку Galaxy {#taskParams-skipGalaxyInstall}

Показывается для шаблона Ansible, который позволяет задаче это менять.

Пропускает установку ролей и коллекций из файлов `requirements.yml` перед запуском плейбука.
Установите флажок, когда зависимости уже установлены и задача не должна обращаться к Ansible
Galaxy.

## Plan {#taskParams-plan}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Выполняет только `plan`. Задача завершается после плана и ничего не применяет.

## Destroy {#taskParams-destroy}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Добавляет `-destroy` к плану и применению: задача уничтожает ресурсы workspace вместо того, чтобы
создавать или обновлять их.

## Auto Approve {#taskParams-autoApprove}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Применяет план, не дожидаясь подтверждения. Работает, только если шаблон разрешает
автоматическое одобрение; шаблон, настроенный одобрять каждую задачу, применяет план в любом
случае.

Без автоматического одобрения задача по расписанию останавливается после плана и ждет, пока
кто-нибудь не подтвердит или не отклонит ее на странице задачи.

## Upgrade {#taskParams-upgrade}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Выполняет `init` с `-upgrade`: провайдеры и модули обновляются до самых новых версий, которые
допускает конфигурация.

## Reconfigure {#taskParams-reconfigure}

Показывается для шаблона Terraform, OpenTofu или Terragrunt.

Выполняет `init` с `-reconfigure` вместо `-migrate-state`: backend настраивается заново, а
существующее состояние не переносится.

## Run at {#scheduleForm-runAt}

Показывается для расписания, которое запускается один раз.

Дата и время запуска задачи в часовом поясе сервера, показанном в конце поля. Для нового
расписания изначально указан следующий полный час. Момент должен быть в будущем: сервер
отклоняет уже прошедшее время.

После запуска задачи расписание выключается или удаляется, если установлен флажок **Delete after
run**. Если Semaphore не работает в этот момент, задача не запускается позже: при следующем
запуске расписание выключается или удаляется без выполнения.

## Delete after run {#scheduleForm-deleteAfterRun}

Показывается для расписания, которое запускается один раз.

Удаляет расписание после запуска его задачи. Оставьте флажок снятым, чтобы сохранить расписание
выключенным: тогда можно задать новое время и снова включить его.

## Show cron format {#scheduleForm-rawCron}

Показывается для расписания cron.

Переключает между вводом выражения cron (включено) и его составлением из **Timing** и флажков
времени (выключено). Оба способа меняют одно и то же выражение. Браузер запоминает выбор.

Переключатель заблокирован во включенном положении, когда выражение нельзя показать флажками:
когда оно неверно или использует форму вроде `@daily` или `CRON_TZ=`.

## Cron {#scheduleForm-cronFormat}

Показывается для расписания cron, когда включено **Show cron format**.

Выражение cron из пяти полей: минута, час, день месяца, месяц, день недели (`0` — воскресенье).
Поле обязательное, и сервер проверяет выражение по мере ввода. Для нового расписания изначально
указано `* * * * *` — каждую минуту.

```
0 3 * * *       every day at 03:00
*/15 * * * *    every 15 minutes
30 8 * * 1-5    at 08:30 from Monday to Friday
0 0 1 * *       at midnight on the first day of every month
```

Сервер также принимает `@hourly`, `@daily`, `@weekly`, `@monthly`, `@yearly` и `@every 1h30m`, а
также префикс вроде `CRON_TZ=Europe/Berlin` для другого часового пояса. Предпросмотр ниже не может
показать следующий запуск для таких выражений.

## Timing {#scheduleForm-timing}

Показывается для расписания cron, когда **Show cron format** выключено.

Как часто выполняется задача. Флажки ниже меняются вместе с этим полем:

- **Hourly**: **Minutes**.
- **Daily**: **Hours** и **Minutes**.
- **Weekly**: **Weekdays**, **Hours** и **Minutes**.
- **Monthly**: **Days**, **Hours** и **Minutes**.
- **Yearly**: **Months**, **Days**, **Hours** и **Minutes**.

## Months {#scheduleForm-months}

Показывается, когда в поле **Timing** выбрано **Yearly**.

Месяцы, в которые выполняется задача. Отметьте несколько, чтобы она выполнялась в каждом из них.
Если ничего не отмечено, задача выполняется каждый месяц.

## Weekdays {#scheduleForm-weekdays}

Показывается, когда в поле **Timing** выбрано **Weekly**.

Дни недели, в которые выполняется задача. Если ничего не отмечено, задача выполняется каждый
день.

## Days {#scheduleForm-days}

Показывается, когда в поле **Timing** выбрано **Monthly** или **Yearly**.

Дни месяца, в которые выполняется задача. Месяц без такого дня пропускается: задача, назначенная
на 31-е число, не выполняется в апреле. Если ничего не отмечено, задача выполняется каждый день.

## Hours {#scheduleForm-hours}

Показывается, когда в поле **Timing** выбрано **Daily**, **Weekly**, **Monthly** или **Yearly**.

Часы, в которые выполняется задача, в часовом поясе, показанном справа. Если ничего не отмечено,
задача выполняется каждый час.

## Minutes {#scheduleForm-minutes}

Показывается для расписания cron, когда **Show cron format** выключено.

Минуты часа, в которые выполняется задача, с шагом пять минут. Если ничего не отмечено, задача
выполняется каждую минуту: отметьте хотя бы одну, например `:00`, для задачи, которая должна
выполняться раз в час или раз в день.

## Next run time {#scheduleForm-nextRun}

Когда запустится следующая задача по расписанию в том виде, в каком оно задано в форме: в часовом
поясе сервера и в местном времени вашего браузера. Прочерк означает, что выражение неверно или
что предпросмотр не может его прочитать, например `@daily`.

## Включено {#scheduleForm-active}

Запускает ли расписание задачи. Снимите флажок, чтобы сохранить расписание, не выполняя его.
Переключатель в списке расписаний делает то же самое. Новое расписание включено.
