# 編集 Repository

リポジトリは、タスクテンプレートのプレイブック、Terraform のコード、スクリプトの取得元です。Git リポジトリ、またはタスクを実行するマシン上のディレクトリです。Semaphore はタスクのたびに Git リポジトリをクローンするか、以前にクローンしたコピーを更新し、ブランチをチェックアウトして、そのコピーでタスクを実行します。

## 名前 {#repository-name}

リポジトリ ページ、およびタスクテンプレートとインベントリのリポジトリ選択欄に表示されるリポジトリの名前です。このフィールドは必須です。

## URLまたはパス {#repository-gitUrl}

コードの場所です。このフィールドは必須です。下のチップは入力したアドレスの種類を示し、チップをクリックするとアドレスがその種類に書き換えられます。

- **ssh**: `git@github.com:org/repo.git` または `ssh://git@github.com/org/repo.git`。Git はアドレス内のユーザーと、**アクセスキー** で選択した **SSHキー** でログインします。
- **https** と **http**: `https://github.com/org/repo.git`。非公開のリポジトリには **パスワードでログイン** のキーが必要で、公開のリポジトリには **なし** が必要です。`http` は避けてください。ログインとパスワードが暗号化されずに送信されます。
- **git**: `git://host/org/repo.git`。読み取り専用の Git プロトコルで、ログインはありません。
- **file**: `file:///srv/git/repo.git`。タスクを実行するマシンのディスク上にある Git リポジトリで、リモートのリポジトリと同じようにクローンされます。
- **絶対パス**: `/srv/playbooks` や `D:\playbooks` のような絶対パスです。Semaphore はこれをクローンしません。タスクはそのディレクトリで直接実行されるため、そのディレクトリはタスクを実行するマシン (Semaphore サーバーまたはランナー) 上に存在する必要があります。ブランチは適用されません。

アドレスを変更すると、Semaphore サーバーが古いアドレスからクローンしたコピーは削除されます。

## ブランチ {#repository-gitBranch}

Semaphore がクローンして最新に保つブランチです。例: `main`。このフィールドは必須ですが、絶対パスの場合はロックされます。

タスクテンプレートは独自のブランチを指定でき、それがこちらより優先されます。また、テンプレートでは、タスクの開始時にブランチを選択できるようにすることもできます。タグも使えますが、タグはプルできないため、Semaphore はタスクのたびにリポジトリを新たにクローンします。

## Single checkout for all templates {#repository-monorepo}

デフォルトではオフで、各タスクテンプレートがリポジトリの独自のコピーを持ちます。チェックを入れると、リポジトリを一度だけクローンし、そのコピーをリポジトリを使うすべてのテンプレートで共有します。テンプレートごとにコピーを持つには大きすぎるリポジトリ向けです。

共有のコピーはこのリポジトリのブランチのままです。それを使うテンプレートは独自のブランチを持てず、そのタスクは別のブランチやコミットを選択できません。絶対パスの場合はロックされます。

## アクセスキー {#repository-sshKeyId}

Git がリポジトリへのログインに使う、キーのストアのキーです。このフィールドは必須です。3 種類のキーを選択でき、どれを選ぶかは URL によって決まります。

- `ssh` の URL には **SSHキー**。Semaphore はクローンまたは更新の間、秘密鍵を SSH エージェントに読み込みます。ユーザーは URL 内のもので、`git@github.com:org/repo.git` では `git` です。
- `https` の URL には **パスワードでログイン**。ログインとパスワード、または Git サーバーのアクセストークンです。ログインが空の場合、パスワードだけがユーザー名として送信されます。これは一部のサーバーがトークンに求める形式です。同じ資格情報は、同じサーバー上のロールとコレクションのために `ansible-galaxy` にも渡されます。
- 公開のリポジトリ、`git` または `file` の URL、または絶対パスには **なし**。

URL に合わないキーでは Git に資格情報が渡されず、非公開のリポジトリはクローンに失敗します。
