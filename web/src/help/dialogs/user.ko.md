# 사용자 수정

사용자는 Semaphore에 로그인하는 계정입니다. **Settings** 탭에는 계정의 프로필과 플래그가 있으며, **저장**으로
기록됩니다. **Security** 탭에는 비밀번호, 2단계 인증, 연결된 로그인 계정이 있고, **Roles** 탭에는 사용자의 전역
역할이 있습니다. 이 두 탭은 **저장** 없이 즉시 적용됩니다. 사용자가 프로젝트 안에서 할 수 있는 일은 여기가 아니라
그 프로젝트의 **팀** 페이지에서 설정합니다.

## 이름 {#user-name}

사이드바와 사용자 목록, 프로젝트 멤버 목록에 표시되는 사용자의 전체 이름입니다. 이 필드는 필수입니다.

**외부** 사용자의 경우 Semaphore는 로그인할 때 ID 공급자가 이름을 보내면 그 이름을 가져오므로, 여기에서 변경한
내용은 다음 로그인 이후에는 유지되지 않을 수 있습니다.

## 사용자 이름 {#user-username}

사용자의 로그인입니다. 이 필드는 필수입니다. 사용자는 사용자 이름 또는 이메일과 비밀번호로 로그인합니다.

**외부** 사용자의 사용자 이름은 변경할 수 없으며, 서버는 저장을 거부합니다.

## 이메일 {#user-email}

사용자의 이메일 주소입니다. 이 필드는 필수입니다. Semaphore는 사용자의 작업 알림을 이 주소로 보내며, 인증 앱은
이 주소를 계정 이름으로 표시합니다. 이 주소는 비공개이며, 사용자 본인과 사용자를 관리할 수 있는 사람만 볼 수
있습니다.

**외부** 사용자의 경우 이메일은 ID 공급자에서 가져옵니다. 이 필드는 읽기 전용이며, Semaphore는 로그인할 때마다
주소를 업데이트합니다.

## 비밀번호 {#user-password}

새 사용자를 만들 때 표시됩니다.

사용자가 로그인할 때 사용하는 비밀번호입니다. Semaphore에 비밀번호가 없는 **외부** 사용자를 제외하면 이 필드는
필수입니다. 기존 사용자의 비밀번호를 변경하려면 **Security** 탭의 **Change password**를 사용하세요.

## 알림 전송 {#user-alert}

사용자가 볼 수 있는 작업이 프로젝트에서 실패하면 사용자에게 이메일을 보냅니다. 프로젝트가 알림을 허용해야 하고,
서버 관리자가 이메일 알림을 켜야 합니다. 작업 템플릿은 실패한 작업이 알림을 보내지 않도록 설정할 수 있습니다.

이 플래그는 Telegram, Slack 및 기타 메신저로 전송되는 프로젝트 알림에는 영향을 주지 않습니다.

## 관리자 사용자 {#user-admin}

관리자일 때 표시됩니다.

관리자는 서버에서 모든 일을 할 수 있습니다. 사용자, 전역 역할, 서버 설정을 관리하고, 모든 프로젝트를 전체 권한으로
엽니다.

자신의 계정에서 이 플래그를 뺄 수 없으며, 서버는 적어도 한 명의 관리자를 유지합니다. 마지막 관리자에게서 플래그를
빼는 것은 거부됩니다.

## Pro user {#user-pro}

Pro 에디션에서 표시됩니다. 관리자만 이 플래그를 변경할 수 있습니다.

사용자에게 Pro 구독의 자리 하나를 줍니다. 구독에는 Pro 사용자 수가 정해져 있으며, 그 수에 도달하면 서버는 플래그
저장을 거부합니다. 활성 구독이 없으면 이 플래그는 효과가 없습니다.

## 외부 {#user-external}

관리자일 때 표시됩니다. 사용자를 만들 때만 설정할 수 있습니다.

외부 사용자는 Semaphore의 비밀번호가 아니라 LDAP 또는 OpenID Connect를 통해 로그인합니다. 비밀번호 필드는
비활성화되며, 비밀번호로 로그인하는 것은 거부됩니다. 이름과 이메일은 로그인할 때마다 ID 공급자에서 가져옵니다.
비밀번호로 로그인하는 사용자라면 상자를 비워 두세요.

## Change password {#user-changePassword}

서버가 비밀번호 로그인을 허용할 때, **외부**가 아닌 기존 사용자의 **Security** 탭에 표시됩니다.

새 비밀번호를 설정하는 대화 상자를 엽니다. 자신의 비밀번호를 변경하려면 현재 비밀번호를 입력해야 하며, 다른
사용자의 비밀번호를 재설정할 때는 입력하지 않습니다.

## Time-based one-time password {#user-totp}

관리자가 서버에서 2단계 인증을 켰을 때 **Security** 탭에 표시됩니다.

이 사용자의 2단계 인증을 켭니다. 스위치를 켜면 Semaphore가 즉시 시크릿을 만들어 QR 코드로 보여 줍니다. 인증
앱으로 스캔하세요. 그 후로는 로그인할 때 비밀번호 다음에 앱의 코드를 묻습니다.

서버가 복구를 허용하면 QR 코드 아래에 복구 코드가 표시됩니다. 복구 코드는 한 번만 표시되므로, 복사하여 안전하게
보관하세요. 스위치를 끄면 시크릿이 즉시 제거됩니다.

## LDAP 공급자 {#user-ldapProvider}

서버에 아직 계정이 연결되지 않은 LDAP 공급자가 있을 때 자신의 계정의 **Security** 탭에 표시됩니다.

LDAP 서버가 여러 개일 때 계정을 연결할 LDAP 서버입니다.

## LDAP username {#user-ldapUsername}

**LDAP 공급자**와 함께 표시됩니다.

LDAP 서버에서의 사용자 이름입니다. 연결하면 LDAP를 통해서도 이 계정에 로그인할 수 있습니다.

## LDAP password {#user-ldapPassword}

**LDAP 공급자**와 함께 표시됩니다.

LDAP 서버에서의 비밀번호입니다. Semaphore는 LDAP 계정이 본인의 것인지 확인하기 위해 한 번 사용하며, 저장하지
않습니다.

## Link {#user-ldapLink}

**LDAP 공급자**와 함께 표시됩니다.

계정을 위의 LDAP 계정에 연결합니다. 자격 증명이 틀렸거나, LDAP 계정이 다른 사용자에 연결되어 있거나, 계정이 이미
그 공급자에 연결되어 있으면 연결이 거부됩니다. 연결된 계정은 **Linked accounts** 아래에 표시되며, 연결을 끊으려면
그 칩을 닫으세요.

## Global role {#global-role-select}

Pro 에디션에서 전역 역할을 관리할 수 있을 때, 기존 사용자의 **Roles** 탭에 표시됩니다.

사용자에게 부여할 전역 역할로, 사용자가 아직 갖지 않은 역할 중에서 선택합니다. 전역 역할은 서버 전체에 대한
권한을 부여합니다. 사용자, 전역 역할 또는 서버 설정을 관리하거나 감사 로그를 읽는 권한입니다. 전역 역할 자체는
사용자 페이지의 **전역 역할** 탭에서 만듭니다.

## Assign {#globalRoleAssign-assign}

**Global role**과 함께 표시됩니다.

선택한 역할을 사용자에게 즉시 부여합니다. 사용자가 가진 역할은 아래에 나열되며, 각 역할에는 그 역할을 빼는 버튼이
있습니다. **Effective global permissions**는 사용자가 최종적으로 할 수 있는 일과 각 권한의 출처를 보여 줍니다.
