# Choose workspace to attach

このワークスペースをテンプレートに接続し、その状態とエイリアスとともにテンプレートのワークスペースの中に表示されるようにします。ワークスペースは一度に 1 つのテンプレートに属します。接続すると、インベントリ ページから外れ、テンプレートで管理されるようになります。接続しても、テンプレートのデフォルトのワークスペースにはなりません。そうするには、テンプレートを開いて **Make default** を押します。

## Template {#inventoryAttach-templateId}

ワークスペースを接続するテンプレートです。このフィールドは必須です。一覧には、ワークスペースと同じアプリ (Terraform または OpenTofu) 用に作られたプロジェクトのテンプレートが表示されます。

ワークスペースは名前、キー、状態を保持します。後で別のテンプレートに移すには、接続先のテンプレートで **Detach** を押します。ワークスペースはインベントリ ページに戻ります。テンプレートのデフォルトのワークスペースは切り離せません。
