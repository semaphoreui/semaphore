# 변수 그룹 수정

변수 그룹은 이 그룹을 사용하는 작업 템플릿의 모든 작업에 Semaphore가 전달하는 추가 변수, 환경 변수, 비밀 값을
보관합니다. Ansible은 추가 변수를 `--extra-vars`로, Terraform과 OpenTofu는 `-var`로 받으며, 환경 변수는 작업
프로세스에 설정됩니다. 템플릿은 여러 그룹을 사용할 수 있습니다. 두 그룹이 같은 이름을 정의하면 템플릿에서 나중에
오는 그룹이 우선합니다.

## 그룹 이름 {#varGroup-name}

변수 그룹 페이지와 작업 템플릿의 변수 그룹 선택 목록에 표시되는 그룹 이름입니다. 이 필드는 필수입니다.

## Secret storage {#varGroup-secretStorageId}

그룹이 새것이고 서버가 비밀 저장소를 지원할 때 표시됩니다. 선택 사항입니다.

이 그룹의 비밀 값이 보관되는 비밀 저장소입니다. 예: HashiCorp Vault. 비밀 값을 Semaphore 데이터베이스에 암호화하여
보관하려면 비워 두세요.

저장소는 그룹을 만들 때 한 번만 선택합니다. 기존 그룹은 저장소를 유지하며 이 필드는 더 이상 표시되지 않습니다.
**Read only**로 표시된 저장소는 새 비밀 값을 받지 않으며, 그곳에 비밀 값을 저장하면 실패합니다.

## Secret key prefix {#varGroup-secretStorageKeyPrefix}

그룹이 새것이고 서버가 비밀 저장소를 지원할 때 표시됩니다. **Secret storage**를 선택하면 사용할 수 있습니다.

이 그룹의 모든 비밀 값이 저장소에서 받는 경로의 앞부분입니다. Semaphore는 여기에 임의의 문자 10개를 덧붙입니다.
접두사가 `semaphore/prod/`이면 비밀 값은 `semaphore/prod/` 뒤에 그 문자들이 붙은 경로로 저장됩니다. 접두사는
그대로 사용되므로, 비밀 값이 폴더처럼 그 아래에 있어야 한다면 `/`로 끝내세요.

접두사는 그룹을 만들 때 한 번만 설정합니다. **Secrets** 탭에 소스 경로 패턴으로 표시됩니다.

## Table, JSON 또는 YAML {#varGroup-extraVarsMode}

추가 변수를 편집하는 방식입니다.

- **Table**: 변수 하나에 행 하나이며, 각 행에 유형이 있습니다. 스위치 옆의 **+** 버튼으로 행을 추가하세요.
- **JSON**: 모든 변수를 하나의 JSON 객체로 입력합니다.
- **YAML**: 모든 변수를 하나의 YAML 매핑으로 입력합니다.

대화 상자는 **Table**로 열립니다. 전환하면 입력한 내용이 변환됩니다. 내용을 읽을 수 없으면 대화 상자는 원래 방식에
머물며 오류를 표시합니다. 방식과 관계없이 변수는 이름과 값으로 된 하나의 객체로 저장됩니다.

## JSON 형식의 추가 변수 {#varGroup-extraVarsJson}

추가 변수를 **JSON**으로 편집할 때 표시됩니다.

하나의 JSON 객체로 된 추가 변수입니다. 이름은 비어 있을 수 없으며, 값은 문자열, 숫자, 목록 또는 객체일 수
있습니다.

```json
{
  "app_version": "1.4.2",
  "replicas": 3,
  "regions": ["eu-west-1", "us-east-1"]
}
```

## YAML 형식의 추가 변수 {#varGroup-extraVarsYaml}

추가 변수를 **YAML**로 편집할 때 표시됩니다.

하나의 YAML 매핑으로 된 추가 변수입니다. 텍스트는 JSON이 아는 유형으로 읽힙니다. 따옴표 없는 날짜(예:
`2024-01-01`)는 문자열로 남으며, `.inf`나 `.nan`은 거부됩니다. 최상위의 목록이나 스칼라도 거부됩니다.

```yaml
app_version: 1.4.2
replicas: 3
regions:
  - eu-west-1
  - us-east-1
```

## 변수 이름 {#varGroup-varName}

추가 변수를 **Table**로 편집할 때 모든 행에 표시됩니다.

플레이북이나 Terraform 코드에서 보이는 변수의 이름입니다. 예: `app_version`.

## 변수 유형 {#varGroup-varType}

추가 변수를 **Table**로 편집할 때 모든 행에 표시됩니다.

행의 값을 읽는 방법입니다.

- **String**: 텍스트 그대로입니다.
- **Number**: 숫자입니다. 예: `42`.
- **List**: JSON 배열입니다. 예: `["a", "b"]`.
- **Dict**: JSON 객체입니다. 예: `{"key": "value"}`.

유형에 맞지 않는 값이 있으면 변수 이름과 함께 저장이 중단됩니다.

## 변수 값 {#varGroup-varValue}

추가 변수를 **Table**로 편집할 때 모든 행에 표시됩니다.

유형의 형식에 맞는 변수의 값입니다. **List**나 **Dict**의 경우 필드 끝의 버튼을 누르면 더 큰 편집기가 열립니다.

Semaphore는 값을 데이터로 Ansible에 전달합니다. 값 안의 `{{ … }}` 표현식은 평가되지 않으며, 플레이북은 텍스트를
그대로 받습니다.

## 환경 변수 이름 {#varGroup-envName}

**Variables** 탭의 **환경 변수** 아래 모든 행에 있습니다. 섹션의 **+** 버튼으로 행을 추가하세요.

작업을 실행하는 프로세스의 환경에 설정되는 변수의 이름입니다. 예: `AWS_REGION`.

## 환경 변수 값 {#varGroup-envValue}

**Variables** 탭의 **환경 변수** 아래 모든 행에 있습니다.

변수의 값으로, 텍스트입니다. 일반 텍스트로 저장되어 그룹을 여는 모든 사람에게 표시되므로, 비밀번호와 토큰은 대신
**Secrets** 탭에 넣으세요.

## Sync keys enabled {#varGroup-syncEnabled}

비밀 저장소가 있는 그룹의 **Secrets** 탭에 표시됩니다.

켜면 **Sync paths**에 설정한 경로에서 저장소의 비밀 값을 이 그룹으로 가져옵니다. 가져오기는 변수 그룹 페이지에서
그룹의 동기화 버튼을 누를 때와, **Sync paths**에 설정한 간격마다 자동으로 실행됩니다. 끄면 아무것도 가져오지
않습니다.

## Sync paths {#varGroup-syncPaths}

**Sync keys enabled**가 켜져 있을 때 표시됩니다.

가져올 저장소의 경로와 자동 가져오기 간격이 있는 대화 상자를 엽니다. 버튼의 숫자는 경로의 개수입니다. 그룹에
경로가 하나 이상 있을 때까지 변수 그룹 페이지에서 그룹의 동기화 버튼은 비활성화된 채로 있습니다.

그 대화 상자에는 **닫기**만 있습니다. 그 안에서 변경한 내용은 이 대화 상자의 **저장**으로 그룹과 함께 저장됩니다.

## 비밀 변수 이름 {#varGroup-secretVarName}

**Secrets** 탭의 **추가 변수** 아래 모든 행에 있습니다. 섹션의 **+** 버튼으로 행을 추가하세요.

값이 비밀인 추가 변수의 이름입니다. 작업은 **Variables** 탭의 추가 변수와 같은 방식으로 이를 받으며, 비밀 값이 같은
이름의 추가 변수보다 우선합니다. Ansible은 비밀 값을 Ansible Vault로 암호화된 파일로 받고, Terraform과 OpenTofu는
`-var`로 받습니다. 대화 상자의 경고대로, 이렇게 전달된 비밀 값은 Ansible 로그에 일반 텍스트로 나타날 수 있습니다.

## 비밀 변수 값 {#varGroup-secretVarValue}

**Secrets** 탭의 **추가 변수** 아래 모든 행에 있습니다.

비밀 값입니다. Semaphore는 이를 암호화하거나 그룹의 비밀 저장소에 기록하며, 다시 표시하지 않습니다. 나중에 그룹을
열면 이 필드는 비어 있습니다. 저장된 값을 유지하려면 비워 두고, 교체하려면 새 값을 입력하세요. 행을 삭제하면 그룹을
저장할 때 비밀 값이 삭제됩니다.

## 비밀 환경 변수 이름 {#varGroup-secretEnvName}

**Secrets** 탭의 **환경 변수** 아래 모든 행에 있습니다. 섹션의 **+** 버튼으로 행을 추가하세요.

값이 비밀인 환경 변수의 이름입니다. 예: `DB_PASSWORD`. **Variables** 탭의 환경 변수와 마찬가지로 작업을 실행하는
프로세스의 환경에 설정됩니다.

## 비밀 환경 변수 값 {#varGroup-secretEnvValue}

**Secrets** 탭의 **환경 변수** 아래 모든 행에 있습니다.

비밀 값입니다. 비밀 추가 변수와 마찬가지로 다시 표시되지 않습니다. 저장된 값을 유지하려면 필드를 비워 두고,
교체하려면 새 값을 입력하세요.
