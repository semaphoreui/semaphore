# 実行を編集

実行とは、他のサービスが Semaphore の webhook URL を呼び出したとき（たとえば GitHub の push
イベント）にインテグレーションが開始するものです。タスクテンプレートのタスク、または workflow を開始します。URL
とリクエストの検証は実行ではなく、インテグレーションのエンドポイントに属します。実行のページには、そのマッチャーとリクエストから取り出す値があります。

## 名前 {#integrationForm-name}

統合 ページに表示される統合の名前です。統合が開始したタスクは、監査ログでその統合によるものとして記録されます。このフィールドは必須です。

## インテグレーション {#integrationForm-groupId}

実行が属するインテグレーションです。実行は、そのインテグレーションのエンドポイントに届き、認可を通過したリクエストで開始されます。このフィールドは必須です。

## ターゲット {#integrationForm-targetToggle}

サーバーがワークフローをサポートしている場合に表示されます。

統合が開始するものです。**Template** はタスクテンプレートのタスクを開始し、**Workflow** はワークフローの実行を開始します。**Workflow** に切り替えると、下のタスクパラメーターは破棄されます。

## Workflow to run {#integrationForm-workflowId}

**ターゲット** が **Workflow** の場合に表示されます。

リクエストが開始するワークフローです。統合がリクエストから取り出すすべての値は、同じ名前のワークフローの調査変数への回答としてワークフローに渡されます。ワークフローの統合には Pro エディションが必要です。Pro エディションがない場合、このフィールドは無効になり、サーバーは変更を拒否します。

## 実行するタスクテンプレート {#integrationForm-templateId}

**ターゲット** が **Template** の場合に表示されます。

リクエストがタスクを開始するタスクテンプレートです。このフィールドは必須です。テンプレートを選択すると、そのタスクのパラメーターが下に表示されます。

## タスクパラメーター {#integrationForm-taskParams}

タスクテンプレートが選択されている場合に表示されます。

この統合が開始するすべてのタスクが受け取るパラメーターで、テンプレートから自分でタスクを開始した場合と同じです。ここにあるのは、テンプレートがタスクでの上書きを許可しているオプションのみです。リクエストから取り出した値はこれらを上書きします。**Variables** タイプの値は同じ名前の回答を、**Task Params** タイプの値は同じ名前のパラメーターを上書きします。

テンプレートがタスクでの CLI 引数を許可している場合、**CLI args** にはタスクのコマンドライン用の追加の引数を入力します。

## メッセージ {#taskParams-message}

任意です。統合が開始するすべてのタスクのメッセージで、タスクの履歴に表示されます。

## 調査変数 {#taskParams-survey}

テンプレートに調査変数がある場合に表示されます。

テンプレートの調査への回答で、すべてのタスクで同じです。リクエストから取り出した **Variables** タイプの値は、同じ名前の回答を置き換えます。

シークレットタイプの変数への回答は、統合とともに保存されません。シークレットは代わりにテンプレートの変数グループを通じて渡してください。

## ブランチ {#taskParams-gitBranch}

テンプレートがタスクでのブランチの上書きを許可している場合に表示されます。

タスクがチェックアウトするリポジトリのブランチまたはタグです。テンプレートのブランチを使う場合は、そのままにします。リクエストから取り出した、名前が `git_branch` の **Task Params** タイプの値がこれを上書きします。その値の先頭の `refs/heads/` は削除されます。

## インベントリ {#taskParams-inventoryId}

テンプレートがタスクでのインベントリの上書きを許可している場合に表示されます。

テンプレートのインベントリの代わりにタスクが対象とするインベントリ、または Terraform の場合はワークスペースです。

## Ansibleオプション {#taskParams-ansible}

テンプレートが Ansible のプレイブックを実行する場合に表示されます。

すべてのタスクに対する `ansible-playbook` のオプションで、それぞれテンプレートが許可している場合に表示されます: **制限**、**タグ**、**スキップタグ**、**デバッグ**、**ドライラン** (`--check`)、**差分**、**Skip Galaxy install**。

## Terraformオプション {#taskParams-terraform}

テンプレートが Terraform、OpenTofu、Terragrunt を実行する場合に表示されます。

- **Plan**: タスクはプランを実行して停止し、何も適用されません。
- **Destroy**: プランと適用によってリソースが破棄されます。
- **Auto Approve**: テンプレートが自動承認を許可している場合、プランは確認なしで適用されます。これがない場合、タスクは誰かが Semaphore で確認するまで待機します。
- **Upgrade** と **Reconfigure**: `init` が `-upgrade` と `-reconfigure` 付きで実行されます。
