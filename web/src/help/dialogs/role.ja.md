# Edit Role

ロールは、プロジェクト内の権限に名前を付けたセットです。プロジェクトのメンバーにロールを付与し、メンバーはいずれかのロールが許可することを行えます。プロジェクトの Roles ページから開いた場合、このダイアログはそのプロジェクトのロールのみを編集します。プロジェクトの外の Roles ページから開いた場合は、すべてのプロジェクトで使える共有のロールを編集します。組み込みのロール Owner、Manager、Task Runner、Guest は変更できません。

## 名前 {#role-name}

Roles ページ、およびロールを選択するすべての場所 (プロジェクトにメンバーを追加するときなど) に表示されるロールの名前です。このフィールドは必須です。ロールの名前はいつでも変更できます。

## Slug {#role-slug}

ロールの識別子です。名前を入力している間、自分でスラッグを編集するまで、Semaphore が名前からこれを入力します。1 から 100 文字の英字、数字、アンダースコア、ハイフンを使えます。例: `release-managers`。

ロールを保存した後、スラッグは変更できません。ロールを編集するときは、このフィールドはロックされています。

- スラッグは一意である必要があり、その確認では英字の大文字と小文字は区別されません。共有のロールのスラッグは他のすべてのロールと異なる必要があります。プロジェクトのロールのスラッグは、共有のロールおよびそのプロジェクトの他のロールと異なる必要があります。
- `owner`、`manager`、`task_runner`、`guest`、`all` は、大文字と小文字に関係なく予約されています。

## Permissions {#role-permissionsTitle}

ロールを持つメンバーがプロジェクトで行えることです。新しいロールでは何もチェックされていません。メンバーが持つすべてのロールの権限は合算されます。Semaphore の管理者は、ロールに関係なく、すべてのプロジェクトですべてのことを行えます。

- **Can read project**: プロジェクトを表示します。タスクテンプレート、タスクとそのログ、インベントリ、キー、リポジトリ、変数グループ、スケジュール、メンバーです。プロジェクト内のすべての読み取りにこの権限が必要で、他の権限にはこれが含まれないため、ほとんどすべてのロールでチェックを入れてください。これがない場合、メンバーには、ロールに独自のアクセス権を付与しているタスクテンプレートとワークフロー、およびそのタスクのみが表示されます。
- **Can run project tasks**: タスクテンプレートからタスクを開始し、停止し、確認待ちのタスクを確認または拒否します。
- **Can update project**: プロジェクトの設定を変更し、プロジェクトを削除します。
- **Can manage project resources**: タスクテンプレート、インベントリ、キー、リポジトリ、変数グループ、スケジュール、ビュー、統合、シークレットストレージ、プロジェクトのランナー、プロジェクトのロールを作成、変更、削除します。タスクを削除します。どのロールがタスクテンプレートを使えるかを設定します。
- **Can manage project users**: プロジェクトにメンバーを追加し、そのロールを変更し、メンバーを削除します。
- **Can run workflows**: ワークフローを開始し、その実行を停止します。
- **Can edit workflows**: ワークフローを作成、変更、削除し、どのロールがワークフローを使えるかを設定します。
- **Can approve workflows**: 承認待ちのワークフローの実行のステップを承認または拒否します。
