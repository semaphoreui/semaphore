# 러너 수정

러너는 Semaphore 서버 대신 자체 머신에서 작업을 실행하는 별도의 `semaphore runner` 프로세스입니다. 서버가
러너에서 작업을 실행하도록 설정되어 있거나, 작업 템플릿이나 그 인벤토리에 러너 태그가 있으면 작업이 러너로
갑니다. 그러면 서버는 활성화되어 있고, 등록되어 있고, 온라인이며, 병렬 작업 한도에 도달하지 않은 러너를
고릅니다. 프로젝트 러너가 먼저이고 그다음이 전역 러너이며, 각 그룹 안에서는 임의의 순서입니다. 일치하는 모든
러너가 오프라인이거나 바쁘면 작업은 대기열에서 기다리고, 일치하는 러너가 전혀 없으면 작업은 실패합니다.

## 이름 {#runner-name}

필수입니다. 러너 페이지에 표시되는 러너 이름입니다. 예: 러너가 실행되는 호스트. 러너가 받는 작업에는 영향을
주지 않습니다.

## Tags {#runner-tags}

Semaphore Pro에서 사용할 수 있으며, 다른 에디션에서는 이 필드가 잠겨 있습니다.

이 러너의 작업을 고르는 태그입니다. 러너 태그가 있는 작업은 그 태그를 가진 러너로만 갑니다. 작업 템플릿의
태그가 인벤토리의 태그보다 우선합니다. 태그를 입력하고 Enter를 누르거나, 다른 러너가 사용하는 태그를
선택하세요. 빈 태그와 중복 태그는 저장할 때 제거됩니다.

프로젝트 러너에는 **Is default**가 체크되어 있지 않으면 태그가 하나 이상 필요합니다.

## Is default {#runner-isDefault}

러너 태그가 없는 작업은 기본으로 표시된 러너로만 갑니다. 자신의 태그 중 하나가 있는 작업만 받아야 하는
러너라면 체크를 해제하세요.

새 전역 러너에서는 체크되어 있고, 새 프로젝트 러너에서는 해제되어 있습니다.

## Register {#runner-registered}

러너를 만들 때 표시됩니다.

- 체크됨(기본값): 서버가 토큰과 함께 러너를 만듭니다. **생성** 후 대화 상자에 토큰과 그 토큰으로 러너를
  시작하는 명령이 표시됩니다.
- 해제됨: 토큰 없이 러너가 만들어집니다. 나중에 러너 행에서 **Regenerate registration token**(두 화살표
  아이콘)을 클릭하여 1시간 동안 유효한 일회용 등록 토큰을 받고, `semaphore runner register`로 러너를
  등록하세요.

등록되지 않은 러너는 작업을 받지 않습니다.

## Webhook {#runner-webhook}

선택 사항입니다. 서버가 이 러너에 작업을 줄 때 호출하는 URL입니다. 예: 필요할 때 러너를 시작하기 위해. 서버는
JSON 본문과 함께 `POST` 요청을 보냅니다.

```json
{"action": "start", "project_id": 1, "task_id": 42, "template_id": 7, "runner_id": 3}
```

URL은 30초 안에 상태 200 또는 204로 응답해야 하며, 그렇지 않으면 작업은 실패합니다. 웹후크가 있는 러너는
최근에 서버를 폴링하지 않았더라도 항상 온라인으로 취급됩니다. 항상 실행되는 러너라면 이 필드를 비워 두세요.

## 최대 병렬 작업 수 {#runner-maxParallelTasks}

러너가 동시에 실행할 수 있는 작업 수입니다. 한도에 도달하면 다음 작업은 일치하는 다른 러너로 가거나
대기열에서 기다립니다. 한도를 두지 않으려면 이 필드를 비워 두거나 `0`으로 설정하세요.

## 활성화됨 {#runner-active}

활성화된 러너만 새 작업을 받습니다. 러너를 삭제하지 않고 서비스에서 빼려면 체크를 해제하세요. 러너 목록의
스위치도 같은 역할을 합니다.

새 러너에서는 체크가 해제되어 있습니다. 체크하거나, 나중에 목록에서 러너를 활성화하세요.
