# 수정 Repository

리포지토리는 작업 템플릿의 플레이북, Terraform 코드 또는 스크립트를 가져오는 곳입니다. Git 리포지토리이거나
작업을 실행하는 머신의 디렉터리입니다. 모든 작업 전에 Semaphore는 Git 리포지토리를 복제하거나 이전에 복제한
사본을 업데이트하고, 브랜치를 체크아웃한 다음, 그 사본에서 작업을 실행합니다.

## 이름 {#repository-name}

리포지토리 페이지와 작업 템플릿 및 인벤토리의 리포지토리 선택 목록에 표시되는 리포지토리 이름입니다. 이
필드는 필수입니다.

## URL 또는 경로 {#repository-gitUrl}

코드가 있는 위치입니다. 이 필드는 필수입니다. 필드 아래의 칩은 입력한 주소의 종류를 보여 주며, 칩을
클릭하면 주소가 그 종류로 다시 작성됩니다.

- **ssh**: `git@github.com:org/repo.git` 또는 `ssh://git@github.com/org/repo.git`. Git은 주소에 있는 사용자와
  **액세스 키**에서 선택한 **SSH 키**로 로그인합니다.
- **https** 및 **http**: `https://github.com/org/repo.git`. 비공개 리포지토리에는 **비밀번호로 로그인** 키가,
  공개 리포지토리에는 **없음**이 필요합니다. `http`는 피하세요. 로그인과 비밀번호가 암호화되지 않은 채
  전송됩니다.
- **git**: `git://host/org/repo.git`. 로그인이 없는 읽기 전용 Git 프로토콜입니다.
- **file**: `file:///srv/git/repo.git`. 작업을 실행하는 머신의 디스크에 있는 Git 리포지토리로, 원격
  리포지토리처럼 복제됩니다.
- **절대 경로**: `/srv/playbooks` 또는 `D:\playbooks`와 같은 절대 경로입니다. Semaphore는 이를 복제하지
  않습니다. 작업은 바로 그 디렉터리에서 실행되며, 디렉터리는 작업을 실행하는 머신(Semaphore 서버 또는
  러너)에 있어야 합니다. 브랜치는 적용되지 않습니다.

주소를 바꾸면 Semaphore 서버가 이전 주소에서 복제한 사본이 제거됩니다.

## 브랜치 {#repository-gitBranch}

Semaphore가 복제하고 최신 상태로 유지하는 브랜치입니다. 예: `main`. 이 필드는 필수이며, 절대 경로의 경우에는
잠겨 있습니다.

작업 템플릿은 자체 브랜치를 지정할 수 있으며 이것이 여기의 브랜치보다 우선합니다. 또한 템플릿은 작업을 시작할
때 브랜치를 선택하도록 허용할 수 있습니다. 태그도 사용할 수 있지만 태그는 pull할 수 없으므로, Semaphore는
모든 작업 전에 리포지토리를 새로 복제합니다.

## Single checkout for all templates {#repository-monorepo}

기본적으로 꺼져 있으며, 이 경우 모든 작업 템플릿이 리포지토리의 자체 사본을 갖습니다. 템플릿마다 사본을
두기에는 너무 큰 리포지토리라면, 이 상자를 체크하여 리포지토리를 한 번만 복제하고 그 사본을 이 리포지토리를
사용하는 모든 템플릿이 공유하게 하세요.

공유 사본은 이 리포지토리의 브랜치에 머뭅니다. 이 사본을 사용하는 템플릿은 자체 브랜치를 가질 수 없으며, 그
작업도 다른 브랜치나 커밋을 선택할 수 없습니다. 절대 경로의 경우에는 잠겨 있습니다.

## 액세스 키 {#repository-sshKeyId}

Git이 리포지토리에 로그인할 때 사용하는 키 저장소의 키입니다. 이 필드는 필수입니다. 세 가지 유형의 키를
선택할 수 있으며, 어떤 것을 선택할지는 URL에 따라 다릅니다.

- `ssh` URL에는 **SSH 키**. Semaphore는 복제나 업데이트가 진행되는 동안 개인 키를 SSH 에이전트에
  불러옵니다. 사용자는 URL에 있는 사용자로, `git@github.com:org/repo.git`의 `git`이 그 예입니다.
- `https` URL에는 **비밀번호로 로그인**. 로그인과 비밀번호, 또는 Git 서버의 액세스 토큰입니다. 로그인이
  비어 있으면 비밀번호만 사용자 이름으로 전송되며, 일부 서버는 토큰을 이렇게 받습니다. 같은 자격 증명이 같은
  서버에 있는 롤과 컬렉션을 위해 `ansible-galaxy`에도 전달됩니다.
- 공개 리포지토리, `git` 또는 `file` URL, 절대 경로에는 **없음**.

URL에 맞지 않는 키는 Git에 자격 증명을 주지 못하며, 이 경우 비공개 리포지토리는 복제에 실패합니다.
