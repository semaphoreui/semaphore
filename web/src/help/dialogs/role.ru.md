# Edit Role

Роль — это именованный набор прав внутри проекта. Вы назначаете роли участникам проекта, и
участник может делать то, что разрешает любая из его ролей. Если диалог открыт со страницы Roles
проекта, он изменяет роль только этого проекта; если он открыт со страницы Roles вне проекта, он
изменяет общую роль, которую может использовать любой проект. Встроенные роли Owner, Manager, Task
Runner и Guest изменить нельзя.

## Имя {#role-name}

Имя, под которым роль показана на странице Roles и везде, где выбирается роль, например при
добавлении участника в проект. Поле обязательное. Роль можно переименовать в любой момент.

## Slug {#role-slug}

Идентификатор роли. Semaphore заполняет его по имени, пока вы вводите имя, до тех пор, пока вы
сами не измените slug. Он состоит из 1–100 букв, цифр, знаков подчеркивания и дефисов, например
`release-managers`.

Slug нельзя изменить после сохранения роли: при редактировании роли поле заблокировано.

- Slug должен быть уникальным, и проверка не учитывает регистр букв. Slug общей роли должен
  отличаться от всех остальных ролей; slug роли проекта должен отличаться от общих ролей и от
  остальных ролей своего проекта.
- `owner`, `manager`, `task_runner`, `guest` и `all` зарезервированы в любом регистре.

## Permissions {#role-permissionsTitle}

Что участники с этой ролью могут делать в проекте. У новой роли не отмечено ни одно право. Права
всех ролей участника складываются; администратор Semaphore может делать все в любом проекте
независимо от ролей.

- **Can read project**: видеть проект: его шаблоны задач, задачи и их логи, инвентари, ключи,
  репозитории, группы переменных, расписания и участников. Это право требуется для любого чтения в
  проекте, и никакое другое право его не включает, поэтому отмечайте его почти для каждой роли.
  Без него участник видит только те шаблоны задач и workflow, которые сами дают роли доступ, вместе
  с их задачами.
- **Can run project tasks**: запускать задачи из шаблонов задач, останавливать их, а также
  подтверждать или отклонять задачу, которая ждет подтверждения.
- **Can update project**: изменять настройки проекта и удалять его.
- **Can manage project resources**: создавать, изменять и удалять шаблоны задач, инвентари, ключи,
  репозитории, группы переменных, расписания, представления, интеграции, хранилища секретов,
  исполнителей проекта и роли проекта; удалять задачи; задавать, какие роли могут использовать
  шаблон задачи.
- **Can manage project users**: добавлять участников в проект, изменять их роли и удалять их.
- **Can run workflows**: запускать workflow и останавливать его выполнения.
- **Can edit workflows**: создавать, изменять и удалять workflow и задавать, какие роли могут
  использовать workflow.
- **Can approve workflows**: одобрять или отклонять шаг выполнения workflow, который ждет
  одобрения.
