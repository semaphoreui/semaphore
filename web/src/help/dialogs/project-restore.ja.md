# プロジェクトを復元...

プロジェクトの 設定 ページにある **プロジェクトのバックアップ** で作成したバックアップファイルから、新しいプロジェクトを作成します。新しいプロジェクトには、バックアップに設定されているタスクテンプレート、インベントリ、リポジトリ、変数グループ、キー、スケジュール、統合、その他のものが含まれ、そのオーナーには自分がなります。サーバーの管理者がすべてのユーザーにプロジェクトの作成を許可していない限り、プロジェクトを復元できるのは管理者だけです。

## プロジェクト名 {#restoreProject-name}

新しいプロジェクトの名前です。このフィールドは必須で、バックアップファイルに書かれた名前を置き換えます。

名前は、サーバー上のすべてのプロジェクトの名前と異なる必要があります。すでに使われている名前でプロジェクトを復元しようとすると、サーバーは拒否します。

## Backup file {#restoreProject-file}

バックアップの JSON ファイルです。**Restore** を押す前にファイルを選択してください。

バックアップには、キーのシークレットと、変数グループの **Secrets** タブにあるシークレットは含まれません。復元後、Semaphore は空になっていてシークレットの再入力が必要なキーの数を知らせます。また、変数グループのシークレットも再入力する必要があります。リポジトリのアドレスなど、ほかのフィールドに直接入力したパスワードは、ファイルにあるとおりに戻ります。プロジェクトのメンバーとタスクの履歴はバックアップに含まれません。新しいバージョンの Semaphore で作成されたバックアップは拒否されます。
