# Редактировать запуск

Запуск — это то, что интеграция запускает, когда другой сервис обращается к webhook URL Semaphore,
например при событии push в GitHub: задача шаблона задачи или workflow. URL и проверка запроса
относятся к эндпоинту интеграции, а не к запуску. На странице запуска находятся его условия и
значения, которые он берет из запроса.

## Имя {#integrationForm-name}

Имя, под которым интеграция показана на странице «Интеграции». Задачи, которые запускает
интеграция, записываются на нее в журнале аудита. Поле обязательное.

## Интеграция {#integrationForm-groupId}

Интеграция, к которой относится запуск. Запуск срабатывает на запросы, которые приходят на эндпоинт
этой интеграции и проходят ее авторизацию. Поле обязательное.

## Цель {#integrationForm-targetToggle}

Показывается, когда сервер поддерживает workflow.

Что запускает интеграция: **Template** запускает задачу шаблона задачи, **Workflow** запускает
выполнение workflow. При переключении на **Workflow** параметры задачи ниже сбрасываются.

## Workflow to run {#integrationForm-workflowId}

Показывается, когда в поле **Цель** выбрано **Workflow**.

Workflow, который запускает запрос. Каждое значение, которое интеграция берет из запроса,
передается в workflow как ответ на его переменную опроса с тем же именем. Интеграциям с workflow
нужна версия Pro: без нее поле недоступно, и сервер отклоняет изменение.

## Шаблон задачи для запуска {#integrationForm-templateId}

Показывается, когда в поле **Цель** выбрано **Template**.

Шаблон задачи, задачу которого запускает запрос. Поле обязательное. Когда шаблон выбран, под ним
появляются параметры его задач.

## Параметры задачи {#integrationForm-taskParams}

Показывается, когда выбран шаблон задачи.

Параметры, которые получает каждая задача, запущенная этой интеграцией, — так, как если бы вы сами
запустили ее из шаблона. Здесь есть только те параметры, которые шаблон разрешает переопределять в
задаче. Значения, взятые из запроса, переопределяют их: значение типа **Variables** — ответ с тем
же именем, значение типа **Task Params** — параметр с тем же именем.

Если шаблон разрешает CLI аргументы в задаче, поле **CLI args** содержит дополнительные аргументы
для командной строки задачи.

## Сообщение {#taskParams-message}

Необязательное поле. Сообщение каждой задачи, которую запускает интеграция; показывается в
истории задач.

## Переменные опроса {#taskParams-survey}

Показывается, когда у шаблона есть переменные опроса.

Ответы на опрос шаблона, одинаковые для каждой задачи. Значение типа **Variables**, взятое из
запроса, заменяет ответ с тем же именем.

Ответы на переменные типа secret не сохраняются вместе с интеграцией: вместо этого передавайте
секрет через группу переменных шаблона.

## Ветка {#taskParams-gitBranch}

Показывается, когда шаблон разрешает переопределять ветку в задаче.

Ветка или тег репозитория, которые извлекают задачи. Оставьте поле как есть, чтобы использовать
ветку шаблона. Значение с именем `git_branch` типа **Task Params**, взятое из запроса,
переопределяет его; начальный `refs/heads/` из этого значения удаляется.

## Инвентарь {#taskParams-inventoryId}

Показывается, когда шаблон разрешает переопределять инвентарь в задаче.

Инвентарь, а для Terraform — workspace, с которым выполняются задачи вместо инвентаря шаблона.

## Параметры Ansible {#taskParams-ansible}

Показывается, когда шаблон запускает плейбук Ansible.

Параметры `ansible-playbook` для каждой задачи; каждый показывается, если шаблон его разрешает:
**Лимит**, **Теги**, **Пропустить теги**, **Отладка**, **Пробный запуск** (`--check`),
**Различия** и **Пропустить установку Galaxy**.

## Параметры Terraform {#taskParams-terraform}

Показывается, когда шаблон запускает Terraform, OpenTofu или Terragrunt.

- **Plan**: задача выполняет план и останавливается, ничего не применяется.
- **Destroy**: план и применение уничтожают ресурсы.
- **Auto Approve**: план применяется без подтверждения, если шаблон разрешает автоматическое
  одобрение. Без этого задача ждет, пока кто-нибудь не подтвердит ее в Semaphore.
- **Upgrade** и **Reconfigure**: `init` выполняется с `-upgrade` и `-reconfigure`.
