# Edit Extract Value

Витягнуте значення бере частину вхідного запиту, наприклад гілку з події push, і передає її
завданню, яке запускає інтеграція. Кожне значення інтеграції береться з кожного запиту, що
запускає завдання.

## Name {#integrationValueForm-name}

Назва, під якою значення відображається на сторінці інтеграції. Вона не змінює ні того, що
береться, ні того, куди воно потрапляє. Поле обов’язкове.

## Source of the Value {#integrationValueForm-valueSource}

Частина запиту, з якої береться значення:

- **Header**: значення заголовка запиту.
- **Body**: тіло запиту.

## Data Type of Body {#integrationValueForm-bodyDataType}

Відображається, коли в полі **Source of the Value** вибрано **Body**.

Як читається тіло:

- **JSON**: тіло розбирається як JSON, а **Key** — це шлях до одного значення в ньому. Значення
  зберігає свій тип JSON: число, список або об’єкт потрапляють у завдання саме такими.
- **String**: усе тіло береться як текст, а **Key** не використовується.

## Key {#integrationValueForm-key}

Що брати із запиту. Поле обов’язкове.

- Для **Header**: назва заголовка, наприклад `X-GitHub-Event`. Регістр не має значення.
  Заголовок, якого немає в запиті, дає порожнє значення.
- Для **Body** у форматі **JSON**: шлях до значення, частини якого з’єднано крапками; елемент
  масиву записується як `.[0]`, наприклад `repository.full_name` або `commits.[0].id`. Шлях, якого
  немає в тілі, не дає значення, і завдання зберігає те, що задано в інтеграції.
- Для **Body** у форматі **String**: не використовується, але формі потрібне значення; введіть
  будь-що.

## Variable Usage {#integrationValueForm-variableType}

Куди потрапляє значення в завданні шаблону:

- **Variables**: додаткова змінна завдання, так само, як передається відповідь на змінну
  опитування. Вона замінює відповідь або змінну групи змінних з такою самою назвою.
- **Task Params**: параметр завдання, так само, як зберігаються параметри діалогу завдання. Назва
  `git_branch` задає гілку завдання, коли шаблон дозволяє перевизначати гілку; початкове
  `refs/heads/` видаляється.

Інтеграція, яка запускає workflow, ігнорує спосіб використання: кожне значення стає відповіддю на
змінну опитування workflow, названу в полі **Variable**.

## Variable {#integrationValueForm-variable}

Назва, під якою передається значення, наприклад `branch` для додаткової змінної, яку playbook
читає як `{{ branch }}`. Поле обов’язкове.
